# 그림과 효과음은 Comfy Cloud 대신 AI가 코드로 만든다

11주차 수업은 이미지·효과음을 Comfy Cloud(유료 구독, Standard 월 $20)로 만드는 경로를 소개했다. 하지만 강의 메인 페이지 평가 섹션은 "AI는 선택 사항"이고 유료 크레디트나 특정 모델을 필수로 요구하지 않는다. Falling Knife의 그림은 GDD상 320×180 도트·16색 이내이고, 소리는 "낮은 저음·시계 초침·둔탁한 충격음" 같은 단순한 소리라서, AI(Claude)가 **코드로 픽셀을 지정하고 파형을 합성**해도 GDD 의도에 맞출 수 있다. 시험 샘플(찌라시 아이콘, 캔들 2종, 충격음, 초침)을 보고 사용자가 이 방식을 결정했다(2026-11-15). 만드는 코드는 `tools/`에 남겨 과정을 그대로 보여 주고, 결과물은 사용자가 보고 듣고 고르며 그림은 직접 보정한다. 배경음악은 AI로 만들지 않고 사용자가 이용 허락된 곡(인더스트리얼 다크 하우스·하드 테크노 계열)을 구해 온다.

## Considered Options

- **Comfy Cloud 구독**: 수업 경로와 같고 캐릭터(광대) 품질이 높을 수 있다. 하지만 월 $20, 환불 원칙적 불가, 크레딧 이월 없음, 1회 생성 비용이 공개되지 않아 필요량을 미리 셀 수 없다. 평가상 필수가 아니어서 채택하지 않았다.
- **무료 음원(GDD 원래 계획, 효과음)**: 비용은 없지만 곡·효과음마다 제작자·이용 조건을 확인해야 하고 길이·톤을 맞추기 어렵다. 코드 합성은 길이·음량을 정확히 맞추고 권리도 단순하다. 효과음에는 채택하지 않았다(배경음악은 사용자가 외부 곡을 구함).

## Consequences

- 광대처럼 캐릭터다운 그림은 품질 한계가 있다 → 단순한 도트로 만들고 사용자가 직접 보정한다(필요하면 직접 그리기).
- 기록: `docs/asset-rights.md` AI 생성 에셋 표에 "도구: Claude가 작성한 코드(`tools/…`)", 사용자가 고른 후보·보정한 부분을 남긴다. gdd-changes #36~38.
