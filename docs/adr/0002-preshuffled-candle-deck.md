# 캔들 덱은 그때그때 뽑지 않고 라운드 시작 때 한 번 섞어 순서를 정해 둔다

캔들을 공개할 때마다 남은 하락·상승 비율로 무작위로 뽑아도 확률은 같다. 하지만 아이템 "차트 분석"(다음 캔들 나만 확인)과 "찌라시"(다음 캔들 공개 후 버림)는 다음 캔들이 미리 정해져 있어야 성립한다. 그래서 라운드 시작과 재장전 때 Fisher-Yates로 한 번 섞어 순서를 고정해 두기로 했다(2026-11-02 Grilling Q4). 덕분에 테스트용 고정 순서(`D U U D U`)도 같은 구조로 넣을 수 있다.

## Considered Options

- **공개할 때마다 비율로 뽑기**: 처음 코드는 더 짧다. 하지만 "다음 캔들"이 공개 직전까지 정해지지 않으므로, 차트 분석·찌라시를 넣을 때 "미리 뽑아 둔 캔들"을 따로 관리해야 하고 고정 순서 테스트도 따로 만들어야 한다. 그래서 채택하지 않았다.
