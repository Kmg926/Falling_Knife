## 줄별 핵심
| 부분 | 왜 |
|---|---|
| 그림의 **기준점(pivot)** 이 상승 = 아래, 하락 = 위 | 코드는 전과 똑같이 세로 크기만 0 → 1로 키운다. 크기를 바꿀 때 기준점은 안 움직이므로, 상승은 아래 끝이 기준선에 붙은 채 위로, 하락은 위 끝이 붙은 채 아래로 자란다. "방향" 계산을 코드에 넣지 않아도 됨 |
| `shownUpSprite`·`shownDownSprite` 따로 | "다음" 창(차트 분석)은 작은 캔들(`upSprite`·`downSprite`) 그대로 쓰기 때문에 그림 칸을 나눔 |
| `rows = look.rect.height` | 예전엔 18(지금 도트) 고정. 이제 그림 높이(새 도트 36줄)를 읽어 **새 도트 1줄씩** 자람 → 0.5단위라 흐려지지 않고, 그림 크기를 바꿔도 코드 수정 없음 |
| `ShowCandle(…, up, down)` | 같은 함수로 큰 캔들·작은 캔들을 모두 처리(어느 그림을 쓸지만 받음) |
| 공개 시간 | `game.RevealSeconds` 그대로(U2, 지금 Scene 값 1초) |
