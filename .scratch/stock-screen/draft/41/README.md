## 줄별 핵심
| 부분 | 왜 |
|---|---|
| `red[]`·`blue[]` 배열 + `Push()`(왼쪽으로 한 칸 밀고 맨 오른쪽에 새 값) | 화면 가로 칸 = 시간. 새 값이 오른쪽에서 들어와 왼쪽으로 흘러가는 **실제 시세 줄** 모양(제안 7) |
| `Sample(line, step)` = 사인 2개 + 해시 + 출렁임 | 큰 물결은 사인 두 개를 섞어 반복이 눈에 덜 띄게, 잔 흔들림은 `Hash`(같은 입력 → 같은 값)라 **무작위 없이도** 들쭉날쭉. 두 선은 위상(phase)을 달리해 겹치지 않음 |
| `Mathf.Clamp(v, 2, height - 3)` | 출렁임이 커도 선이 그림 영역 밖으로 나가지 않게(C4) |
| `wasRevealing && !game.IsRevealing` | 공개가 **끝나는 순간**만 잡음 → 공개 중에는 배경이 결과를 미리 알려 주지 않음(U4, C5) |
| `UpdateSpike` 3단계 | 0.25초에 목표(하락 −36·상승 +24 새 도트)까지 → 1초에 절반 회복 → 2초에 0. 0으로 돌아가야 다음 출렁임이 계속 쌓여 영역 밖으로 밀리지 않음 |
| `Time.deltaTime`만 사용 | 일시정지(`timeScale` 0)면 선도 멈춤 |
| `Sprite.Create(..., pivot (0,1), 2f)` | PPU 2·왼쪽 위 기준 → 다른 그림과 같은 640 격자, 흐리지 않게 `FilterMode.Point` |
| 빨강을 나중에 그림, 아래 한 줄 그림자 | 두 선이 교차할 때 빨강이 위. 그림자는 어두운 단계(red0·navy)라 32색 안 |
