## 줄별 핵심
| 부분 | 왜 |
|---|---|
| `Wobble(u)` = 사인 두 개(빠르기 1.6·3.1번) 섞기 × 0.7 | 위·아래로 **같은 크기**로 오가는 가격 → 출렁이는 동안에는 결과를 알 수 없음(C8). 실제 시세처럼 불규칙해 보이게 빠르기가 다른 두 물결을 섞음 |
| `phaseA·phaseB = Random.value` | 매번 출렁이는 모양이 다름 → "마지막에 위로 출렁였으니 상승"처럼 짐작할 수 없게 |
| `settleFrom = Wobble(1)` → `Lerp(…, target, EaseOutCubic)` | 출렁이던 그 자리에서 결과 끝(상승 +1·하락 −1)까지 부드럽게 굳음(튀지 않게) |
| `ShowPrice`: 가격 ≥ 0이면 상승 그림, 아니면 하락 그림 + 세로 크기 | 40에서 만든 "기준점(상승 = 아래, 하락 = 위) + 세로 크기" 방식을 그대로 써서 **방향만 매 프레임 바꿈**. 줄 수로 끊어 새 도트 단위(흐림 없음) |
| 번쩍임은 `Refresh`에서, 공개가 끝나는 순간(`wasRevealing && !IsRevealing`) | 공개가 끝나면 `Refresh`가 그리기 코루틴을 멈춘다 → 번쩍임을 그리기 끝에 두면 같이 끊길 수 있어서, 따로 코루틴으로 시작 |
| 테두리 그림이 공개 캔들의 **자식** | 굳는 순간 캔들은 길이 100%(세로 크기 1)라 자식 테두리가 그대로 겹침. 기준점(아래·위)이 같은 그림을 방향에 맞게 고름 |
