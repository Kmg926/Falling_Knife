# Spec: 타이틀 배경 — 게임과 같은 방·조명·시세 선 (title-bg)

Status: ready-for-agent

> 근거: 2026-11-18 Grilling Q1~Q8(모두 사용자 채택, `grilling.md`). 기준: formal-ui 29(TitleScene), lighting 49(조명 값·전등·빛줄기), stock-screen 41(`ChartLinesView`), ADR 0004(Comfy 채택 안 함, 그림은 코드), gdd-changes #68.
> Spec 작성 중 AI가 제안한 세부 8개("AI 제안" 절)는 2026-11-18 사용자가 **모두 채택**.
> 확인한 사실: TitleScene = UI만(`TitleCanvas` Screen Space Camera·거리 5 → 그 뒤 스프라이트는 배경), 조명·스프라이트 없음. `ChartLinesView`는 `game`이 비어 있으면 출렁임 없이 흐르기만 함(null 확인 있음), 출렁임 `StartSpike(target)`는 public. 타이틀 광대(UI)는 화면 오른쪽(대략 월드 x 93, 머리 꼭대기 y 37 ~ 몸 아래 y −55, 옛 캡처 기준 — 구현 때 다시 잼).

## 변경·유지·확인

**변경:** TitleScene 뒤에 게임과 같은 방(벽 `room`, 테이블 `table`, 매달린 전등 `lamp`, 빛줄기 `lamp-beam`)과 조명(전체 어둡게 + 노란 Spot Light 2D)을 놓고, 벽에 게임과 같은 출렁이는 시세 선을 흐르게 한다. 전등은 오른쪽 광대 머리 위.

**바꾸지 않을 것 / 유지 (이유):**
- U1 GameScene·판정 그대로(타이틀만)
- U2 타이틀 UI(로고·부제·목표·떨어지는 차트 선 `Graph`·광대·조작 안내·버튼) 자리·밝기 그대로(Q5·Q6·Q7)
- U3 새 그림 없음 — 게임 스프라이트 재사용(Q2), 32색·640 격자·PPU 2
- U4 광대 정지(Q6)

**사건별 알아차릴 정보:**
- 타이틀을 켰을 때: "어두운 방, 광대 위 전등 하나, 벽에 흐르는 시세" → 게임 화면과 같은 장소

**확인 – 작동:**
- C1 TitleScene에 조명 2개(전체 0.35·노랑 스포트) + 방·테이블·전등·빛줄기·시세 선 오브젝트, 재질(전등·빛줄기·시세 선 = 조명 안 받음)
- C2 캡처 밝기: 전등 아래(광대 뒤 벽·테이블)가 왼쪽 위(제목 자리)보다 밝음
- C3 시세 선이 흐름(가장 새 값이 시간에 따라 바뀜), 타이틀에서 오류 없음(`game` 없음)
- C4 제목·안내·버튼이 읽힘(캡처), Space·클릭으로 GameScene 진입, Esc 종료 그대로
- C5 GameScene 퇴행 T65~T68·T143, Console 오류 0

**확인 – 경험 (직접 보기):** 타이틀 분위기가 게임과 이어지는가, 시세 선이 로고 차트 선과 헷갈리지 않는가. "직접 확인 필요".

**확인 전:** 구현 전이라 전부 확인 전.

## Problem Statement

타이틀은 바탕색 위에 글자·선·광대만 있어서 게임 화면(어두운 방·전등·시세 선)과 다른 곳처럼 보인다. Comfy 시험(ADR 0004)으로 생성 그림은 우리 스타일과 맞지 않음을 확인했다.

## Solution

게임에서 이미 쓰는 스프라이트와 조명 설정을 TitleScene에 그대로 배치하고, 전등만 광대 위(오른쪽)로 옮긴다. 시세 선은 `ChartLinesView`를 그대로 붙여 흐르게 한다. 새 그림을 만들지 않는다.

## User Stories

1. 플레이어로서, 타이틀에서부터 게임의 어두운 방 분위기를 느끼고 싶다.
2. 플레이어로서, 제목·조작 안내·버튼이 잘 읽히길 원한다.
3. 플레이어로서, 벽의 시세가 움직여 화면이 살아 있길 원한다.
4. 개발자로서, 새 그림 없이 게임 자산을 재사용하고 싶다.
5. 개발자로서, 게임 화면은 그대로이길 원한다.

## Implementation Decisions

- **Scene (TitleScene, AI가 MCP로):** `TitleArt`(빈 부모) 아래 `Room`·`Table`·`Lamp`(+자식 `LampLight`)·`LampBeam`·`ChartLines`, `Global Light 2D`. 재질·정렬 순서는 GameScene과 같게.
- **코드:** 시세 선은 기존 `ChartLinesView` 재사용. 아래 제안 3을 고르면 짧은 코드 추가(AI 작성, 4장 예외).

### AI 제안 → 사용자 채택 (2026-11-18, 8개 모두)
1. **자리:** 방 `room`은 GameScene과 같이 화면 전체(가운데 (0, 0)). 전등 `Lamp`는 **광대 머리 위**(x = 타이틀 광대 가운데, 위 끝 y 90), `LampLight`·`LampBeam`도 같은 x로. 시세 선 `ChartLines`는 GameScene과 같은 자리(벽 위쪽 y 18~98).
2. **테이블:** 광대(UI)는 스프라이트보다 앞에 그려져 테이블 앞에 선 것처럼 보일 수 있음 → 테이블을 **아래로 내려** 뒤쪽 모서리가 광대 몸 아래 끝(약 y −55) 근처에 오게, 화면 아래에 테이블 앞부분만 보이게. 캡처로 확인 후 조정.
3. **떨어지는 칼 느낌(선택):** 타이틀에서 시세 선이 **가끔 급락**(8~12초마다 임의로 `StartSpike(−36)`). `ChartLinesView`에 칸 2개(`idleSpikeMin`·`Max`, 0이면 끔 → 게임 화면은 0이라 그대로). 게임 이름 "Falling Knife"를 타이틀에서 보여 줌.
4. **조명 값:** GameScene과 같게(전체 0.35·(0.75, 0.8, 1), 스포트 노랑 1.3·40°/100°·반지름 60/190).
5. **로고 차트 선 `Graph`와 구분:** 시세 선은 어두운 색(red1·navy2)이라 로고 선(밝은 red2)과 구분됨 — 캡처로 확인, 헷갈리면 시세 선을 로고 아래로 내림.
6. **카메라:** TitleScene 카메라가 GameScene처럼 Pixel Perfect(640×360·PPU 2)인지 확인, 아니면 같게 맞춤.
7. **시안 먼저:** Play에서 임시 배치 캡처(지금 / 적용 후) → 사용자 확인 → Scene 저장.
8. **Ticket:** 52 "타이틀에서 어두운 방과 흐르는 시세가 보인다" 하나.

## Testing Decisions

- **좋은 테스트:** 바깥 동작만 — 오브젝트·조명·재질(C1), 캡처 픽셀 밝기(C2), 시세 선 값 변화(C3), 캡처·씬 전환(C4), 퇴행(C5).
- **seam:** ① TitleScene 오브젝트 ② `ChartLinesView` 공개 값(`NewestRed`·`Spike`) ③ 캡처 ④ 씬 전환.
