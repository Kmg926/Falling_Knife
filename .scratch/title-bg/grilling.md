# Grilling: 타이틀 배경 (코드로)

> 2026-11-18. 계기: comfy-local 51 "로컬 ComfyUI 채택 안 함"(ADR 0004) 뒤 사용자 "타이틀 배경 진행". 그 전 사용자 결정: "배경에 선 움직이는 거는 claude 내부에서 처리".
> 확인한 사실: TitleScene은 화면 UI만(제목 `Logo`·부제·목표, 빨간 차트 선 `Graph`, 광대 `Clown`, 조작 안내 상자, 시작·종료 버튼, `TitleCanvas` = Screen Space Camera·거리 5), 조명 없음, 스프라이트 0개, 배경은 카메라 바탕색.
> 사용자가 **Q1~Q8 모두 채택**.

## 1라운드 (모두 채택)
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 배경 내용 | **게임과 같은 방**(벽·테이블·매달린 전등·빛줄기) | 타이틀에서 게임으로 이어지는 느낌 |
| Q2 | 만드는 방식 | 새 그림 없이 **게임 스프라이트(방·테이블·전등·빛줄기) + 조명(전체 어둡게·노란 스포트라이트)을 TitleScene에 배치**(MCP) | 게임과 똑같이 보이고, 움직이기 쉬움 |
| Q3 | 구도 | 왼쪽은 제목 자리로 어둡게, **전등을 오른쪽 광대 머리 위로** | 광대 쪽에 시선, 제목 읽힘 |
| Q4 | 테이블 | 게임 테이블 그대로(매트 포함), 화면 아래 | 새 그림 없이 |
| Q5 | 움직이는 선 | **이번에 같이**: 게임 벽 시세 선(`ChartLinesView`)을 타이틀 벽에 재사용. 떨어지는 빨간 선 `Graph`는 로고 역할이라 그대로 | 사용자 "선 움직임은 Claude 내부(코드)에서" |
| Q6 | 타이틀 광대 | 정지 그대로(clown-idle Spec U4) | 범위 작게 |
| Q7 | 글자 | UI라 조명 영향 없음, 지금 밝기 | 어두운 배경이라 대비 좋아짐 |
| Q8 | 진행 | `.scratch/title-bg/` Grilling → Spec → Ticket 52, Scene·코드는 AI가(MCP) | 지금까지와 같은 방식 |

## 범위 밖
- 전등 깜빡임, 결과·일시정지 화면 배경

## 아직 정하지 않은 것 (Spec에서)
- 전등·빛 원뿔·테이블의 정확한 자리(광대 UI 자리와 맞추기), 조명 값(게임과 같게 / 조금 다르게)
- `ChartLinesView`가 GameManager 상태(공개 끝 출렁임)에 묶여 있는지 → 타이틀에서 그대로 쓸 수 있는지
- 광대(UI)는 조명을 안 받음 → 빛 원뿔과 어울리는지 캡처로 확인
