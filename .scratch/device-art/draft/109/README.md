# 109 줄별 설명 — 폰 목록에서 확인·닫기를 없애고 칸을 키운다

> 2026-11-27, 사용자 "확인, 닫기 없애고 보유 아이템 크기를 늘리자". AI가 Scripts에 직접 씀(device-art Grilling 흐름, CLAUDE.md 4장 예외).

## PhoneView.cs (`PhoneView.before.cs` → `PhoneView.cs`)
| 줄 | 바뀐 것 | 왜 |
|---|---|---|
| `leftLabel = detail ? (clown ? "" : "사용") : "";` | 목록일 때 `"확인"` → `""` | 목록에선 칸을 누르면 상세로 가고, 초록 키·Space도 그대로라 글자가 필요 없음 |
| `rightLabel = detail ? "뒤로" : "";` | 목록일 때 `"닫기"` → `""` | 빨간 키·Esc·우클릭으로 닫힘 |
| `softLeftButton.gameObject.SetActive(leftLabel != "")` (오른쪽도) | 새 줄 | 글자가 없는데 클릭 칸이 남으면, 커진 아래 칸 줄 위에 보이지 않는 버튼이 겹쳐 칸 대신 눌림. 상세에선 다시 켜짐(튜토리얼이 "사용"을 가리킴) |
상세의 "사용·뒤로"는 그대로. 광대 폰 상세는 전처럼 왼쪽이 빈칸(이제 클릭 칸도 꺼짐).
