# device-art — Grilling (폰·모니터 그림 다듬기)

> 2026-11-27. 사용자: "폰과 모니터 스프라이트도 퀄리티 높이자. 레퍼런스 줄게. 단, 폰에 있는 아이템 갯수 보이는 기능과 진동은 반드시 유지해야 해" + 레퍼런스 10장(노키아식 바 폰·슬림 폰·블랙베리식·가죽 케이스·모토로라식 폴더폰, 베이지 CRT 모니터 4장·초록 화면 CRT 1장). 사용자 **전부 채택**.

## 지금 구조(AI 확인)
- 개수: 테이블 위 접힌 폰은 개수마다 다른 그림(`phone-table-{mine,clown}-0~4`)을 바꿔 끼움(`PhoneView.countSprites`).
- 진동: `PhoneBuzz` = 진동음 + 0.6초 좌우 ±1 흔들림 + 바깥 화면 "+N" 깜빡임(`-p1~p4`·`-blank`, 광대는 `-noise`).
- → **파일 이름·크기·화면 자리를 그대로** 두고 그림만 다시 그리면 코드 없이 두 기능 유지.
