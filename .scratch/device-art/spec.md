# device-art — Spec

> 2026-11-27. Grilling Q1~Q10 전부 채택.

## 1. 목표
폰(테이블 위 접힌 폰 2개·펼친 폰 2개)과 모니터(내 CRT·광대 모니터 뒷면) 그림을 레퍼런스 수준으로 다듬는다. **개수 표시·진동은 그대로 동작**.

## 2. 플레이어 경험
보는 것만 바뀜. 개수 숫자는 초록 LCD에 어두운 글자로 더 또렷하게. 아이템을 받으면 전처럼 폰이 울리고 "+N"이 깜빡임.

## 3. 규칙·값
게임 규칙·코드 값 변경 없음.

## 4. 화면 (지켜야 할 자리)
- 접힌 폰: 위에서 본 원본 모양(`closed_mask`)·바깥 화면 칸(`SCREEN_SRC`)·숫자 자리 그대로 → 원근 계산(`phone_on_table_rot`)을 그대로 거쳐 크기 같음.
- 펼친 폰: 200×354, 화면 `SCREEN`·키 자리(`key_rect`) 그대로.
- 내 모니터: 화면 칸(차트·"다음" 창·기준선) 화면 위치 그대로. 테두리를 키우면 Terminal·MonitorOutline 자리를 MCP로 옮김.
- 광대 모니터 뒷면: 160×80 그대로.

## 5. 코드 구조
- 그림 도구 `tools/make_art_device.py`(새, AI): 시안 A/B + 게임 합성 미리보기. 기존 `make_art_phone.py`는 바깥 화면 색만 바꿀 수 있게(기본값은 전과 같음).
- 게임 코드는 바꾸지 않을 예정(크기가 바뀌면 Scene 자리만).

## 6. 범위 밖
아이템 아이콘, 테이블·방, 폰·모니터 동작.

## 7. 확인
시안 합성 캡처 → 사용자 선택 → 게임 캡처, 개수 0~4·"+N" 깜빡임·진동 MCP, 팔레트 32색 검사.
