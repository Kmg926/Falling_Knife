# Grilling: 광대 idle 모션 (+ 광대 2배 그림)

> 2026-11-18. 계기: stock-screen·monitor-trade 완료(`38baa00`) 뒤 사용자 "광대 idle 모션 생성".
> AI가 지금 광대(`ClownView`: 평소·생각 중·어둡게 그림 3장을 바꿔 끼움, 움직임 없음, 1배 96×96)를 보고 추천과 함께 질문, 사용자가 **Q1~Q7 모두 채택**.

## 1라운드 (모두 채택)
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 어떤 움직임 | **숨쉬기**(어깨·몸 새 도트 1칸 오르내림) + **눈 깜빡임**(가끔) + 아주 가끔 **눈동자가 나를 힐끗** | 작은 움직임으로 "살아 있는" 느낌, 공포 분위기엔 힐끗 보는 눈 |
| Q2 | 만드는 방법 | **Unity Animator**: 숨쉬기 클립, 상태 3개(평소·생각 중·내 차례 어둡게), 파라미터는 `ClownView`가 넣음 | 6주차에 배운 Animator(Clip·파라미터·전환)를 기말에 직접 씀 → 면담 설명에 유리, 구조가 보임 |
| Q3 | 그림 해상도 | **art-hd Ticket 36(광대 2배)과 함께** — 192×192 새 도트로 그리면서 움직임 프레임까지 | 1배로 프레임을 만들면 36에서 다시 그려야 함 |
| Q4 | 프레임·시간 | 숨쉬기 4장 한 바퀴 **2.4초**, 깜빡임 0.12초·**3~6초마다**(규칙적으로 보이지 않게 섞음), 힐끗 15~25초마다 0.6초 | 너무 바쁘면 산만 |
| Q5 | 어디서 움직이나 | 평소·생각 중·어둡게 모두 숨쉬기·깜빡임, 결과 화면의 불 꺼진 광대는 멈춤 | 게임 중엔 늘 살아 있게 |
| Q6 | 흔들림·조명과 충돌 | 맞을 때 흔들림(광대 전체 이동)은 그대로, 어둡게(그림 교체)는 **Animator 상태로 옮김** | 같은 그림을 두 곳(코드·Animator)에서 바꾸면 서로 덮어씀 |
| Q7 | 진행 | `.scratch/clown-idle/` Grilling → Spec → Ticket, 그림은 시안부터(AI 코드 생성, #42), 코드도 AI가 작성 | 지금까지와 같은 방식 |

## 아직 정하지 않은 것 (Spec에서)
- 깜빡임·힐끗을 Animator 클립으로 할지(불규칙 간격을 어떻게), 숨쉬기와 겹치는 방법(레이어 / 눈만 따로 그림)
- 2배 광대 그림의 다듬기 정도(명암 단계, 머리카락 결, 옷 무늬)와 지금 모습(머리 모양·색) 유지 범위
- 화면에서 광대 크기·자리(지금 96×96, 모니터 뒷면이 몸 아래를 가림)
