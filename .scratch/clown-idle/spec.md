## 변경·유지·확인

**변경:** 광대 그림을 2배 세밀(192×192 새 도트)로 다시 그리고, 게임 중 광대가 **숨쉬고 눈을 깜빡이며 가끔 나를 힐끗 본다**. 그림 바꾸기는 `ClownView` 코드 대신 **Unity Animator**(상태: 평소·생각 중·어둡게)가 맡는다.

**바꾸지 않을 것 / 유지 (이유):**
- U1 판정·시간·광대 규칙 그대로(화면만)
- U2 광대 모습(머리 모양·가운데 빈 머리·색·옷 무늬)과 자리·크기(96×96 지금 좌표, 기준점 아래 가운데 (160, 100)) 그대로
- U3 생각 중 = 눈동자 위, 내 차례 = 한 단계 어둡게(ui-revamp 30), 광대 맞을 때 광대만 흔들림(#61)
- U4 결과 화면·타이틀의 광대는 정지 그림(결과 = 불 꺼진 광대 / 평소)
- U5 32색·640 격자, 그림은 AI가 코드로(#42), 코드도 AI가 작성(4장 예외)

**사건별 알아차릴 정보:**
- 평소: "광대가 살아 있다" → 느린 숨쉬기, 가끔 깜빡임
- 가끔: "광대가 나를 본다" → 눈동자가 잠깐 나를 향함(섬뜩함)
- 광대 차례: "광대가 생각한다" → 눈동자 위(그대로), 숨쉬기 계속

**확인 – 작동 (Play·MCP):**

- C2 Animator 상태가 게임 상태를 따름: 광대 생각 중 → 생각 중, 내 차례 → 어둡게, 그 밖 → 평소(그림 이름으로 확인)
- C3 숨쉬기: 4장이 2.4초에 한 바퀴, 머리는 고정·어깨 아래만 1도트 오르내림
- C4 깜빡임 3~6초마다 0.12초, 힐끗 15~25초마다 0.6초(생각 중에는 힐끗 없음), 어둡게일 때는 어두운 눈 그림
- C5 광대 흔들림(#61) 뒤 제자리, 일시정지 중 움직임 멈춤
- C6 결과 화면·타이틀 광대 정지, 글자 겹침 0

**확인 – 경험 (직접 보기):** 광대가 살아 있는 상대처럼 느껴지는가, 힐끗이 섬뜩하되 거슬리지 않는가, 숨쉬기가 산만하지 않은가. "직접 확인 필요".

**확인 전:** 구현 전이라 전부 확인 전.

## Problem Statement

광대는 그림 3장을 바꿔 끼울 뿐 가만히 서 있어서 마네킹처럼 보인다. 그림은 아직 1배 도트라 2배로 다시 그린 테이블·모니터·아이템과 도트 크기가 섞여 보인다. 이 게임의 상대인 광대가 "살아 있는 상대"로 느껴지지 않는다.

## Solution

광대를 2배 세밀하게 다시 그리면서(지금 윤곽 그대로, Scale2x 출발 + 명암·결) 숨쉬기 프레임과 눈 그림(깜빡임·힐끗)을 같이 만든다. Unity Animator 하나로 몸(숨쉬기·상태별 그림)과 눈(깜빡임·힐끗)을 두 레이어로 움직이고, `ClownView`는 Animator에 상태 값과 "지금 깜빡여" 신호만 넣는다.

## User Stories

1. 플레이어로서, 광대가 숨쉬는 걸 보고 살아 있는 상대라고 느끼고 싶다.
2. 플레이어로서, 광대가 가끔 눈을 깜빡이는 걸 보고 싶다.
3. 플레이어로서, 광대가 가끔 나를 힐끗 보는 섬뜩함을 느끼고 싶다.
4. 플레이어로서, 광대가 생각할 때·내 차례일 때 모습이 지금처럼 구분되길 원한다.
5. 플레이어로서, 광대가 테이블·모니터처럼 세밀한 그림이길 원한다.
6. 플레이어로서, 멈춘 동안 광대도 멈추길 원한다.
7. 개발자(면담 대비)로서, 수업에서 배운 Animator(Clip·파라미터·레이어·전환)로 만들어 설명하고 싶다.
8. 개발자로서, 판정이 그대로라 퇴행 테스트가 통과하길 원한다.

## Implementation Decisions

- **그림 (`tools/`, AI 작성):** 지금 광대(96×96)를 Scale2x로 192×192 출발 → 머리카락 결·얼굴 그늘(cream0)·빛(cream2)·옷 명암(navy0·navy2·red 단계) 추가. 상태 3종(평소·생각 중·어둡게) × 숨쉬기 4장 + 결과용 불 꺼진 광대 1장. 눈 덮개 그림(깜빡임·힐끗) 밝은·어두운 2벌.
- **Animator:** 새 컨트롤러 `ClownAnimator`, 파라미터 `IsThinking`(bool)·`IsLit`(bool)·`Blink`(trigger)·`Glance`(trigger). 레이어 2개(몸 / 눈). 클립은 스프라이트 바꾸기만(위치 움직임 없음 → 흔들림과 안 부딪힘).
- **`ClownView` 수정:** 그림을 직접 바꾸지 않고 Animator 파라미터만 넣음. 깜빡임·힐끗은 **임의 간격 타이머**로 trigger를 보냄(Animator만으로는 불규칙 간격이 어려움).
- **눈은 따로 그림:** 광대 아래에 자식 `Eyes`(SpriteRenderer, 광대보다 한 칸 위)를 두고 눈 영역만 덮는 그림을 띄움 → 숨쉬기 프레임과 따로 놀 수 있음(머리는 숨쉬기에서 움직이지 않으므로 자리가 맞음).
- **코드:** AI가 Scripts에 작성(4장 예외 기록), Animator·클립·Scene은 MCP로.

### AI 제안 → 사용자 채택 (2026-11-18, 9개 모두)
1. **숨쉬기 프레임:** 어깨·몸(턱 아래)만 새 도트 기준 [0, 1, 1, 0] 내려감, 4장 × 0.6초 = 2.4초. 머리·눈은 고정.
2. **눈 레이어 방식:** 광대 자식 `Eyes` 스프라이트(평소엔 빈 그림) + Animator 눈 레이어(상태 열림·깜빡임·힐끗). 어둡게일 때는 어두운 눈 그림(`IsLit`으로 나눔).
3. **깜빡임:** 눈꺼풀이 내려온 그림 1장 0.12초, 3~6초 임의 간격(가끔 두 번 연속 15%).
4. **힐끗:** 눈동자가 정면 아래(플레이어 쪽)로 0.6초, 15~25초 임의 간격, 생각 중·공개 중에는 보내지 않음.
5. **2배 그림 다듬기 범위:** 윤곽·색 배치는 지금 그대로(Scale2x), 더하는 것은 명암 단계·머리카락 결·코 반짝임·옷 줄무늬 그늘까지. 표정은 바꾸지 않음.
6. **결과 화면 불 꺼진 광대·타이틀 광대**도 같은 2배 그림으로(정지). 타이틀은 평소 그림 1번 프레임.
7. **Animator 업데이트 방식:** Normal(일시정지 `timeScale` 0이면 멈춤, C5).
8. **시안 먼저:** 2배 광대 4종 + 눈 그림을 나란히 보여 주고 사용자가 고르기/고칠 곳 지시 → 그다음 Animator.
9. **Ticket 나눔:** 45 "광대가 더 세밀해진다"(2배 그림·시안·결과·타이틀) → 46 "광대가 숨쉬고 깜빡이고 나를 본다"(숨쉬기 프레임·눈 그림·Animator·`ClownView`). 46은 45 뒤.
