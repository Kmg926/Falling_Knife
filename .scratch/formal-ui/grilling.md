# Grilling: 아트 방향 + 정식 UI (11주차, 마일스톤 ② 마지막)

> 2026-11-16. 계기: 12주차 소리·화면 반응 완료 뒤 "다음 작업 시작". 남은 일은 그림(코드 생성, ADR 0003) → 텍스트 UI를 정식 UI로 교체.
> 질문은 AI가 추천 답과 함께 묻고, 사용자가 채택·거절했다. 2라운드, Q1~Q12 **모두 채택**.

## 확인한 사실 (질문 전)
- **GDD 06장 화면**: 위 광대·잔고 / 가운데 테이블(GE코인 차트·레버리지) / 아래 행동 버튼·아이템 슬롯. 아이템 확인 중 배경 어둡게, 광대 턴 버튼 회색. 화면: 타이틀 / 플레이 / 결과.
- **GDD 08장 구현**: Table·Terminal은 SpriteRenderer, HUD는 Canvas(Image·Button·TMP), 아이템 확인은 `ItemCloseupPanel`, Main Camera는 Pixel Perfect 320×180.
- **GDD 안 화면 스케치 v2(5장, 1280×720 도트)**
  1. 타이틀: 로고, 떨어지는 빨간 그래프, 부제, 목표 한 줄, 조작 요약, Space 시작 / Esc 종료, 오른쪽 광대
  2. 플레이: 왼쪽 위 광대 잔고(동전), 오른쪽 위 `ROUND 2/3`·`내 턴`, 가운데 광대(빨간 머리·줄무늬 옷), GE코인 단말기(`남은 5`, 캔들, 공개 기록, ? 칸), 레버리지 상자(불꽃, `다음 피해 3`), 아래 내 잔고·보유(나에게)/매도(광대에게)·아이템 슬롯 1~4
  3. 아이템 확인: 가운데 패널(아이콘·이름·분류·설명 2줄·`Space 사용 Esc 취소 1~4 전환`), 배경 어둡게, 선택 슬롯 노란 테두리, "숫자키나 클릭으로 열기"
  4. 파산: 제목 + 이유 문장, 원인(라운드·행동·결과·피해·레버리지), 도달 라운드·최대 레버리지·아이템 사용 횟수·시간, 다시하기/타이틀, 광대 무표정
  5. 생존: 같은 구성, "결정타", 광대 조명 꺼져 어둡게
- **결과 기록(원인·횟수·시간)은 아직 코드에 없다.** 클릭 입력도 없다.
- **11주차 1교시 "아트 방향 메모"**(사이트 확인 2026-11-16): "아트의 Spec" — 모든 그림이 지킬 공통 규칙. 항목: 기준 이미지(파일마다 역할) / 시점 / 표현 방식(선·명암·도트 크기·머리와 몸 비율) / 색(바탕색·강조색과 역할) / 넣지 않을 것(그림 안 글자·UI 등) / 고른 시안과 버린 시안(이유) / 파일 규격(캔버스 크기·투명 여부·몸 높이·기준점, 숫자로). 확인한 것과 정하지 않은 것을 구분, 정하지 않은 것은 질문으로. 예시 위치 `.scratch/art/art-direction.md`. 이 단계에서는 이미지를 생성하지 않는다. 체크포인트: 기준 애셋 하나를 넣고 임시 도형 캡처와 나란히 비교, AI 제작 로그(목적·도구·입력·결과·판단).

## 정리 (1·2라운드 뒤, 사이트 확인)
- 2라운드 때 AI가 "아트 방향 메모 5항목"이라고 한 것은 **지난 기록에서 가져온 가정**이었다. 사이트 확인 결과 메모 항목은 위 "확인한 사실"의 7개다. Q7의 결정은 그 7개 항목의 내용(시점·색·넣지 않을 것 등)으로 옮겨 쓰고, 메모는 사이트 형식을 따른다(`.scratch/art/art-direction.md`).
- 사이트의 Comfy 경로·`Assets/Art/Drafts`·모델/프롬프트 기록은 ADR 0003(코드 생성)에 맞춰 바꿔 적는다: 시안 = `tools/` 코드 결과 PNG, "모델·프롬프트" = 만든 코드와 실행 값(seed 등). 저장 위치는 Spec에서 정한다.
- 아직 정하지 않은 것(Spec 전 질문): 시안 저장 위치, 광대 기준 크기(몸 높이 px), 기준 애셋 첫 번째로 무엇을 만들지.
