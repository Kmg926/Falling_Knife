## 1. `GameManager.cs`
| 부분 | 왜 |
|---|---|
| `IsGameOver => Player.IsBankrupt \|\| IsFinalVictory` | "한 판 끝" = 내 파산(어느 라운드든) 또는 마지막 라운드 광대 파산. 라운드 클리어(1·2라운드 광대 파산)는 끝이 아님 |
| `MaxLeverage`·`ItemUses`·`LastDamage` | 결과 화면 기록(C11). **보여 주기만** — 판정 줄에서 읽지 않는다(U1) |
| `gameStartTime`·`gameEndTime`·`PlaySeconds` | 시간 = 지금 − 시작. 끝난 순간 `gameEndTime`을 남겨 결과 화면에서 시간이 계속 늘지 않게. `-1f` = 아직 안 끝남 |
| `StartGame()` | 처음 시작(`Start`)과 다시하기(`Restart`)가 **같은 함수**로 1라운드·기록 초기화 → 둘이 어긋날 일 없음 |
| `Restart()` 조건 `!IsGameOver` | 다시하기는 결과 화면에서만. 예전 R 키 조건(`!IsRoundOver`)은 라운드 클리어 화면에서도 받았음 |
| `bool used` | 아이템을 **실제로 쓴 경우만** 센다(거래 정지 사용 불가는 제외). 아이템 개수로 세지 않는 이유: 복권이 아이템을 돌려주면 개수가 그대로라서 |
| `RecordLeverage()` | 레버리지가 오르는 두 곳(보유 상승·복권)에서 최대값 갱신. `Mathf.Max` = 둘 중 큰 값 |
| `RecordDamage(...)` | 피해 두 곳(보유 하락·매도 하락)에서. 피해 = 1 + 레버리지라서 레버리지 = 피해 − 1(0으로 돌리기 전 값). 예: `R2, 광대 매도, 하락, 피해 3 (레버리지 2)` |
| RevealRoutine의 `gameEndTime` 줄 | 판정·재장전 확인 뒤, 끝났으면 그 순간을 한 번만 기록 |

## 2. `ResultPanel.cs` (새 파일)
| 부분 | 왜 |
|---|---|
| `root.SetActive(game.IsGameOver)` | 끝났을 때만 화면 전체를 덮는다(27 패널과 같은 방식) |
| `survived` 삼항 여러 줄 | 그림 3장(바탕·상자·광대)과 글자 색을 파산/생존에 맞게 바꿈. 생존 광대는 어둡게 그린 그림(아트 메모 7-5) |
| `causeText = game.LastDamage` | 파산 = 나를 쓰러뜨린 피해(원인), 생존 = 광대를 쓰러뜨린 피해(결정타). 둘 다 "마지막 피해"라서 한 값으로 충분 |
| `reach` | 생존이면 `클리어 3/3`, 파산이면 쓰러진 라운드 |
| `Clock` | 초를 `분:초`로. `{… :00}`은 "두 자리로 채움"(3:05) |
| `titleButton.interactable = false` | TitleScene이 없으니 29 전까지 누를 수 없게 |
| 컴포넌트를 붙이는 곳 | 꺼지지 않는 `HUD`(27과 같은 이유: 꺼진 오브젝트는 Awake가 늦다) |

## 3. 나머지
- `UIManager`: 칸 `resultPanel`, `Refresh`에 한 줄. 개발용 글자 안내 문구만 바꿈.
- `RoundTurnView`: 안내 두 줄(생존·파산 + R) 삭제 → 라운드 클리어 한 줄만.
- `PlayerInputHandler`: R 관련 7줄 삭제(칸·등록·켜기·해제·끄기·함수). Restart 동작이 입력 파일에서도 사라지므로 R을 눌러도 아무 일 없음(C16).
