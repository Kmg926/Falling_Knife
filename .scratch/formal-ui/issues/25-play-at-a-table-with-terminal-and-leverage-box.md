# 25: 테이블 위 단말기에서 캔들이 그려지고, 레버리지 상자에 불꽃이 쌓인다

**What to build:** 플레이 화면 그림을 스케치 v2 배치대로 채운다: 어두운 방 배경·테이블·조명, GE코인 단말기, 레버리지 상자(불꽃 0~3), 캔들(하락·상승), 광대 "생각 중" 장면. 그림은 `tools/make_art.py` 시안 → 사용자 선택(고칠 곳은 지시하면 AI가 수정, #42). 화면 조각 `TerminalView`(남은 N, 덱을 채운 직후만 하락/상승 개수, 공개 중 캔들이 0.5초 동안 그려짐, 결과 캔들, 차트 분석으로 아는 다음 캔들은 플레이어에게만)·`LeverageView`(불꽃 수, `다음 피해 N`)와 광대 2장면 교체(IsClownThinking)를 UIManager.Refresh에서 부른다. 단말기 아래 마지막 결과 한 줄(제안 7).
