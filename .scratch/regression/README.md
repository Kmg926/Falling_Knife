# 퇴행 테스트 T65~T68·T143 (GameScene)

> 2026-11-22 정리. 예전 실행 방법(하네스 코드)은 남아 있지 않아 기록(clown-ai 10, ui-revamp 33)의 조건으로 다시 만든 절차. AI가 MCP `script_eval`로 실행한다.
> 바꾸는 값은 모두 **Play 중에만**(리플렉션) → Scene 파일은 안 바뀐다(끝나고 `isDirty` false 확인).

## 준비 (Play → 타이틀 `시작` → 시작 스토리 넘기기 뒤)
| 값 | 테스트 값 | 이유 |
|---|---|---|
| `GameManager.rounds[0].startingBalance` | 2 | 기록의 잔고(GDD 원래 값)로 짧게 끝나게 |
| `rounds[0].fixedOrder` | 테스트마다(아래) | 덱 순서 고정 |
| `CandleDeck.useFixedOrder` | true | 고정 순서 쓰기(재장전도 같은 순서) |
| `GameManager.itemsPerGrant` | 0 | 아이템이 광대 판단을 바꾸지 않게 |
| `Time.timeScale` | 4 | 빨리 |

그다음 `StartGame()`(private)을 불러 새 판. 행동은 `OpenMonitor()` → `Select(매수/매도)` → `Execute()`(Unity 창에 포커스가 없어 실제 키는 안 들어감). 단계마다 `CanPlayerAct`·`IsRoundOver`가 될 때까지 기다린다(덱 공개 연출 포함).

| 번호 | 덱 | 입력 | 기대 |
|---|---|---|---|

| T67 | D D U U U | 매수 → 기다림 → 매도 → 기다림 | 나 -1 → 광대 매수 하락(1/1) → 내 매도 상승 → 광대 매수 상승 ×2(레버리지 2) + 재장전 → 연출 뒤 광대가 이어서 매수 → "광대 -3" → 클리어(자멸) |
