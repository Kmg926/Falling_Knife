# flip-item — Spec

> 2026-11-23. Grilling(`grilling.md`) Q1~Q13 전부 채택.

## 1. 목표
다음 캔들을 반대로 바꾸는 아이템 **작전**을 더해, 차트 분석으로 알게 된 정보를 "확실한 수"로 바꾸거나 운을 뒤집는 선택지를 준다.

## 2. 플레이어 경험
- 폰 → 작전 → Space: 폰이 닫히고 가운데 판 "작전 / 다음 캔들을 뒤집었다"(알고 있었으면 "다음 캔들: 하락 → 상승"). 차례·레버리지 그대로.
- 광대가 쓰면 말풍선 "**작전**을 쓰겠다." → "흐름을 바꿨다."

## 3. 규칙
| 항목 | 값 |
|---|---|
| 효과 | 덱 맨 위 1장 하락 ↔ 상승. 덱의 하락·상승 수도 1씩 바뀜(화면 표시는 원래 없음) |
| 아는 것 | 차트 분석으로 알던 사람(나·광대 각각)은 뒤집힌 값으로 앎. 쓴 사실은 둘 다 앎 |
| 두 번 | 허용(원래대로) |
| 나오는 확률 | 무게 0.5(구제 금융과 같음) |
| 광대 판단 | ①′ 차트 분석으로 다음이 하락이고 작전이 있으면 → 작전(→ 다음 판단에서 상승을 알므로 매수). 모르면 안 씀 |
| 테스트 글자 | F |

## 4. 화면
- 아이콘(AI 코드 그림): 빨간 캔들 + 초록 캔들 + 서로 바꾸는 금색 화살표 2개. 슬롯 42×32 / 확대 68×52.
- 규칙 4쪽 "회복·기타 아이템"(배당금·구제 금융·작전). 튜토리얼 아이템 설명 한 줄. 말풍선 표 #76·77, 튜토리얼 #63.

## 5. 코드 구조
- `ItemType.Flip`(맨 뒤 — 앞 번호 그대로). `CandleDeck.FlipTop()`. `GameManager.UseFlip`·무게·글자 F·대사·결과 판 신호. `ClownAI` ①′. `ClownLine.UseFlip/FlipDone`. `LotteryPopupView` → 작전 결과도 보임(제목 칸). `TitleMenu` 4쪽 3줄. `TutorialGuide` 한 줄.
- 에셋: `Data/Items/Flip.asset`, 아이콘 2장, 아이콘 배열(슬롯·확대·규칙)에 7번째.

## 6. 확인
- C1 내가 작전: 덱 맨 위·하락/상승 수 바뀜, 차트 분석으로 알던 값 뒤집힘, 결과 판
- C2 광대: 하락을 알고 작전 → 매수(말풍선 2개)
- C3 아이콘이 슬롯·확대·광대 폰·규칙 쪽에 보임
- C4 퇴행 T65·T66, Console 오류 0
