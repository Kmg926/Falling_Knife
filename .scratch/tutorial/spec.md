# tutorial — Spec

> 2026-11-23. Grilling(`grilling.md`) Q1~Q12 전부 채택.

## 1. 목표
처음 하는 사람이 2~3분 안에 한 판의 기본(덱·매수·매도·레버리지·피해·차례·아이템)을 **직접 해 보며** 배운다. 지지 않고, 끝나면 실전으로 바로 간다.

## 2. 플레이어 경험 (순서)
타이틀 `튜토리얼`(또는 처음 `시작` 때 권유에서 "튜토리얼 먼저") → GameScene 튜토리얼 판(시작 스토리 없음) →
| 단계 | 광대 대사(대화창) | 내가 할 일 | 덱 |
|---|---|---|---|
| 0 | 인사·덱 소개 | (덱 공개 연출 보기) | 8장 하락 4·상승 4 |
| 1 | 이번 덱 개수(덱 공개 연출에서 본 것), 순서는 모름 · 모니터 소개(공개된 캔들이 그려짐, 매수·매도도 여기서) | 읽고 넘김 | |
| 2 | 매수 = 내가 들고 감, 오르면 레버리지 +1·차례 계속 | 모니터 → **매수** → 실행 | U |
| 3 | 한 번 더 매수 | **매수** | D → 나 −2(1+레버리지 1), 레버리지 0, 광대 차례 |
| 4 | 광대 차례 구경 | (광대 매도) | U → 변화 없음, 내 차례 |
| 5 | 매도 = 상대에게 넘김, 떨어지면 상대가 맞음 | **매도** | D → 광대 −1, 광대 차례 |
| 6 | 광대 차례 구경 | (광대 매수) | D → 광대 −1, 내 차례 |
| 7 | 레버리지 쌓기 | **매수** 두 번 | U, U → 레버리지 2 |
| 8 | 아이템: 폰 → 차트 분석 | 폰 → 차트 분석 → 사용 | (다음 = D, 나만 앎) |
| 9 | 알았으면 넘겨라 | **매도** | D → 광대 −3 → 0 |
| 10 | 마무리 + 다른 아이템 한 줄씩 | 읽기 | |
| 11 | "이제 진짜다." | `시작` / `타이틀` | |
- 시작 잔고 5 / 5 → 끝 3 / 0. 내 잔고는 0이 되지 않는다(각본).
- 대사 중엔 게임 입력 막힘, Space·Enter·클릭 = 다음 줄, Space 길게 = 건너뛰기(→ 타이틀). 할 일 단계엔 대화창 대신 위쪽 가운데 **할 일 한 줄** + 해야 할 곳에 **금색 테두리 깜빡임**, 그 행동만 됨.

## 3. 규칙·값
- 튜토리얼 라운드: 1라운드, 잔고 5, 덱 고정 `U D U D D U U D`, 내 아이템 차트 분석 1개, 광대 아이템 없음, 재장전 없음(덱을 다 쓰기 전에 끝남).
- 광대 행동 각본: [매도, 매수] 순서(아이템 안 씀). 각본이 끝나면 원래 광대 판단.
- 결과 화면 대신 튜토리얼 끝 화면. 라운드 표시 `TUTORIAL`.
- 처음 권유: `시작`을 처음 누를 때 한 번만(저장 `fk.tutorialAsked`).

## 4. 화면
- 대화창: 시작 스토리 대화창을 그대로 씀(이름표 탭·문장부호 멈춤·목소리 같음). 검은 화면 없이.
- 할 일 한 줄: 위쪽 가운데, 금색 작은 글.
- 강조 틀: 테두리만 있는 금색 틀(창 테두리 그림, 가운데 비움)이 대상 위에서 0.5초마다 깜빡임. 대상: 모니터 / 매수·매도 버튼 / 내 폰 / 폰 첫 칸 / 사용 버튼.
- 끝: 대화창 선택지 `▶ 시작` `타이틀`(시작 스토리의 예/아니오 자리).

## 5. 코드 구조
- `GameManager`: `IsTutorial`, `IsGuideTalking`, `IsCutscene(= 시작 스토리 || 대사 중)`, 튜토리얼 라운드·아이템·광대 각본, 허용 행동(모니터·폰·매수/매도 고정), `RevealCount`(공개가 끝날 때마다 +1). 판정은 그대로.
- `TutorialGuide`(새): 단계 진행(코루틴), 대화창·할 일·강조 틀·건너뛰기·끝 선택. 판정은 하지 않고 GameManager 상태를 읽고 허용만 바꿈.
- `CandleDeck.ForceFixedOrder`: 튜토리얼에서만 고정 순서.
- `TitleMenu`: `튜토리얼` 줄, 처음 권유. `ResultPanel`: 튜토리얼에선 안 뜸. `RoundTurnView`: `TUTORIAL`.
- `DeckRevealView`·`PhoneBuzz`: `IsIntro` → `IsCutscene`(대사 중에도 연출 미룸).

## 6. 확인
- C1 단계 0~11을 각본대로 끝까지(MCP로 행동 넣기), 잔고 5/5 → 3/0
- C2 할 일 단계에서 다른 행동(매도 고정 때 매수, 폰 단계에서 모니터) 안 됨
- C3 대사 중 입력 막힘, Space 길게 → 타이틀
- C4 끝 선택 `시작` → 시작 스토리부터 실전 / `타이틀`
- C5 타이틀 `튜토리얼` 줄, 처음 `시작` 권유 한 번만
- C6 퇴행 T65~T68(실전은 그대로), Console 오류 0
