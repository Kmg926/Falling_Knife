# 111 줄별 설명 — 튜토리얼 강조 틀을 더 세밀하게

> 2026-11-27, 사용자 "튜토리얼에서 표시해주는 테두리를 더 세밀하게 해줘". AI가 Scripts에 직접 씀(tutorial, CLAUDE.md 4장 예외).
> 전 = 굵기 1칸(화면 4px) 금색 선 4개, 0.5초마다 켜짐·꺼짐.

## TutorialGuide.cs (`TutorialGuide.before.cs` → `TutorialGuide.cs`)
| 줄 | 바뀐 것 | 왜 |
|---|---|---|
| `highlightThickness` | 지움 | 새 칸(frameLine·cornerLine)으로 나눔. 이름을 새로 지어 Scene에 저장된 옛 값(1)이 새 기본값을 덮지 않게 |
| `frameLine = 0.5` | 새 | 얇은 선: HUD 0.5칸 = 1280×720에서 2px |
| `cornerLine = 1`·`cornerLength = 6` | 새 | 모서리 꺾쇠 — 얇은 선만으론 흐릿해 보여 모서리를 또렷하게 |
| `breathe = 1.5`·`breatheSeconds = 1` | 새 | 깜빡임 대신 꺾쇠가 바깥으로 1.5칸까지 벌어졌다 돌아오는 1초 주기 |
| `shadowColor`(bg00, 알파 200) | 새 | 틀 바로 바깥 그늘 선 — 밝은 배경(모니터 테두리 등) 위에서도 금색 선이 떠 보이게 |
| `BuildEdges()` | 그늘 선 4 → 얇은 금색 선 4 → 꺾쇠 8(모서리마다 가로·세로, 기준점 = 그 모서리) | 먼저 만든 것이 뒤에 그려지므로 그늘이 맨 뒤 |
| `MakePiece()` | 새 도우미 | 그림 없는 단색 Image 하나(전과 같은 방식 — 창 테두리 그림은 안쪽이 대상을 가려서 안 씀) |
| `Point()` 크기·자리 | 크기는 1칸, 자리는 0.5칸 단위로 반올림 | 선이 화면 픽셀 사이에 걸려 흐려지지 않게 |
| `Point()` 숨쉬기 | `phase` = 사인 0~1, 꺾쇠 이동 = 0.5칸 단위로 반올림, 얇은 선 알파 0.45~0.9 | 부드럽게 움직이되 픽셀은 또렷하게 |
