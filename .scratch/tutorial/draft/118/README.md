# 118 줄별 설명 — 일시정지 창은 늘 맨 위 · "맞으면" → "잃으면"

> 2026-11-27, 사용자 "어떤 상황에서든 esc를 통한 일시정지 창이 맨 위로 올라오게 해. 그리고 튜토리얼에서 '맞으면' 레버리지... 라고 말할 때 맞으면이라는 단어가 안 어울려" → AI 질문 → "맨 위로만"(Esc의 다른 역할 — 창 닫기·시작 스토리 건너뛰기 — 은 그대로).

## GameScene (MCP)
| 대상 | 전 → 후 | 왜 |
|---|---|---|
| PauseScreen(일시정지 창) | HUD/ShakeRoot 맨 끝 → **HUD 맨 끝**(Intro·Tutorial·DamageFlash보다 뒤 = 위에 그려짐) | 같은 캔버스 안에선 뒤 형제가 위에 그려짐. 전엔 ShakeRoot 뒤의 시작 스토리·튜토리얼 대화창이 일시정지 창을 덮었음. 화면 흔들림(ShakeRoot)에선 빠짐(멈춘 화면이라 상관없음) |
코드는 안 바뀜(PausePanel은 `root`로 창을 찾으므로 부모가 바뀌어도 그대로).
