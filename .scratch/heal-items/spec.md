# Spec: 체력 회복 아이템 — 배당금(+1)·구제 금융(+2) (heal-items)

Status: ready-for-agent

> 근거: 2026-11-23 Grilling Q1~Q5·Q8(`grilling.md`). 기준: items 16~20(아이템 4종·지급·광대 규칙), item-phone 63~66(폰 칸·상세), clown-tell 80·81(말풍선), #31(복권 잔고 상한), gdd-changes #77.

## 변경·유지·확인
**변경:** 아이템 2종 추가. 배당금 = 잔고 +1, 구제 금융 = 잔고 +2(최대 = 시작 잔고). 가득이면 못 씀(아이템 남음). 지급 무게 1·1·1·1·1·0.5. 광대도 잔고 3 이하에서 씀.

**유지:** 판정 순서·다른 아이템 효과·최대 4개·폰 칸 4개·키 1~4·Esc.

**확인 – 작동:**
- C1 두 아이템이 지급되고 폰 목록·상세에 그림·이름·설명이 나옴
- C2 잔고 7 → 배당금 8 / 구제 금융 9, 잔고 9 → 구제 금융 10, 잔고 10 → 못 씀(아이템 남음, 안내 줄)
- C3 지급 비율(여러 번 뽑아 대략 1:1:1:1:1:0.5)
- C4 광대: 잔고 3 이하 + 회복 아이템 → 씀(2 이상 비면 구제 금융), 말풍선
- C5 규칙 창 아이템 쪽에 두 아이템, 글 넘침 0
- C6 퇴행 T65~T68·T143, Console 오류 0

## Problem Statement
잔고가 줄기만 해서 위기에서 버틸 방법이 복권 운뿐이다.

## Solution
잔고를 확실히 1·2 회복하는 아이템을 지급한다.

## User Stories
1. 플레이어로서, 잔고가 낮을 때 회복 아이템으로 버티고 싶다.
2. 플레이어로서, 광대도 위기에 회복하는 걸 보고 싶다.

## Implementation Decisions
- 코드(AI 작성, 4장 예외): `ItemType`(2종 추가), `GameManager`(사용·지급 무게·광대 줄 연결), `ClownAI`(③-1 회복), `ClownLine`·`ClownSpeechView`(대사), `ItemCloseupPanel`·`UIManager`(가득 안내). 그림: `tools/`. 데이터·Scene: MCP.

### AI 제안 → 사용자 채택 (2026-11-23)
1. **enum 순서:** 기존 뒤에 `Dividend`, `Bailout`(기존 번호 그대로 → 저장된 값·배열 순서 안 깨짐). 고정 지급 기호 `D` 배당금·`B` 구제 금융.
2. **아이템 데이터:** `Data/Items/Dividend.asset`·`Bailout.asset`(이름·설명·분류 "회복"), 아이콘 배열(폰 칸·상세 큰 그림·회전 그림 자리)은 6칸으로 늘림. 상세 회전 그림은 쓰지 않으므로(spin 꺼짐) 만들지 않음.
3. **그림:** 기존 작은 아이콘(`item-*.png`)·폰 칸 아이콘(`mini-*.png`)·큰 아이콘(`*-big.png`)과 같은 크기·32색. 배당금 = 금화(`gold1`·`gold2`·`goldD`) + 초록 `+`(`green2`), 구제 금융 = 동전 자루(`cream0` 자루·`gold1` 동전·`navy` 끈) + `++`.
4. **지급 무게:** 코드 상수 표(`ItemWeights`)로 — 숫자만 바꾸면 조정. 고정 지급(테스트)은 그대로 문자열 우선.
5. **규칙 창(타이틀):** 아이템 쪽이 4줄 → 6줄이라 넘치면 "규칙 3/4 · 아이템"을 두 쪽(3·4)으로 나눔(총 5쪽). 우선 6줄이 들어가는지 재 보고 넘칠 때만.
6. **광대 결과 대사:** 회복 뒤 "숨 좀 돌리지."(둘 다 같음). 가득이면 광대는 쓰지 않음(판단 단계에서 걸러짐).
7. **Ticket:** 89 지급·사용·그림·규칙 창(제안 1~5) / 90 광대(제안 6, 89 뒤).
