# Grilling: 어두운 방 + 위에서 비추는 노란 전등

> 2026-11-18. 계기: clown-idle 48 뒤 사용자 "전체적으로 어둡게 깔고 위에 조명 만들어서 아래에 노란색으로 빛 쬐게 해".
> AI가 지금 화면을 확인하고(그림은 모두 `Sprite-Lit-Default` 재질, `Global Light 2D` 하나가 밝기 1·흰색, HUD Canvas는 조명을 안 받음) 추천과 함께 질문, 사용자가 **Q1~Q8 모두 채택**.

## 1라운드 (모두 채택)
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 만드는 방법 | **Unity 2D 조명**: 전체 조명(Global Light 2D)을 낮추고, 위에서 아래로 비추는 노란 **Spot Light 2D** 추가 | 그림이 이미 조명을 받는 재질이라 새 덮개 그림 없이 됨. 숫자로 밝기·범위를 바로 조절 |
| Q2 | 얼마나 어둡게 | 전체 조명 밝기 1 → **0.35**, 색은 살짝 남색(차가운 어둠) | 빛이 닿는 곳과 아닌 곳의 대비가 분명하게, 너무 어두워 안 보이지는 않게 |
| Q3 | 조명 모양 | 화면 위 가운데(광대 머리 위)에 **매달린 전등 그림** 1개 + 아래로 퍼지는 도트 빛줄기 그림(AI가 코드로, #42) | 빛이 어디서 오는지 보여야 "전등"으로 읽힘 |
| Q4 | 어디를 비출까 | 광대·테이블 가운데·내 모니터까지 원뿔, 노란색(팔레트 gold 계열), 가장자리 부드럽게 | 판이 벌어지는 자리(광대·테이블·모니터)에 시선 모음 |
| Q5 | 화면 UI(잔고 판·아이템·글자) | **그대로 밝게** | 읽기 쉬움 우선 |
| Q6 | 스스로 빛나는 것 | 모니터 화면·캔들·벽 시세 선·레버리지 불꽃은 **어둠에 안 묻히게**(조명 안 받는 재질) | 화면·불꽃은 원래 빛을 내는 물건 |
| Q7 | 광대 어둡게(내 차례, 그림 바꾸기) | **그대로 둠**, 전등은 항상 켜짐 | 이미 있는 차례 표시와 겹치지 않게 |
| Q8 | 진행 | `.scratch/lighting/` Grilling → Spec → Ticket 49, 그림·코드·Scene은 AI가 작성(MCP) | 지금까지와 같은 방식 |
