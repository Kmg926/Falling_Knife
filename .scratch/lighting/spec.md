# Spec: 어두운 방 + 매달린 전등의 노란빛 (lighting)

Status: ready-for-agent

> 근거: 2026-11-18 Grilling Q1~Q8(모두 사용자 채택, `grilling.md`). 기준: art-hd(640 격자·PPU 2), stock-screen 40·41·47(모니터·시세 선·번쩍임), monitor-trade 43(광대 모니터), clown-idle 45~48(광대·숨쉬기·빨간 깜빡임), gdd-changes #42·#66.

## Problem Statement

지금 방은 고르게 밝아서 그림이 모두 같은 무게로 보이고, 어두운 도박판 분위기가 약하다. 빛이 어디서 오는지 보이지 않아 공간감도 없다.

## Solution

Unity 2D 조명으로 전체를 낮추고(0.35, 남색 기운), 광대 머리 위에 전등 그림을 매달아 그 자리에서 노란 Spot Light 2D가 아래를 비추게 한다. 빛줄기는 옅은 도트 그림으로 보이게 하고, 스스로 빛나는 물건(모니터 안 캔들·불꽃·시세 선 등)은 조명을 받지 않는 재질로 바꿔 어둠에 묻히지 않게 한다.

## User Stories

1. 플레이어로서, 어두운 방에서 전등 하나 아래 판이 벌어지는 분위기를 느끼고 싶다.
2. 플레이어로서, 빛이 어디서 오는지(전등) 보고 싶다.
3. 플레이어로서, 어두워도 캔들·잔고·글자는 잘 읽히길 원한다.
4. 플레이어로서, 모니터 화면·불꽃은 어둠 속에서 빛나 보이길 원한다.
5. 개발자로서, 판정이 그대로라 퇴행 테스트가 통과하길 원한다.

## Implementation Decisions

- **조명 (Scene, MCP):** `Global Light 2D` 밝기 1 → 0.35, 색 살짝 남색. 새 오브젝트 `Lamp`(전등 그림) + 자식 `LampLight`(Spot Light 2D, 노란색).
- **그림 (`tools/`, AI 작성):** 전등갓·줄, 빛줄기(옅은 도트).
- **스스로 빛나는 것:** 재질을 `Sprite-Unlit-Default`로(조명 무시).
- **코드:** 조명은 Scene 값만이라 새 코드 없음(필요해지면 AI가 작성, 4장 예외).

### AI 제안 → 사용자 채택 (2026-11-18, 8개 모두)
1. **전등 자리·모양:** 화면 위 가운데에 줄이 위 끝(y 90)에서 내려오고, 납작한 원뿔 갓(가로 약 40칸 = 80 새 도트, 높이 약 8칸)이 광대 머리카락 꼭대기(약 y 80)에 **살짝 겹치게**(갓이 광대보다 앞, 정렬 순서 위). 갓 아래 가운데에 밝은 전구 끝 몇 도트. 색은 어두운 금속(navy0·gray0) + 갓 안쪽 gold. → 머리 위 공간이 10칸뿐이라 머리카락 꼭대기를 조금 가리는 것이 가장 자연스러움.
2. **Spot Light 2D 값(처음 값):** 자리 전등 갓 아래(0, 80), 아래 방향, 안쪽 각도 40°·바깥 각도 100°, 반지름 바깥 190칸(내 모니터 아래 끝 y −88까지 닿음)·안쪽 60칸, 색 gold 계열(팔레트 `gold2`에 가까운 따뜻한 노랑), 밝기 1.3, 가장자리 부드럽게(Falloff). 캡처 보고 맞춤.
3. **빛줄기 그림:** 갓 아래에서 테이블까지 퍼지는 사다리꼴, 노란 도트를 바둑판 무늬(dither)로 듬성듬성 + 아래로 갈수록 성기게. 조명 안 받는 재질·반투명(약 20%), 광대 앞·테이블 뒤 순서. 너무 가리면 빼기 쉽게 따로 오브젝트.
4. **스스로 빛나는 것(조명 안 받음) 목록:** `ShownCandle`·`KnownCandle`·`FlashOutline`·`BaselineFlash`·`MonitorOutline`(모니터 안 화면 요소), `Flame1~3`(레버리지 불꽃), `ChartLines`(벽 시세 선 — 방 그림과 따로 있는 오브젝트라 가능). 모니터 몸체(`Terminal`)·광대 모니터 뒷면·테이블·방·광대·레버리지 상자는 조명을 받음(전등 아래라 밝음).
5. **타이틀 화면:** 이번엔 그대로(범위 밖). 결과·일시정지는 UI라 영향 없음.
6. **도트 느낌:** 조명 밝기 변화(그라데이션)는 매끄럽게 그려짐 — 도트 그림과 섞여 보이는지 캡처로 확인하고, 거슬리면 빛줄기 그림 쪽 무늬로 보완(설정 변경 없음). → Pixel Perfect의 "Upscale Render Texture"를 켜면 조명도 도트처럼 되지만 화면 전체 그리기 방식이 바뀌어 이번엔 안 씀.
7. **시안 먼저:** 전등·빛줄기 그림 + 조명 적용 캡처(지금 / 적용 후)를 나란히 보여 주고 사용자가 고르기/고칠 곳 지시 → 그다음 기록·커밋.
8. **Ticket:** 49 "어두운 방에서 전등이 판을 노랗게 비춘다"(조명·전등·빛줄기·재질 한 번에). 나눌 만큼 크지 않음.
