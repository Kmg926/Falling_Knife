# draft 83: 광대 폰과 내 폰이 같은 폰으로 보이게

> 2026-11-22. 사용자 "묘하게 광대랑 '나'의 핸드폰이 다르게 보여. 이유 찾고 수정해". 게임 코드 변경 없음 — 그림 만드는 코드(`tools/make_art_phone.py`, AI 작성 규칙)와 Scene 크기만.

## 원인
두 폰 그림을 만드는 값(`TABLE_PHONES`)이 서로 다른 "카메라"로 그려져 있었다.
| 값 | 내 폰(가까움) | 광대 폰(멂) | 문제 |
|---|---|---|---|
| `phi`(위에서 본 듯 눌린 정도, 클수록 위에서 내려다봄) | 0.8 | 0.9 | **거꾸로**: 같은 탁자면 가까운 내 폰이 더 위에서 내려다보여야 함 |
| `thick`(두께, 새 도트) | 8 | 5 | 크기 비율 1.12/0.92 = 1.22인데 두께 비율 1.6 → 내 폰만 두툼 |

## 고침 (사용자 확인 없이 AI가 고른 것 — 바꾸고 싶으면 지시)
- 비교한 시안: ① 진짜 한 카메라(같은 f = dy²/phi) `variant-same-camera.png` — 먼 광대 폰이 phi 0.58로 납작해져 숫자 "2"가 눌림(예전 기록: phi 0.6·0.75는 숫자 넘침) → 안 씀. ② **같은 모양 + 거리만큼 크기**(`variant-same-shape.png`) → 3번째 줄 채택.
- 내 폰 `phi 0.8 → 0.9`, `thick 8 → 7` / 광대 폰 `thick 5 → 6`(크기 비율 1.22 ≈ 7/6). 크기(scale)·자리·돌림(18°)은 그대로.
- 새 그림 24장(각 폰 기본·테두리·숫자 0~4·빈 화면·+1~+4) 다시 만들어 `Sprites/Phone/`에 덮어씀(32색 검사 OK). 내 폰 90×55 → 90×59, 광대 폰 74×49 → 74×50.
- Scene(MCP): `PhoneClosed` (218,−148)·45×27.5 → (218,−147)·45×29.5, 테두리 47×31.5 / `ClownPhoneClosed` 크기 37×24.5 → 37×25, 테두리 39×27. 바깥 화면 글자(`Count`)는 실행 중 꺼져 있어(숫자가 그림에 있음) 그대로.
