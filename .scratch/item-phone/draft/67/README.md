# draft/67: 폰 소프트키 글자 누르기 + 숫자 4 모양 (63·66 고침)

사용자: "휴대폰 아이템 자세히 보기 때 사용, 뒤로가 안 눌려", "폰이 아이템 '4'를 표시할 때 가독성이 별로야".

## 원인
- 화면 아래 "확인·사용" / "닫기·뒤로"는 **글자(TMP)만** 있고 버튼이 아니었다(클릭이 폰 몸체 그림에만 닿음). 아래 초록·빨간 키는 정상.
- 5×7 숫자 "4"(비스듬한 획)는 눕히고 18° 돌리면 뭉개져 보였다.

## PhoneView.cs
| 바뀐 줄 | 왜 |
|---|---|
| `softLeftButton`·`softRightButton` 칸 | 글자 자리 클릭 영역 |
| `Awake`: 왼쪽 → `game.Execute()`(Space·초록 키와 같음), 오른쪽 → `game.PhoneBack()`(Esc·빨간 키와 같음) | 목록에서는 "확인/닫기", 상세에서는 "사용/뒤로". 광대 폰 상세의 왼쪽은 Execute가 아무 일도 안 함(보기 전용) |

## Scene (MCP)
- `PhoneZoom/Body`에 `SoftLeftHit`·`SoftRightHit`(투명 그림 + Button, 글자 칸보다 사방 2 넓게, 글자 바로 뒤). 한 오브젝트에 글자와 그림을 같이 둘 수 없어서 따로 만듦.

## 그림
- `tools/make_art_phone.py`의 5×7 "4"를 위가 열린 모양(`#...#` ×3, `#####`, `....#` ×3)으로 → 두 폰 `-4`·`-p4` 다시 만듦.

## 확인
- 상세를 연 뒤 글자 가운데를 레이캐스트: `SoftLeftHit`·`SoftRightHit`이 맨 먼저 맞음. 오른쪽 클릭 → 목록으로, 왼쪽 클릭 → 아이템 사용(2 → 1개, 폰 닫힘).
- 두 폰 "4" 캡처 `four-crop.png`. Console 새 오류 0.
