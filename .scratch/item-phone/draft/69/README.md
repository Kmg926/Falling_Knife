# draft/69: 폰 상세 아이콘 뜸에 맨 위·맨 아래 0.3초 멈춤 (63 고침)

사용자: "아이템 뜨고 내려가는 것도 0.3초 정지 줘, 광대 숨쉬기 애니메이션처럼".

## ItemCloseupPanel.cs
| 바뀐 줄 | 왜 |
|---|---|
| `bobHoldSeconds = 0.3f` | 맨 위·맨 아래에서 멈추는 시간(Inspector에서 바꿀 수 있음) |
| `bob = Bob(t)` | 전에는 사인파(`Sin`)라 멈춤 없이 계속 오르내림 |
| 새 `Bob(t)` | 한 바퀴 = 올라감 0.5 → 위 멈춤 0.3 → 내려감 0.5 → 아래 멈춤 0.3 = 1.6초. 움직이는 동안은 `SmoothStep`(처음·끝이 느림)으로 −1 → +1, 도트에 맞게 반올림 |

광대 숨쉬기(clown-idle, 피크 쉼 0.4초)와 같은 "멈췄다 다시" 느낌. 컴파일 오류 0.

## 확인 (Unity 다시 켠 뒤)
- `Bob(t)` 0.1초 간격: 0.0 −1 → 0.4~0.9 +1(위 멈춤) → 1.2~1.6 −1(아래 멈춤).
- Play에서 상세를 열고 아이콘 자리를 두 번 읽음: y −11(위), −13(아래) — 실제로 오르내림. 새 Console 오류 0.

## 고침: 멈춤 0.3 → 0.5초 (사용자 "맨 위, 맨 아래 멈춤 0.5초로")
- `bobHoldSeconds` 기본값 0.5 → 한 바퀴 = 0.5 + 0.5 + 0.5 + 0.5 = 2.0초. GameScene에는 이 칸 값이 저장돼 있지 않아(파일 검색) 코드 기본값이 그대로 쓰임. 컴파일 오류 0.
