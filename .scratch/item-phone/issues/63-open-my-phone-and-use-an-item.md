# 63: 내 폰을 열어 아이템을 고르고 쓴다

**What to build:** 테이블 위 `TableItems` 자리에 접힌 내 폰(62 그림)을 두고, 바깥 화면에 아이템 개수를 보여 준다. 열 수 있을 때(내 차례 + 공개 중 아님)는 금색 테두리. 폰 클릭 = 확대된 폰(뒤 어둡게)의 목록(2×2, "아이템 N/4"), 1~4 = 그 아이템 상세(아이콘·이름·분류·설명·"Space 사용 · Esc 뒤로"). 지금 `ItemCloseupPanel` 내용을 폰 위 화면으로 옮긴다. 키패드 1~4는 칸에 아이템이 있으면 금색이고, 클릭하면 그 칸 상세. Space = 사용(상세) / 고른 칸 상세(목록), Esc = 상세 → 목록 → 닫기, 폰이 열려 있으면 A/D 무시. 모니터와 폰은 동시에 안 열린다(모니터가 열려 있을 때 1~4 → 모니터 닫고 폰 상세). 모니터에서는 아이템 칸·"아이템" 글·세로 구분선을 없애고, 차트 칸을 오른쪽 끝까지(x 48~272), 매수·매도 버튼을 가운데로(x 88·162), 캔들 자리를 가운데(x 156)로. `TableItems` 없앰. 코드는 AI가 Scripts에 직접(4장 예외), Scene은 MCP.

## 시연 순서
1. 내 차례 → 테이블 오른쪽 접힌 폰에 금색 테두리, 바깥 화면 "2"
2. 폰 클릭 → 확대된 폰 목록 → 2 키 → 상세 → Space → 아이템 사용, 결과 글
3. 1 키 → 상세 → Esc → 목록 → Esc → 닫힘
4. Space → 모니터: 차트 칸이 화면 폭 전체, 버튼 가운데
