## 변경·유지·확인

**변경:**
- 모니터 확대 화면에서 "다음 캔들은?"·조작법 줄·아이템 칸·"아이템" 글을 없애고 차트 칸을 넓힌다.
- 내 아이템은 테이블 위 **접힌 폴더폰** → 열면 확대된 폰(목록·상세·사용). 광대 아이템은 테이블 뒤 **펼쳐 세운 폴더폰**에 늘 보인다.
- 아이템을 받으면 두 폰이 진동하고 진동음이 난다. 광대가 아이템을 쓰면 광대 폰에서 그 칸이 반짝이고 사라진다.

**바꾸지 않을 것 / 유지 (이유):**
- U1 아이템 4종·효과·지급 규칙(2개씩, 최대 4개)·광대 AI 판단 그대로 — 표시만 바뀜
- U2 키: 1~4·Space·Esc·클릭 그대로(Q10). 아무것도 안 열렸을 때 Space = 모니터 열기
- U3 열 수 있는 때는 모니터와 같음: 내 차례 + 공개 중 아님(Q12)
- U4 32색·640 격자·Galmuri, UI는 조명 안 받음. 테이블 위 물건(폰)은 조명 받음(전등 빛 안)
- U5 차트 분석으로 아는 다음 캔들은 지금처럼 모니터 차트 칸에 표시

**사건별 알아차릴 정보:**
- 아이템 받음 → "몇 개 받았나": 진동·진동음 + 내 폰 바깥 화면 "+2", 광대 폰 새 칸 톡톡
- 내 폰 열 수 있음 → 모니터처럼 금색 테두리(테두리만, 깜빡임 없음)
- 광대가 아이템 씀 → "무엇을 썼나": 광대 폰 그 칸 금색 반짝 → 사라짐 + 지금처럼 결과 글

**확인 – 작동:**
- C1 모니터 확대 화면에 "다음 캔들은?"·조작법·아이템 칸·"아이템" 글 없음, 차트 칸이 넓어짐, 매수·매도 클릭·A/D·Space 그대로
- C2 내 폰: 클릭 → 목록, 1~4 → 그 아이템 상세, Space 사용, Esc 상세 → 목록 → 닫기, 모니터와 폰 동시에 안 열림
- C3 광대 차례·공개 중에는 폰 클릭·1~4 무시, 바깥 화면 개수는 늘 맞음
- C4 광대 폰 4칸 = 광대 아이템과 늘 같음, 광대 사용 칸 반짝임 뒤 사라짐
- C5 라운드 시작·재장전·복권 +1 때 진동·진동음·"+N"·NEW·톡톡, NEW는 폰을 한 번 열면 사라짐
- C6 글 넘침 0(폰 화면 상세 설명 4종 + 사용 불가 줄)
- C7 퇴행 T65~T68·T143, Console 오류 0

**확인 – 경험:** 폰을 "받는" 느낌이 나는가, 광대 폰 아이콘이 알아볼 만한가, 진동이 귀찮지 않은가. "직접 확인 필요".

**확인 전:** 구현 전이라 전부 확인 전.

## Problem Statement

아이템이 모니터 옆 작은 아이콘과 모니터 안 칸에 나뉘어 있어 "받는다"는 느낌이 없고, 받을 때 아무 신호가 없다. 모니터 확대 화면은 조작법·안내 글과 아이템 칸 때문에 차트 칸이 좁다.

## Solution

아이템을 두 사람의 **폴더폰**으로 옮긴다. 내 폰은 테이블 위에 접혀 있고 열면 확대 화면에서 고르고 쓴다. 광대 폰은 펼쳐 세워 늘 보인다. 받을 때 폰이 진동한다. 모니터는 차트와 매수·매도만 남겨 넓게 쓴다.

## User Stories

1. 플레이어로서, 아이템을 받을 때 폰이 울려서 받았다는 것을 바로 알고 싶다.
2. 플레이어로서, 내 폰을 열어 아이템을 고르고 설명을 읽고 쓰고 싶다.
3. 플레이어로서, 광대가 어떤 아이템을 가지고 있는지 늘 보고, 무엇을 썼는지 알고 싶다.
4. 플레이어로서, 모니터를 열면 차트가 넓게 보이길 원한다.
5. 키보드 플레이어로서, 1~4·Space·Esc만으로 지금처럼 아이템을 쓰고 싶다.

## Implementation Decisions

- **코드(AI 작성, 4장 예외, Grilling Q6):** 새 `PhoneView`(내 폰: 접힘·열림·목록·NEW·"+N"·진동), 새 `ClownPhoneView`(광대 폰: 4칸·톡톡·사용 반짝임·진동). `GameManager`에 폰 열림 상태(`IsPhoneOpen`, 모니터와 배타)와 "방금 받은 아이템" 신호. `ItemCloseupPanel`은 폰 화면 안으로 옮겨 그대로 씀. `ItemSlotsView`는 폰 목록으로 바꾸거나 `PhoneView`가 대신함. `PlayerInputHandler`의 1~4·Esc 순서 조정. `AudioManager`에 진동음.
- **그림·소리(AI가 `tools/` 코드로, 시안 → 사용자 선택):** `make_art_phone.py`(접힌 내 폰·확대된 펼친 폰·광대 폰), `make_art_trade.py zoom_panel` 새 배치, `make_sfx.py`에 진동음.
- **Scene(MCP):** `ZoomPrompt`·`ZoomKeys`·`ZoomItemsLabel`·`ItemSlots`·`TableItems`·`ClownItems` 끄거나 지우고, 폰 오브젝트 추가.

### AI 제안 → 사용자 채택 (2026-11-18, 8개 모두)
1. **모니터 새 배치(Ticket 61·63):** 61에서 "다음 캔들은?"·조작법 줄·키 안내 구분선(y 135)을 없애고 차트 칸을 **아래로** 늘림(y 42~90 → 42~96, 버튼은 y −102로). 63에서 아이템 칸·"아이템" 글·세로 구분선(x 199)을 없애고 차트 칸을 **오른쪽 끝까지**(x 48~272), 매수·매도 버튼은 가운데로(x 88·162). 차트 칸 캔들 자리도 가운데(x 156)로. → 61만 끝나도 아이템은 지금처럼 쓸 수 있음.
2. **내 폰(접힘) 자리·크기:** 테이블 오른쪽 앞, `TableItems` 자리(x 약 262~302, y −142~−166), 비스듬히 누운 접힌 폴더폰 약 40×24. 뚜껑 바깥 작은 화면(약 14×8)에 아이템 개수 숫자(0~4). 열 수 있을 때 금색 테두리(모니터 `MonitorOutline`과 같은 방식). 모니터의 "Space" 안내(`OpenHint`)는 그대로.
3. **확대된 내 폰:** 화면 가운데에 펼친 폴더폰 약 **150×172**(위 = 화면, 아래 = 키패드), 뒤는 모니터처럼 어둡게(`pause-dim`). 위 화면 약 130×78:
   - 목록: 2×2 칸(30×30, 지금 `slot-normal/selected` 그림 재사용) + 위에 "아이템 N/4".
   - 상세: 아이콘(돌아가는 큰 아이콘 재사용) + 이름·분류 태그 한 줄, 아래 설명(폭 약 126, 2~3줄), 맨 아래 "Space 사용 · Esc 뒤로". 지금 `ItemCloseup`의 아이콘 상자·패널 그림은 쓰지 않음.
   - 아래 키패드: 장식 + **1~4 키가 금색**(그 칸에 아이템이 있으면) — 키 번호 = 칸 번호를 눈으로. 키패드 1~4 클릭 = 그 칸 상세(마우스).
4. **광대 폰:** 광대 잔고 판 오른쪽 뒤, 테이블 뒤 모서리에 **펼쳐 세운** 폴더폰 약 32×44(x 약 90~122, y −60~−104, 아래가 테이블 모서리에 살짝 걸침). 위 화면에 2×2 아이콘(각 약 12×9, 아이템 아이콘을 작게 다시 그림). 왼쪽 위 `ClownItems` 없앰. 광대 쪽이라 화면 글자는 없음.
5. **습득 효과(Q8):** 두 폰 진동 = 0.6초 동안 0.05초마다 x ±1(테이블 위 물건) + 진동음 1개(낮은 "지잉" 0.5초, `make_sfx.py`로 후보 2~3개). 광대 폰 = 새 칸이 0.15초 간격으로 나타남(작게 → 원래 크기). 내 폰 = 바깥 화면에 "+N"을 1.2초 깜빡임 뒤 개수로 돌아감, 열면 새 칸 오른쪽 위에 작은 "N"(금색 점 글자) — 그 폰을 한 번 열면 사라짐. 라운드 시작 때는 라운드 안내와 겹치지 않게 안내가 끝난 뒤 시작.
6. **광대 사용(Q9):** 광대가 아이템을 쓸 때 광대 폰의 그 칸이 금색 테두리로 0.3초 반짝(0.1초 간격 3번) → 빈칸. 지금 광대 생각 1초 안에서 일어나게(시간 늘리지 않음).
7. **입력 순서(Q10):** 폰이 열려 있으면 A/D·←/→는 무시, Space = (상세에서) 사용 / (목록에서) 고른 칸 상세, Esc = 상세 → 목록 → 닫기. 모니터가 열린 상태에서 1~4 → 모니터 닫고 폰 상세. 폰 열린 상태에서 Space로 모니터가 열리지 않음.
8. **Ticket(5개):**
   - 61 "모니터를 열면 차트가 넓게 보인다" — 제안 1 앞부분(글·키 줄 지우기)
   - 62 "폰 그림 시안을 고른다"(ready-for-human: 그림 3개 + 진동음 후보 → 사용자 선택)
   - 63 "내 폰을 열어 아이템을 고르고 쓴다" — 62 뒤. 제안 1 뒷부분·2·3·7, `TableItems`·모니터 아이템 칸 없앰
   - 64 "광대 폰에서 광대 아이템이 보이고, 쓸 때 반짝인다" — 62 뒤. 제안 4·6, `ClownItems` 없앰
   - 65 "아이템을 받으면 폰이 울린다" — 63·64 뒤. 제안 5
