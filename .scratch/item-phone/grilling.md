# Grilling: 아이템 폰 (폴더폰으로 아이템 표시·습득 효과) + 모니터 정리

> 2026-11-18. 계기: 사용자 "아이템 표시 방식과 습득 효과를 만들고 싶어. 모니터 옆에 단순히 표시되는 게 아니라 아이템이 담긴 휴대전화 or 폴더폰을 받는 형식으로. 그리고 모니터 안에 조작법 설명과 '다음 캔들은?' 텍스트는 없애줘, 화면이 더 넓게 보이면 좋겠어."
> 확인한 사실: 내 아이템 = 테이블 위 모니터 오른쪽 아이콘(`HUD/ShakeRoot/TableItems/Item1~4`) + 모니터 확대 화면 안 4칸(`MonitorZoom/Main/ItemSlots`, `ItemSlotsView`). 광대 아이템 = 왼쪽 위 아이콘 4개(`ClownItems`, #34). 아이템 상세 화면(`ItemCloseupPanel`)은 모니터 확대 화면 안(monitor-trade 44). 모니터 글 = `ZoomPrompt`("다음 캔들은?")·`ZoomKeys`(조작법 줄)·`ZoomItemsLabel`. 지급 = 라운드 시작·재장전 때 두 사람 2개씩(`GameManager.GiveItems`), 받을 때 따로 연출 없음.
> 사용자: **Q1은 추천과 다르게 결정**(광대 아이템도 폰), 나머지 Q2~Q12 모두 채택.

## 1라운드
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 폰으로 바꿀 범위 | **내 아이템과 광대 아이템 모두 폰으로** (추천은 "내 것만, 광대는 왼쪽 위 아이콘 유지" → 사용자가 거절) | 사용자 "광대 아이템도 폰으로 보여줘" — 두 사람 같은 방식으로 |
| Q2 | 내 폰 위치·열기 | 테이블 위 모니터 오른쪽(지금 `TableItems` 자리)에 **접힌 폴더폰**. 클릭·1~4 → 화면 가운데 확대된 펼친 폰에서 고르고 씀. `TableItems`·모니터 안 `ItemSlots` 없앰 → 모니터는 차트·매수·매도만 | 아이템은 폰에서만, 모니터를 넓게 |
| Q3 | 폰 모양 | **폴더폰**: 접힘 = 바깥 작은 화면에 개수, 펼침 = 안쪽 화면에 4칸. 지금 팔레트(남색 몸체 + 금색 테두리) | 사용자 제안(폴더폰), 화면 분위기와 맞춤 |
| Q4 | 모니터 글 | "다음 캔들은?"·조작법 줄 지우고 **차트 칸을 넓힘**. 조작법은 규칙 4쪽에만 | 사용자 요청(화면을 넓게) |
| Q5 | 순서 | **모니터 정리가 첫 Ticket**, 폰은 그 뒤 Ticket들 | 폰과 상관없이 바로 할 수 있음 |
| Q6 | 만드는 방식 | 폰 그림·진동음은 AI가 `tools/` 코드로(시안 → 사용자 선택), 게임 코드는 AI가 `draft/NN` → Scripts 직접(CLAUDE.md 4장 예외), Scene은 MCP | 지금까지와 같은 방식 |

## 2라운드 (모두 채택)
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q7 | 광대 폰 | 테이블 왼쪽 뒤, 광대 잔고 판 옆에 **펼친 채 나를 향해 세움**, 화면에 광대 아이템 4칸이 늘 보임(#34 유지). 왼쪽 위 `ClownItems` 없앰 | 광대 아이템을 계속 볼 수 있게 |
| Q8 | 습득 효과 | 두 폰 **진동(좌우 ±1도트, 0.6초) + "지잉" 진동음**. 광대 폰 = 새 칸이 0.15초 간격으로 톡톡 나타남. 내 폰 = 바깥 화면 "+2" 깜빡임, 펼치면 새 칸에 "NEW"(한 번 보면 사라짐). 복권 아이템 +1도 같은 효과(1개) | "받는 형식"을 눈·귀로 |
| Q9 | 광대 아이템 사용 | 광대 폰에서 **쓰는 칸이 금색으로 0.3초 반짝이고 사라짐** | 지금은 결과 글로만 알 수 있음 |
| Q10 | 조작 | 폰 클릭 = 4칸 목록, **1~4 = 폰이 열리며 그 아이템 상세**, Space = 사용, Esc = 상세 → 목록 → 닫기. **모니터와 폰은 동시에 안 열림**. 아무것도 안 열렸을 때 Space = 모니터 열기(지금 그대로) | 지금 키 배치를 그대로 살림 |
| Q11 | 상세 화면 | `ItemCloseupPanel`(이름·분류·설명·Space 사용·Esc 뒤로)을 **폰 안쪽 화면으로 옮김** → 모니터엔 아이템 화면이 남지 않음 | 아이템은 폰에서만(Q2) |

## 아직 정하지 않은 것 (Spec에서)
- 두 폰의 정확한 크기·자리(테이블 원근, 광대 잔고 판·레버리지 상자와 겹침), 확대된 폰 크기
- 진동음 소리 모양, "+2"·NEW 글자 모양, 접힌 폰의 "열 수 있음" 표시(모니터의 금색 테두리처럼)
- 광대 폰 화면이 작을 때 아이콘 크기(4칸이 알아볼 수 있는지)
- Ticket 나누기(모니터 정리 / 폰 그림 / 내 폰 열기·사용 / 광대 폰 / 습득 효과)
