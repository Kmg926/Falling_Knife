## Problem Statement
두 폰이 같은 모양이라 어느 것이 광대 것인지 알기 어렵고, 광대 폰 확대 화면도 내 폰과 같다. 시작 스토리를 다시 볼 때 빨리 넘기는 방법이 Esc뿐이라 잘 모른다.

## Solution
광대 폰을 빨갛고 깨진, 가끔 지지직거리는 폰으로 만들고 확대 화면도 맞춘다. 시작 스토리는 Space를 길게 눌러 건너뛸 수 있고, 그 방법을 화면 구석에 보여 준다.

## User Stories
1. 플레이어로서, 탁자 위 두 폰 중 광대 것을 한눈에 알아보고 싶다.
2. 플레이어로서, 광대 폰을 열었을 때도 광대 것을 보고 있다는 걸 느끼고 싶다.
3. 다시 하는 플레이어로서, Space를 꾹 눌러 시작 스토리를 건너뛰고 싶다.
4. 오래 누르기 어려운 플레이어로서, Esc 한 번으로도 건너뛰고 싶다.

## Implementation Decisions
- **그림(AI, `tools/`):** `make_art_phone.py`에 광대 폰 색·깨짐 그림, `make_art.py`에 건너뛰기 키캡.
- **코드(AI 작성, 4장 예외):** 새 `PhoneGlitch.cs`(지지직), `PhoneView.cs`(광대 폰이면 확대 그림 바꿈), `IntroStory.cs`(길게 누르기·표시).
- **Scene(MCP):** 광대 폰에 `PhoneGlitch`, 확대 화면에 금 간 유리·글리치 그림, `HUD/Intro`에 건너뛰기 표시.

### AI 제안 → 사용자 채택 (2026-11-22, 6개 모두)
1. **광대 폰 색:** 남색 계열 → 빨강 계열로 바꿈(`navy0→red0`, `navy→red1`, `navy2→red2`, 금색 테·초록 숫자는 그대로). 테이프 = `cream0`·`gray1` 비스듬한 띠 한 줄(경첩 반대쪽 모서리), 깨진 모서리 = 왼쪽 앞 모서리 2~3도트 빠짐(`bg00`), 바깥 화면 금 = `cream2`/`gray1` 1도트 선 2~3줄(숫자 칸은 피함).
2. **지지직 그림:** 노이즈 한 장(`phone-table-clown-noise.png`: 바깥 화면에 가로줄 무늬)과 기존 빈 화면(`-blank`)을 번갈아 0.05초씩 + 그림 전체 1도트 좌우 떨림. 받는 진동(`PhoneBuzz.Busy`) 중엔 안 함.
3. **확대 화면:** `phone-open-clown.png`(빨강 몸통·키패드, 키 1개 금·1개 빠짐 — 아이템 키 1~4는 피함), `phone-crack.png`(화면 위 투명 그림, 금은 모서리 쪽), `phone-glitch.png`(가로줄 밀림 띠). 글리치 = 띠 그림 0.1초 + 화면 글자 묶음 1~2도트 가로 밀림.
4. **건너뛰기 키캡:** 픽셀 키캡 31×11(지금 좌표 기준 약 16×6 HUD) — 바깥 `gray0`·안 `bg0`·글자 "SPACE"(`cream`), 채움 = `gold1`(왼→오), 다 차면 0.1초 `gold2` 번쩍. 글자 "길게 눌러 건너뛰기" 크기 8 `cream0`. 자리: 대사 상자 오른쪽 위 바깥(HUD 약 (232, −122)).
5. **짧게 누르기 처리:** Space는 누를 때가 아니라 **뗄 때** 다음 줄(0.25초 안), Enter·클릭은 누를 때. 그래서 Space 줄 넘김이 0.25초 안쪽만큼 늦게 느껴질 수 있음.
6. **Ticket:** 84 탁자 위 광대 폰(제안 1·2) / 85 확대 화면(제안 3, 84 뒤) / 86 길게 눌러 건너뛰기(제안 4·5, 따로).
