## 줄별 설명 (면담 대비)
### GameSettings.cs
- `SfxKey "fk.sfx"`, `DefaultSfx 10`: 효과음 값을 컴퓨터에 저장(PlayerPrefs). 기본 100% → 이 기능 전과 같은 크기.
- `Sfx`: 전체·음악과 같은 모양(0~10에서 멈춤, 저장, `Changed` 알림).
- `SfxVolume`(0~1), `EffectsVolume = 전체 × 효과음`: 효과음이 실제로 들리는 크기. 음악은 전처럼 MusicPlayer가 `전체 × 음악 × 기준 0.35`.
- `GetVolume(n)`·`SetVolume(n, 값)`: 설정 창 줄 번호(0 전체, 1 효과음, 2 음악)로 읽고 쓰기 → 설정 창이 줄마다 `if`를 쓰지 않아도 됨.

### AudioManager.cs
- 시작할 때·설정이 바뀔 때 `masterVolume = EffectsVolume`(전엔 전체만). 이름은 그대로지만 뜻은 "효과음 최종 크기". 효과음·광대 목소리 모두 이 값을 곱함.

### SettingsPanel.cs
- `Rows 5`, `VolumeRows 3`: 앞 3줄이 소리 막대.
- `Change`: 소리 줄이면 `SetVolume(줄, 지금 + 방향)`, 다음 줄은 흔들림, 마지막은 전체화면.
- `PlayClick`: 값을 바꾸면 **효과음 최종 크기**로 딸깍(효과음을 줄이면 딸깍도 작아짐 = 바로 들어 보기).
- `Show`: 이름·값 5줄.
- 막 누름 판단: `pressed = 지금 눌림 && !wasDown`. Unity 입력의 `wasPressedThisFrame`이 멈춘 동안 가상 마우스 시험에서 안 잡혀서, 일시정지 메뉴와 같은 직접 비교로. `wasDown`은 창을 열 때 true로 시작 → 톱니·메뉴를 누른 그 클릭이 바로 값을 바꾸지 않음.
