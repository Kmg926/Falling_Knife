# Grilling: 체력 회복 아이템 2종 + 게임 중 설정 버튼 (heal-items · game-settings)

> 2026-11-23. 계기: 사용자 "체력 회복 아이템 만들어줘. 회복량 1, 2짜리 2개로. 그리고 인게임에 설정 버튼 만들어줘".
> 확인한 사실: "체력" = 잔고(최대 = 시작 잔고 10, `Participant.Heal`은 최대를 넘지 않음, 복권 잔고 +1도 같음 #31). 아이템 4종(`ItemType`)을 같은 확률로 무작위 지급, 최대 4개. 게임 중 일시정지 창은 계속/타이틀 두 버튼뿐(`PausePanel`), 설정 창은 타이틀 코드(`TitleMenu`) 안에만 있음(title-menu Q8에서 "일시정지 설정은 다음에"로 미뤘던 것).
> 사용자 **Q1~Q8 모두 채택**.

| Q | 질문 | 결정 |
|---|---|---|
| Q1 | 이름 | +1 **배당금** "잔고를 1 회복한다." / +2 **구제 금융** "잔고를 2 회복한다." |
| Q2 | 잔고가 가득일 때 | 쓸 수 없고 아이템은 남음(거래 정지와 같은 방식), 폰 상세에 "(잔고가 가득이라 못 쓴다)". 1만 비었으면 구제 금융도 1만 회복 |
| Q3 | 나오는 빈도 | 기존 4종 각 1, 배당금 1, 구제 금융 0.5(무게). 복권 "아이템 +1"도 같은 확률 |
| Q4 | 광대 | 잔고 3 이하면 회복 아이템 사용(2 이상 비면 구제 금융 먼저), 순서 = 차트 분석·거래 정지 다음·복권 앞. 말풍선 "**배당금**을 받지."·"**구제 금융**을 쓰지." / 결과 "숨 좀 돌리지." |
| Q5 | 그림 | `tools/` 코드: 배당금 = 금화 + 초록 "+", 구제 금융 = 동전 자루 + 초록 "++" (탁자 위 폰 칸 크기·상세 큰 크기) |
| Q6 | 설정 여는 곳 | 둘 다: 왼쪽 위 작은 톱니 버튼(일시정지 + 설정으로 바로) + 일시정지 메뉴 "설정" 줄(계속 / 설정 / 타이틀). 여는 동안 게임 멈춤 |
| Q7 | 설정 창 | 타이틀과 같은 4가지(전체 소리·음악·화면 흔들림·전체화면), 같은 창 모양·조작, 바로 반영(음악 MusicPlayer·전체 소리 효과음·흔들림 UIManager). 설정 코드를 `TitleMenu`에서 빼 공통 `SettingsPanel`로 |
| Q8 | 진행 | `.scratch/heal-items/` Ticket 89·90, `.scratch/game-settings/` Ticket 91, 코드·Scene·그림 AI, gdd-changes·asset-rights |
