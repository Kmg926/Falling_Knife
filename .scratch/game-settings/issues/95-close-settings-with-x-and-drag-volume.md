# 95: X로 설정을 닫고, 음량 막대를 눌러·끌어 맞춘다

**What to build:** 사용자 "설정에 X 버튼, 음량 조절을 클릭했을 때 해당하는 크기로, 드래그도 가능하게"(2026-11-23). 타이틀·게임 중 설정 둘 다(공통 부품 `SettingsPanel`).

- 이름 쪽·켬/끔 줄 클릭은 전과 같음(한 단계 / 켬↔끔).
