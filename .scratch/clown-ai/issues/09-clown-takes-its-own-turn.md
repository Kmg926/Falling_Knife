# 09: 내가 턴을 넘기면 광대가 남은 덱 비율로 스스로 보유·매도한다

**What to build:** 차례가 광대로 넘어가면 결과 줄 아래 `광대 생각 중...`이 0.5초(Inspector `Clown Think Seconds`) 보이고, 광대가 남은 하락 ÷ (하락 + 상승) ≥ 0.5면 매도, 아니면 보유를 고른다. `선택:` 줄에 광대 선택이 보인 뒤 기존 공개(0.5초)·판정을 그대로 탄다. 광대가 보유 → 상승이면 다시 생각하고 고른다. 광대 차례(생각·공개) 동안 A/D·Space·R은 무시된다. 광대 턴이 끝나면 플레이어 차례, `[보유]`.

**Blocked by:** 없음

**Status:** ready-for-agent

- [ ] `ClownAI.Decide`: 2/3 → 보유, 2/2 → 매도, 3/1 → 매도, 0/4 → 보유, 4/0 → 매도 (C1)
- [ ] 내가 턴을 넘기면 내 결과 문구 + `광대 생각 중...` → 광대 선택 → 공개 → 광대 결과 (C2)
- [ ] 광대 생각 중·공개 중 A/D·Space·R → 변화 없음 (C3)
- [ ] 광대 보유 → 상승이면 광대가 이어서 고른다 (C4)
- [ ] 광대 턴이 끝나면 `차례: 플레이어`, `[보유]`, 내 입력이 다시 먹힌다 (C5)

Spec: `../spec.md` (Q1~Q8) · Grilling: `../grilling.md`

## 시연 순서 (1라운드 고정 순서, 광대 행동은 규칙으로 예측)

**A. 광대 매도 한 번 — `U D U D U`** (C2, C5)
| 차례 | 남은 하락/상승 | 행동 | 캔들 | 화면 결과 |
|---|---|---|---|---|
| 나 | 2/3 | D → Space (매도) | U | `매도 → 상승! 변화 없음 (레버리지 0 그대로)` + `광대 생각 중...` |
| 광대 | 2/2 → 0.5 | **매도** | D | `매도 → 하락! 플레이어 -1`, 잔고 1/2 |
| 나 | 1/2 | — | — | `차례: 플레이어`, `[보유]` |

**B. 광대 연속 행동 — `D U U U D`** (C4, C5)
| 차례 | 남은 하락/상승 | 행동 | 캔들 | 화면 결과 |
|---|---|---|---|---|
| 나 | 2/3 | D → Space (매도) | D | `매도 → 하락! 광대 -1`, 잔고 2/1 |
| 광대 | 1/3 → 0.25 | **보유** | U | `보유 → 상승! 광대 레버리지 1, 차례 유지` |
| 광대 | 1/2 → 0.33 | **보유** | U | `… 레버리지 2, 차례 유지` |
| 광대 | 1/1 → 0.5 | **매도** | U | `매도 → 상승! 변화 없음 (레버리지 2 그대로)` |
| 나 | 1/0 | — | — | `차례: 플레이어`, `[보유]`, 레버리지 2 |

**C. 입력 무시** (C3): A의 광대 생각 중과 공개 중에 A·D·Space·R → 화면 그대로(선택 줄도 그대로), 광대 행동도 예측대로.
