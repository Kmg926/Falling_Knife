# Ticket 10 초안: 광대 턴에 라운드가 끝나거나 덱이 재장전돼도 게임이 맞게 이어진다

> 근거: `../../spec.md` (C6~C9, Q9·Q10). 구현 전 정상 버전: 커밋 `a9f0869` (09 완료)

## 1. 결론: **바꿀 코드 없음**
08과 같은 경우다. 10의 수락 기준은 09 코드에 이미 들어 있다. 10은 "**이미 되는 동작을 경계 상황에서 확인**"하는 Ticket이다.

## 2. 왜 이미 되는가 (코드에서 확인한 사실)
| 10 수락 기준 | 이미 들어 있는 곳 |
|---|---|
| C6 광대 매도로 내가 파산 → 패배, 광대 멈춤 | `RevealRoutine` 끝: `IsRoundOver`면 재장전 안 함 → `IsClownTurn`(= 광대 차례 **그리고 라운드 안 끝남**)이 false → `ClownTurnRoutine` 시작 안 함. R은 `Restart()`가 끝난 화면에서만 받음 |
| C7 광대 자멸 → 클리어/최종 승리 | `ResolveHold` 하락 → `PassTurn()`으로 차례 플레이어 → `IsRoundCleared`/`IsFinalVictory` 판정은 GameManager 그대로 |
| C8 광대 턴 재장전 → 광대 계속 | `RevealRoutine`: 판정 → (파산 아니고 덱 비면) `Reload()` → **그 뒤에** `IsClownTurn` 확인. 보유+상승이면 차례가 광대로 남아 있으므로 새 덱으로 다시 생각 |
| C9 내 매도로 광대 파산(차례 표시 광대) → Space로 다음 라운드 | `IsClownTurn`이 `!IsRoundOver`를 포함 → 광대 안 움직임. `Execute()`는 `IsRoundCleared` 확인이 `IsClownTurn` 확인보다 **앞** → `NextRound()` → `StartRound()`가 `Current = Player` |

- 09에서 `IsClownTurn`에 `&& !IsRoundOver`를 넣은 한 줄이 C6·C7·C9를 모두 막아 준다. 면담 때 설명할 핵심.

## 3. 테스트 (Ticket 10, 1라운드 고정 순서, 지금 값: 잔고 2, 덱 5장)
| # | 고정 순서 | 입력 | 기대 |
|---|---|---|---|
| T65 | `D U U D U` | D → Space, 이후 기다림 → R | 광대 보유·보유·매도 → `매도 → 하락! 플레이어 -3`, 0/1, `패배... - R로 처음부터`, 이후 `광대 생각 중...` 없음 → R → `라운드 1 / 3`, 2/2 (C6) |
| T66 | `D U D U U` | D → Space, 기다림 → Space | 광대 보유·보유 → `보유 → 하락! 광대 -2`, 2/0, `라운드 1 클리어!`, 생각 없음 → Space → `라운드 2 / 3`, `차례: 플레이어` (C7) |
| T67 | `D D U U U` | Space(보유), 기다림, D → Space, 기다림 | 나 -1 → 광대 보유 하락(1/1) → 나 매도 상승 → 광대 보유 상승 ×2 + `덱 재장전 (하락2 / 상승3)` → 광대 다시 생각, 보유 → `보유 → 하락! 광대 -3` → `라운드 1 클리어!` (C8) |
| T68 | `D U U U D` | D → Space, 기다림(09 T62와 같음) → D → Space → Space | 내 매도 → `매도 → 하락! 광대 -3`, `라운드 1 클리어!`, `차례: 광대` 표시, 생각 없음 → Space → `라운드 2 / 3`, `차례: 플레이어` (C9) |

끝나면 고정 순서 비우기 → `Use Fixed Order` 끄기 → Ctrl+S.
