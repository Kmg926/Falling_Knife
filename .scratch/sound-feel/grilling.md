# Grilling: 소리·화면 반응 (12주차) + 에셋 만드는 방식

> 2026-11-15. 계기: 12주차 "화면과 소리로 몰입 만들기". Comfy Cloud 구독 대신 AI가 코드로 그림·소리를 만들기로 사용자 결정("comfy cloud를 너가 대체할 수 있으면 결제를 하지 않고 진행" → 시험 샘플 확인 → "이 방식으로 진행").
> 질문은 AI가 추천 답과 함께 묻고, 사용자가 채택·거절했다. 2라운드, Q1~Q13 **모두 채택**.

## 확인한 사실 (질문 전)
- **강의 메인 평가 섹션 "AI는 선택 사항"**: 유료 크레디트·특정 외부 모델 필수 아님, 비AI·수작업으로 같은 기준 평가. 기말 배점: 시각·UI·사운드 일관성 10, AI 투명성·선택 근거·권리 15. 11주차는 Comfy Cloud를 수업 경로로 소개("생성에는 유료 구독이 필요") — 필수 문구는 없음.
- **Comfy Cloud**: Standard 월 $20, 해지 자유·환불 원칙적 불가, 크레딧 이월 없음, 1회 생성 비용 명시 없음, 결과물 고객 소유(ToS 2026-05-13).
- **GDD 07장**: 도트, 320×180 ×4, 16색 이내, 어두운 방·조명 하나, 광대 무표정·대사 없음. 소리 "음악 대신 낮은 저음과 시계 초침, 캔들 공개 직전 잠깐 무음, 피해 시 둔탁한 충격음". 확보: 광대·아이템·배경 "AI 생성 후 직접 보정", 효과음 6종(저음·초침·충격음·클릭·셔플) "무료 음원", 캔들·UI "직접 제작".
- **12주차**: 핵심 행동·피해 사건에 화면 반응, 상태 하나에 긴장 연출, 효과음 2개 이상(후보 3개, 직접 듣고 고르기), 소리 크기 0이면 무음 확인, 판정·시간은 바꾸지 않음.
- **시험 샘플**(`.scratch/art-sound/samples/`): numpy로 찌라시 아이콘 14×14, 캔들 2종, 충격음·초침 WAV 생성 가능 확인. 광대(캐릭터)는 품질 한계.

## 1라운드
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 순서 | ① 소리·화면 반응(12주차) → ② 아트 방향 메모·그림 → ③ 정식 UI 교체 | 소리는 지금 텍스트 UI에 바로 붙일 수 있고 이번 주와 맞음. 그림은 정식 UI와 함께여야 의미 |
| Q2 | 결정 기록 | ADR 0003(Comfy 대신 코드 생성) + gdd-changes 변경 줄 | AI 투명성·선택 근거 15점 |
| Q3 | 에셋 만드는 코드 | AI가 작성, `tools/`에 둠(게임 코드와 구분). 결과물은 사용자가 보고 듣고 고르고 그림은 직접 보정 | "게임 코드는 직접 타이핑" 규칙은 구술 면담용 게임 코드 대상. 만드는 과정을 저장소에 남김 |
| Q4 | 소리-사건 | 충격음=하락으로 잔고 감소, 초침=캔들 공개 중 1회(직전 잠깐 무음), 클릭=선택 이동·아이템 확인/취소, 셔플=재장전, 저음=배경 반복 | GDD 목록 그대로, 12주차 2개 이상 충족 |
| Q5 | 소리 크기 | Inspector 값(0~1), 설정 화면은 정식 UI 때 | 12주차 "크기 0이면 무음" 확인용 |
| Q6 | 화면 반응(텍스트 UI) | 피해: 가운데 글자 0.2초 빨갛게 깜빡임(한 번만) / 긴장: 내 잔고 3 이하면 잔고 줄 어두운 빨강. 판정·시간 불변 | 12주차 요구. 정식 UI 때 그림 쪽으로 옮김 |

## 사용자 추가 결정 (1라운드 뒤)
- **배경음악은 AI로 만들지 않는다.** "게임 OST 원본인 벅샷 룰렛 같이 노래는 인더스트리얼 다크 하우스나 좀 비틀어서 하드 테크노가 좋겠어. 내가 최대한 구해볼게. 일단은 ai 생성하지마." → Q4의 "저음 배경"은 사용자가 구해 오는 곡으로 바뀜.
- AI 안내: 원본 OST 파일은 저작권 음악 → 이용 조건 확인 필수, 이용 허락된 곡이면 출처·조건을 `docs/asset-rights.md`에 기록.

## 2라운드

| Q7 | 효과음 길이·후보 | 충격음 0.3~0.4초 / 초침 0.05~0.08초 / 클릭 0.03~0.05초 / 셔플 0.5~0.8초, 각 후보 3개. AI는 길이·앞 무음·최대 음량만 측정, **고르는 건 사용자** | 12주차 방식 |

| Q9 | 구조 | `AudioManager`(방송실)를 두고 GameManager(심판)가 사건 자리에서 한 번씩 부름. 판정 코드 불변 | GDD 구현 계획에 AudioManager |
| Q10 | 크기 칸 | 전체(0~1) + 음악(0~1). 전체 0이면 모두 무음 | 하드 테크노는 효과음보다 커서 따로 조절 |
| Q11 | 공개 중 음악 | 공개 0.5초 동안 음악을 약 20%로 줄였다가 복귀. 파일 없어도 코드는 미리 | GDD "공개 직전 잠깐 무음"을 음악 있는 상태로. 수치는 음악 들어온 뒤 조정 |
| Q12 | Ticket | **21** 사건마다 효과음(4종, 크기 0이면 무음) / **22** 피해 깜빡임·잔고 3 이하 긴장 표시 / **23** 배경음악 자리·공개 중 음악 줄이기(파일은 사용자 연결) | 23은 음악 전에도 진행 가능 |
| Q13 | GDD 변경 기록 | 변경 3줄: 효과음 무료 음원 → 코드 합성 / 그림 AI 이미지 생성 → 코드로 픽셀 지정 + 직접 보정 / 배경음 "음악 대신 저음" → 인더스트리얼 다크 하우스·하드 테크노 곡(사용자 확보) | GDD 제출본 수정 불가 |
