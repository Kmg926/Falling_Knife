## 곡 자르기 (AI, 도구 코드: `find_loop.py`·`cut_loop.py`, ffmpeg로 48kHz 디코딩)
| 조각 | 원곡 시간 | 샘플(48kHz) | 재생 |
|---|---|---|---|
| `xjj9-intro.wav` | 0 ~ 62.928초 | 3,020,533 | 게임 시작 때 한 번 |
| `xjj9-loop.wav` | 62.928 ~ 151.544초 | 4,253,581 | 끝없이 반복 |
| (안 씀) | 151.544 ~ 163.03초 | | 갑자기 끝나는 마지막 부분 |

- 찾는 법: 뒤쪽 아무 점 b 앞뒤 2초와 가장 닮은 앞쪽 점 a를 찾음 → 62.91 ↔ 151.53초 닮음 0.98(130BPM 48마디 = 88.62초 간격). 1샘플 단위로 길이를 맞추고, 점프 순간 파형 차이가 가장 작은 자리(차이 0.014, 곡 크기 0.91)로 정함 → '틱' 소리 없음.
- 원곡이 디코딩하면 1.0을 넘는 샘플이 11만 개(아주 크게 마스터링) → 그대로 자르면 찌그러짐 → 전체를 똑같이 −3.4dB(0.98/최댓값).
- 가져오기 설정: Compressed In Memory · Vorbis 70% · Preload.

## 줄별 설명 (AudioManager.cs, 면담 대비)
- `introClip`·`loopClip`·`loopSource` — 두 조각과 루프 전용 재생기(AudioSource). 칸이 비면 예전 방식 그대로.
- `PlayMusic()` (Start에서) — `AudioSettings.dspTime`은 **오디오 장치의 시계**(게임 프레임과 상관없이 샘플 단위로 정확). 인트로를 0.1초 뒤에 예약(`PlayScheduled`), 루프를 "인트로 시작 + 인트로 길이(= 샘플 수 ÷ 48000)"에 예약 → 인트로 마지막 샘플 다음에 루프 첫 샘플이 바로 나온다.
  - `Update`에서 "인트로가 끝났나?"를 보고 바꾸면 프레임(약 0.016초) 단위라 틈이 생겨 소리가 끊긴다 → 그래서 예약 방식.
- `loopSource.loop = true` — 루프 조각 끝에서 처음으로 Unity가 바로 돌아감(자른 두 끝이 원래 이어지는 소리라 자연스러움).
- `ApplyMusicVolume()` — 설정 크기·공개 중 20%가 두 재생기에 똑같이.
- Scene: `Audio`에 AudioSource 하나 추가(루프용), 원래 음악 재생기의 Play On Awake 끔(이제 코드가 틂).
