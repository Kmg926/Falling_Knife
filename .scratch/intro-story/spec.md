## Problem Statement
`시작`을 누르면 바로 판이 시작돼서 광대가 누구인지, 왜 이 판을 하는지 느낄 틈이 없다.

## Solution
GameScene 처음에 짧은 광대 대사와 "준비됐나?" 선택을 보여 주고 판을 시작한다.

## User Stories
1. 플레이어로서, 시작하자마자 광대가 말을 걸어 와서 분위기를 느끼고 싶다.
2. 플레이어로서, "준비됐나?"에 대답하고 싶다(무엇을 골라도 시작).
3. 다시 하는 플레이어로서, 대사를 Esc 한 번으로 넘기고 싶다.

## Implementation Decisions
- **코드(AI 작성, 4장 예외):** 새 `IntroStory.cs`(GameScene: 페이드·대사·선택·넘기기, 키보드·마우스를 직접 읽음 — `TitleMenu`와 같은 방식), `GameManager.cs`(`IsIntro` + 입력 무시 조건에 추가, `EndIntro()`), `DeckRevealView.cs`(시네마틱 중엔 연출 시작 미룸), `TitleMenu.cs`(시작 = 0.5초 어두워짐 → 시네마틱 켜고 Scene 전환).
- **Scene(MCP):** GameScene `/HUD/Intro`(검정·대사 상자·이름·대사·▼·예/아니오), TitleScene `Fade`(검정).

### AI 제안 → 사용자 채택 (2026-11-22, 6개 모두)
1. **숨길 게임 UI:** 글자 정보만 — `HudBar`·잔고 2개·`RoundTurn`·`TurnBanner`·레버리지 글자·`NextDamage`. 테이블 위 폰·모니터는 탁자 물건이라 그대로 보임.
2. **덱 공개 연출:** 시네마틱이 끝난 뒤 시작(지금 라운드 시작 연출을 그대로).
3. **에디터에서 GameScene을 바로 Play:** 시네마틱 없음(테스트 편하게). Inspector 칸 `Play In Editor Without Title`로 켤 수 있음.
4. **글자 소리:** 클릭음 30% 크기, 2글자마다 한 번(빈칸 제외).
5. **대사 상자 크기·자리:** 화면 아래 약 300×44(HUD 단위), 대사 글자 크기 11(메뉴와 같음).
6. **Ticket:** 77 페이드·대사·넘기기(+타이틀 어두워짐) / 78 "준비됐나?" 예·아니오(77 뒤).
