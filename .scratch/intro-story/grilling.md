# Grilling: 시작 스토리 시네마틱 (intro-story)

> 2026-11-22. 계기: 사용자 "게임 시작 누르면 페이드 인 되면서 간단한 스토리 시네마틱 만들자. 광대가 너도 나도 잃을게 없으니 여기 있다는 식으로 말을 시작하는거야".
> 확인한 사실: 타이틀 `시작` = `SceneManager.LoadScene` 바로(`TitleMenu.Choose`). 다시하기(`GameManager.Restart`)는 Scene을 다시 열지 않고 `StartGame`만 부름. 라운드 시작 덱 공개 연출 = `DeckRevealView` + `GameManager.Begin/EndPresentation`. GameScene HUD = `/HUD/ShakeRoot/…`(잔고·라운드·폰·모니터 버튼 등).
> 사용자 **Q1~Q10 채택**(Q3는 5번 줄만 수정).

## 1라운드
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 어디서 | **GameScene 안**: 검은 화면 → 페이드 인 → 광대가 앉은 탁자 → 대사 → 바로 1라운드 | 광대 그림·숨쉬기 재사용, Scene 전환 1번 줄임 |
| Q2 | 언제 | 타이틀 `시작`마다, **다시하기 때는 안 나옴** | 넘기기 있음(Q4) |
| Q3 | 대사 | ① "……또 한 명 왔네." ② "너도 나도 더 잃을 게 없으니까 여기 앉아 있는 거겠지." ③ "규칙은 간단해. 다음 캔들을 들고 있을지, 나한테 넘길지." ④ "떨어지는 칼은 잡는 게 아니야. 남한테 넘기는 거지." ⑤ **"준비됐나?" → 예/아니오, 아니오여도 시작** | 사용자 수정(5번) |
| Q4 | 방식·조작 | 검정 → 1초 페이드 인, 아래 대사 상자, 한 글자씩(0.03초), 클릭음 작게, 광대는 평소 숨쉬기·깜빡임, Space·Enter·클릭 = 다음(나오는 중이면 줄 전체), Esc = 전체 넘기기, 시네마틱 동안 게임 UI 숨김 | |
| Q5 | 타이틀에서 | 0.5초 검게 어두워진 뒤 GameScene | 검정 → 페이드 인이 이어짐 |
| Q6 | 배경음악 | 그대로 | 곡 연결 전 |
| Q7 | 진행 | `.scratch/intro-story/` Grilling → Spec → Ticket, 코드·Scene은 AI(MCP), gdd-changes 기록 | 지금까지와 같음 |

## 2라운드
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q8 | 고른 뒤 대답 | 예 → "좋아. 시작하자." / 아니오 → "상관없어. 칼은 이미 떨어지고 있거든." → 그 줄 끝나면 바로 1라운드 | 아니오여도 시작된다는 느낌 |
| Q9 | 선택지 | 대사 상자 안 오른쪽 아래 `예` / `아니오`, 고른 쪽 금색 + ▶, ←/→·A/D·↑/↓·W/S 이동, Space·Enter·클릭 선택, 마우스 올리면 선택, 처음 `예`, Esc = "예"(바로 시작) | 타이틀 메뉴와 같은 느낌 |
| Q10 | 상자 모양 | 화면 아래 폭 전체 어두운 상자, 왼쪽 위 "광대" 금색, 새 그림 없이 규칙 창과 같은 창 그림 | 새 그림 안 만듦 |
