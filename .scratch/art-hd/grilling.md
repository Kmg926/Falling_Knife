# Grilling: 테이블 위 동전 · 아트 화소 2배

> 2026-11-17. 계기: ui-revamp 30~33 완료(`725efc0`) 뒤 사용자 "체력을 동전으로 한 건 좋은데 그게 각자의 테이블 위에 올려놓은 것 처럼 생겼으면 좋겠어. 테이블 스프라이트 변경 고려해봐. 그리고 아트워크 퀄리티 높여줘(화소를 높인 것 처럼)".
> AI가 지금 화면(캡처 `.scratch/art/captures/30-table-glance.png`)·`tools/make_art.py`·아트 메모 7절을 보고 추천과 함께 질문, 사용자가 **Q1~Q7 모두 채택**.

## 지금 화면에서 본 문제
- 광대 동전은 테이블 면에 평평한 원 10개, 내 동전은 아래 띠(HUD)에 있음 → "테이블 위 물건"으로 안 보임
- 테이블 = 갈색 사다리꼴 320×41 + 나뭇결 선 4개, 앞 모서리 두께·구역 없음
- 전체 320×180 도트·16색 → 명암 단계가 부족해 평면적

## 1라운드 (모두 채택)
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 화소를 높이는 방법 | **그림만 2배(640×360 도트)**: Pixel Perfect Camera 기준 해상도 640×360, 그림 PPU 2. 글자·버튼 Canvas(320×180 기준)와 UI 좌표는 그대로 | 세밀함 2배, UI 위치 다시 잡을 필요 없음. 320×180에서 다듬기만은 효과가 작고, UI까지 640은 작업량이 큼 |
| Q2 | 도트 크기 섞기 | **섞지 않음**: 월드 그림(방·테이블·광대·캔들·아이템)을 모두 2배로 다시 그림 | 큰 도트·작은 도트가 섞이면 싸구려처럼 보임 |
| Q3 | 팔레트 | **16색 → 32색** (색마다 밝은·어두운 단계 추가) | 2배 해상도에서는 명암 단계가 있어야 입체감 |
| Q4 | 동전 자리 | 각자 앞 테이블 위: **내 것 = 테이블 가까운 쪽 왼쪽**, **광대 것 = 광대 앞 먼 쪽** | "각자 테이블 위에 올려놓은 것"(사용자 요청) |
| Q5 | 동전 모양 | **동전 탑 2줄 × 5개**(윗면 타원 + 옆면 두께), 잃으면 위 동전이 떨어짐, 숫자 `3/10`은 탑 옆에 작게 유지 | 디에제틱 + 읽기 쉬움(ui-revamp Q6) |
| Q6 | 테이블 | 원근 사다리꼴을 아래 띠 위까지 넓힘, 나뭇결·앞 모서리 두께, **각자 자리에 가죽 매트(구역)**, 단말기는 테이블 위 물건 | "각자 테이블" 느낌을 매트로 |
| Q7 | 진행 순서 | **시안 1장 먼저**(테이블·동전만 2배로 그린 정지 화면) → 사용자가 고름 → 광대·방·캔들·아이템 순서로 다시 그림 | 큰 작업이라 방향부터 확인. 그림은 AI 코드 생성(gdd-changes #42) |

## 아직 정하지 않은 것 (Spec에서)
- 내 동전이 테이블로 가면서 비는 아래 띠 왼쪽 공간에 무엇을 둘지(버튼·슬롯 재배치 여부)
- 32색 팔레트의 실제 색(시안 단계에서 만들고 고름)
- 도트 2배일 때 움직임(흔들림 2도트·눌림 1도트·동전 떨어짐 8도트)을 새 도트로 볼지 지금 도트로 볼지
