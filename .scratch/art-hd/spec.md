## 변경·유지·확인

**변경:** 두 사람의 잔고 동전을 각자 앞 테이블 위 **동전 탑**으로 옮기고, 테이블을 원근·두께·가죽 매트(각자 자리)가 있는 그림으로 바꾼다. 그림 전체를 **640×360 도트(지금의 2배 세밀)**와 **32색**으로 다시 그린다. 화면 크기 1280×720, 글자·버튼 위치(Canvas 320×180 기준)는 그대로다.

**바꾸지 않을 것 / 유지 (이유):**
- U1 판정·처리 순서·잔고·레버리지·덱·아이템·광대 규칙·시간 그대로 (그림만)
- U2 Canvas 기준 320×180과 UI 좌표 그대로 (Q1: 위치 다시 잡지 않음). 월드 좌표 단위도 그대로(1단위 = 지금 도트 1개 = 새 도트 2개)
- U3 개수 공개·순서 숨김, 덱 공개 연출·회전 아이템·흔들림·눌림 등 ui-revamp 연출 동작 그대로
- U4 그림 안 글자 없음, 반투명 대신 바둑판 점, 그림은 AI가 코드로(#42), 사용자는 시안을 고르고 말로 지시
- U5 잔고 숫자(`3/10`)는 탑 옆에 작게 유지 (읽기 쉬움, ui-revamp Q6)
- U6 흔들림 끄기(`Screen Shake`) 유지

**사건별 알아차릴 정보:**
- 잔고: "각자 테이블 앞에 돈이 얼마 쌓여 있나" → 내 탑은 가까이, 광대 탑은 광대 앞
- 피해: "내(광대) 돈이 줄었다" → 그 사람 탑 맨 위 동전이 떨어짐 + 흔들림

**확인 – 작동 (Play·MCP·검사 도구):**
- C1 모든 그림이 같은 도트 크기(640×360 격자) — 2배로 늘린 옛 그림이 남아 있지 않음 (Q2)
- C2 모든 그림이 32색 팔레트 안 (`make_art.py check`)
- C3 Pixel Perfect Camera 640×360·PPU 2, 1280×720에서 정수 배(2배), 흐림 없음
- C4 동전 탑: 잔고 n = 탑에 보이는 동전 n개(최대 10), 0~10 모든 값에서 모양이 맞음, 3 이하 빨강 규칙 유지
- C5 피해 때 떨어지는 동전 = 줄어든 수, 탑 **위에서부터** 사라짐
- C6 글자 겹침 0, 최소 크기 9, 글자와 탑·매트·단말기 겹침 0
- C7 퇴행: T65~T68·T143, ui-revamp T190~T202 핵심(덱 공개 개수, 회전 8장, 흔들림 제자리, 눌림), Console 오류 0

**확인 – 경험 (직접 보기):** 동전이 "각자 테이블 위에 놓인 것"처럼 보이는가, 화소가 높아진 느낌인가, 글자(큰 도트)와 그림(작은 도트)이 어색하지 않은가. "직접 확인 필요".

**확인 전:** 구현 전이라 전부 확인 전.

## Problem Statement

잔고를 동전으로 보여 주는 건 좋지만, 광대 동전은 테이블에 평평하게 붙은 원이고 내 동전은 아래 띠(HUD)에 있어서 "각자 앞에 놓인 돈"으로 보이지 않는다. 테이블은 갈색 사다리꼴 하나라 자리 구분이 없다. 그림 전체가 320×180·16색이라 명암 단계가 적어 평면적이고, 결과적으로 아트 퀄리티가 낮아 보인다.

## Solution

테이블을 다시 그려 각자 자리(가죽 매트)를 만들고, 동전을 그 위에 쌓은 탑으로 보여 준다. 카메라 기준 해상도를 640×360으로 올려 그림을 2배 세밀하게 그리되, 월드 좌표·Canvas 좌표는 그대로 두어 코드·배치 변경을 최소로 한다. 팔레트는 지금 16색에 밝은·어두운 단계 16색을 더한 32색으로 늘린다. 먼저 테이블·동전만 그린 **시안 정지 화면**으로 방향을 고른 뒤(Q7), 광대 → 방·캔들·단말기 → HUD·아이템 순서로 다시 그린다.

## User Stories

1. 플레이어로서, 내 돈이 내 앞 테이블 위에 쌓여 있는 걸 보고 싶다.
2. 플레이어로서, 광대 돈이 광대 앞에 따로 쌓여 있어 누구 돈인지 바로 알고 싶다.
3. 플레이어로서, 돈을 잃으면 내 탑 맨 위 동전이 떨어지는 걸 보고 싶다.
4. 플레이어로서, 그림이 더 세밀하고 입체적으로 보이길 원한다.
5. 플레이어로서, 숫자도 같이 보여 정확한 잔고를 알고 싶다.
6. 사용자(아트 결정자)로서, 크게 다시 그리기 전에 시안 몇 개를 보고 고르고 싶다.
7. 개발자로서, UI 좌표를 다시 잡지 않고 그림만 바꾸고 싶다.
8. 개발자(면담 대비)로서, 바뀐 코드가 적고 설명하기 쉽길 원한다.

## Implementation Decisions

- **해상도 (Q1):** Pixel Perfect Camera Reference Resolution 640×360, Assets PPU 2. 모든 그림 PPU 2·Point·압축 없음. 월드 좌표 단위는 그대로 → SpriteRenderer 위치·Canvas 좌표 변경 없음. Canvas 위 Image는 크기(RectTransform)를 지금과 같은 값으로 고정(그림 픽셀 ÷ 2).
- **팔레트 (Q3):** `tools/palette.txt` 32색 = 지금 16색 + 새 16색(밝은·어두운 단계). 옛 16색을 그대로 두므로 바꾸는 도중에도 옛 그림이 팔레트 검사를 통과.
- **그리기 방식 (`tools/make_art.py`, AI 작성):** 아래 "AI 제안 8" 참고. 명령 이름은 `hd-*`.
- **테이블 (Q6):** 원근 사다리꼴, 나뭇결, 앞 모서리 두께(옆면 한 단계 어둡게), 광대 쪽·내 쪽 가죽 매트 2개. 단말기·레버리지 상자는 테이블 위 물건(그림자 1줄).
- **동전 탑 (Q4·Q5):** 동전 1개 = 윗면 타원 + 옆면 두께. 2줄 × 5개. 내 탑은 테이블 가까운 쪽 왼쪽, 광대 탑은 광대 앞 먼 쪽(원근 때문에 조금 작게). 자리 좌표는 시안에서 정함.
- **`BalanceView` 수정:** 동전 칸(Image 10개)을 탑 모양 자리로 배치, 그림 교체(`coin-on/danger/off` → 탑 동전 그림). "줄어든 칸 = 위에서부터"가 되도록 칸 순서를 아래→위로. 떨어짐 움직임은 그대로 재사용. 내 잔고 칸은 아래 띠에서 테이블 위로 옮김.
- **코드:** AI가 Scripts에 작성(4장 예외 기록, Grilling Q8 방식 이어서). Scene·가져오기 설정은 AI가 MCP로.

### AI 제안 → 사용자 채택 (2026-11-17, 8개 모두)
1. **Canvas 그림도 2배:** 버튼·슬롯·단말기 틀·아이콘·패널 같은 Canvas Image도 같이 2배로 다시 그림(Q2 "섞지 않음"을 HUD까지). 위치·크기는 그대로.
2. **글자는 그대로:** Galmuri11 크기 9~11 유지. 글자 도트(4px)가 그림 도트(2px)보다 굵어지지만, 읽기 쉬움이 먼저. 시안에서 어색한지 직접 봄.
3. **팔레트 = 옛 16 + 새 16:** 새 색은 wood·red·navy·gold·cream·green·orange의 밝은/어두운 단계와 그림자용 어두운 색. 시안과 함께 색표를 보여 줌.
4. **움직임 거리는 지금 단위 그대로**(흔들림 2 = 새 도트 4, 눌림 1 = 새 도트 2, 동전 8 = 새 도트 16). 대신 `Tween`의 반올림을 0.5 단위(새 도트 1개)로 바꿔 더 부드럽게.
5. **시안 3개(정지 화면 1280×720, 게임 코드 변경 없음):**
   - A: 광대 탑 = 광대 앞 왼쪽 먼 곳, 내 탑 = 가까운 쪽 왼쪽 (둘 다 단말기 왼쪽, 앞뒤로)
   - B: 광대 탑 = 광대 앞 오른쪽 먼 곳(레버리지 위), 내 탑 = 가까운 쪽 왼쪽 (대각선)
   - C: 테이블을 아래로 넓히고 아래 띠를 낮춰, 내 탑을 버튼 바로 위 가까운 가장자리에
   → 사용자가 하나를 고르고 말로 고칠 곳 지시.
6. **비는 아래 띠 왼쪽:** 고른 시안에 맞춰 정함(버튼을 왼쪽으로 옮기거나 띠를 줄임). 시안에 같이 그림.
7. **Ticket 나눔(Q7 순서):** 34 시안 3개·색표(그림만) → 35 해상도·팔레트·테이블·동전 탑을 게임에 → 36 광대(평소·생각·어둡게·꺼짐) → 37 방·캔들·뒷면·단말기·레버리지·불꽃 → 38 HUD·아이콘·확인 패널·회전 32장 → 39 결과·타이틀·일시정지. 35~39 사이에는 옛 도트와 새 도트가 잠깐 섞이고, 39에서 C1로 모두 확인.
8. **그리는 방법:** 옛 그림을 그냥 늘리면(최근접 2배) 화소가 높아지지 않음. **Scale2x(EPX)로 대각선을 다듬어 출발점으로 쓰고**(팔레트 밖 색을 만들지 않는 방법) 그 위에 명암 단계·가장자리 빛·질감(나뭇결·가죽·천)을 코드로 더함. 테이블·동전처럼 새 물건은 처음부터 640 격자로 그림.
