## 줄별 핵심
| 부분 | 왜 |
|---|---|
| `coins[0~4]` = 왼쪽 탑 아래→위, `[5~9]` = 오른쪽 탑 아래→위 | 판정 코드는 "잔고 n이면 앞에서 n칸 켜기" 그대로. **칸 순서만** 탑 모양으로 놓으면 줄어들 때 오른쪽 탑 맨 위부터 사라진다(배열 뒤쪽이 먼저 꺼지므로) |
| `towerSize = 5` | 탑 하나 높이. `i % towerSize == 0` = 탑 맨 아래 칸 |
| `enabled = i < StartingBalance && (have \|\| towerBottom)` | 탑에서 빠진 동전은 그 자리에 아무것도 없어야 자연스럽다 → 끔. 단, 탑이 통째로 비면 "여기 내 탑 자리였다"를 보이게 맨 아래 칸만 점선 고리(`coinOff`) |
| `sprite = have ? (danger ? coinDanger : coinOn) : coinOff` | 3 이하 빨강 규칙(Ticket 22) 그대로 |
| `wasDanger` | 떨어지는 동전은 **잃기 전** 모습. 빨강 탑에서 금색 동전이 떨어지면 어색해서 |
| `falling.enabled = true` | 원래 칸을 이미 꺼 둔 뒤 복사하므로 복사본도 꺼져 있다 → 켠다 |
| `dropSide = 6` | 탑 위에서 그대로 아래로 떨어지면 아래 동전들을 **뚫고** 내려가 보인다 → 옆으로 미끄러지며 떨어지게 |
| `Tween`의 `Dot = 0.5f` | 카메라가 640×360(PPU 2)이 되어 1단위 = 새 도트 2개. 0.5로 반올림하면 움직임이 한 칸씩 더 촘촘해지고, 여전히 도트 격자에 맞아 흐려지지 않는다(제안 4). 흔들림 2·눌림 1·떨어짐 8 같은 **거리 값은 그대로** |
