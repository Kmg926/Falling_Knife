## 변경·유지·확인

**변경:** 화면 아래 띠(보유·매도 버튼, 아이템 슬롯)를 없앤다. 내 차례에 테이블 위 모니터를 클릭(또는 Space)하면 모니터 화면이 크게 열리고, 그 안에서 **매수·매도**를 고르거나 아이템을 쓴다. 고르면 화면이 닫히고 캔들이 모니터에서 자동으로 공개된다. "보유"는 모든 곳에서 "매수"로 바꾼다. 캔들 개수·구성을 숫자·글자로 알려 주지 않고(덱을 채울 때도 캔들 색만), 복권 당첨 내용은 글자로 알리지 않는다.

**바꾸지 않을 것 / 유지 (이유):**
- U1 판정·처리 순서·잔고·레버리지·덱·아이템 효과·광대 규칙 그대로. **결정한 뒤 공개**(Grilling Q1)
- U2 공개 시간 `Reveal Seconds`, 광대 생각 1초, 덱 공개 연출 시간·Space 건너뛰기 그대로
- U3 순서 숨김, 공개 기록 없음(#39·40)
- U4 키보드만으로도 플레이 가능(Q7)
- U5 체력(동전) 표현은 이번 범위 밖(Q8, 나중에 결정)
- U6 32색·640 격자·그림 안 글자 없음, 그림·코드는 AI가 작성(4장 예외)

**사건별 알아차릴 정보:**
- 내 차례: "모니터를 들여다볼 수 있다" → 모니터 테두리가 금색으로 빛남
- 모니터 열림: "무엇을 할까" → 매수·매도 버튼과 내 아이템
- 결정: "가격이 움직인다" → 화면이 닫히고 모니터에서 캔들이 자람
- 덱 채움: "이번 덱의 캔들" → 색만 늘어놓았다가 섞임(숫자 없음)

**확인 – 작동 (Play·MCP):**
- C1 내 차례(입력 가능)일 때만 모니터 클릭·Space로 열림, 광대 차례·공개 중·덱 공개 중·일시정지·결과 화면에서는 안 열림
- C2 열린 화면에서 매수/매도를 고르면(클릭, A/D + Space) 닫히고 공개 → 판정 결과가 지금과 같음(퇴행 T65~T68)
- C3 열린 화면에서 아이템 고르기(클릭, 1~4) → 상세(회전 그림·이름·분류·설명) → 사용/뒤로, 효과가 지금과 같음, Esc = 뒤로/닫기
- C4 화면 어디에도 개수·구성 글자 없음(`남은`, `하락n`, `상승n` 검색 0), 덱 공개 연출에 글자 없음
- C5 복권 결과 글자 = `…: 복권 사용`(당첨 내용 없음)
- C6 화면 글자·결과 문장에 "보유" 0개, "매수" 사용. 코드 `PlayerAction.Buy`
- C7 아래 띠·버튼·슬롯 없음, 글자 겹침 0, 최소 크기 9, 새 그림 32색·PPU 2
- C8 퇴행: T65~T68·T143(이름만 매수로), 일시정지·결과 화면·타이틀, Console 오류 0

**확인 – 경험 (직접 플레이):** 모니터를 들여다보는 느낌이 드는가, 한 번 더 클릭해야 해서 답답하지 않은가, 숫자 없이 캔들 색만으로 기억하는 게 재미있는가. "직접 확인 필요".

**확인 전:** 구현 전이라 전부 확인 전.

## Problem Statement

화면 아래 띠의 버튼·슬롯이 화면을 차지하고, 행동이 "버튼 누르기"라 테이블 위 모니터와 따로 논다. "보유"와 "매도"는 짝이 맞지 않는 말이다. 남은 개수·구성 숫자가 늘 보여서 기억할 거리가 없고, 복권은 당첨 내용을 글자로 바로 알려 준다.

## Solution

모니터를 거래 단말기로 만든다: 내 차례에 모니터를 열어(확대) 매수·매도·아이템을 고르고, 닫히면서 캔들이 공개된다. 아래 띠를 없애 테이블을 넓히고, 내 아이템은 평소 모니터 앞 테이블 위 작은 아이콘으로 보인다. 말은 매수·매도로 통일하고, 개수·복권 결과는 글자로 알리지 않는다. 판정 코드는 이름만 바꾸고 동작은 그대로 둔다.

## User Stories

1. 플레이어로서, 내 차례에 모니터를 클릭해 화면을 들여다보고 싶다.
2. 플레이어로서, 들여다본 화면에서 매수 또는 매도를 고르고 싶다.
3. 플레이어로서, 고르면 화면이 닫히고 모니터에서 캔들이 오르내리는 걸 보고 싶다.
4. 플레이어로서, 아이템도 모니터 안에서 골라 자세히 보고 쓰고 싶다.
5. 플레이어로서, 화면 아래 버튼 없이 테이블 전체를 보고 싶다.
6. 플레이어로서, 매수·매도처럼 짝이 맞는 말을 쓰고 싶다.
7. 플레이어로서, 덱의 캔들을 숫자가 아니라 색으로 보고 기억하고 싶다.
8. 플레이어로서, 복권은 결과 글자 대신 바뀐 잔고·레버리지·아이템으로 알아차리고 싶다.
9. 키보드 플레이어로서, Space·A/D·1~4·Esc로 똑같이 하고 싶다.
10. 개발자로서, 판정이 그대로라 퇴행 테스트가 이름만 바꿔 통과하길 원한다.

## Implementation Decisions

- **이름 바꾸기:** `PlayerAction.Hold` → `Buy`, 결과 문장 `보유 → …` → `매수 → …`, 화면 글자, GLOSSARY "보유" 항목 → "매수". ClownAI·입력·View 모두.
- **모니터 열기 상태 (GameManager):** `IsMonitorOpen`. `OpenMonitor()`(입력 가능할 때만)·`CloseMonitor()`. `CanPlayerAct`는 그대로 판정용, 열린 동안 `Execute`는 고른 행동 실행 → 닫고 공개. 판정 코루틴은 그대로.
- **확대 화면 (새 `MonitorZoomPanel`, Canvas):** 모니터 그림을 키운 패널 + 매수·매도 버튼 + 아이템 아이콘 4칸 + 아이템 상세 페이지(지금 `ItemCloseupPanel`의 회전 그림·이름·분류·설명·사용/취소를 이 화면 안으로 옮김).
- **모니터 클릭:** 모니터 자리에 투명 UI 버튼(Canvas, 지금 버튼·슬롯 클릭과 같은 방식). 클릭 가능할 때 금색 테두리 그림 켬.
- **아래 띠 없앰:** `HudBar`·버튼·슬롯 끔(코드 `ActionButtonsView`·`ItemSlotsView`는 확대 화면용으로 바꾸거나 정리), 테이블 그림을 화면 아래까지.
- **개수 글자 없앰:** 모니터 `RemainingText` 끔, `DeckRevealView` 글자(`하락 n · 상승 m`, `섞는 중…`) 끔.
- **복권:** 결과 문장을 `{이름}: 복권 사용`으로.
- **코드:** AI가 Scripts에 작성(4장 예외 기록), Scene은 MCP.

### AI 제안 → 사용자 채택 (2026-11-17, 10개 모두)
1. **확대 화면 크기·자리:** 화면 가운데 **240×140**(x 40~280, y 20~160) 모니터 모양 패널, 뒤는 바둑판 점으로 어둡게(광대는 어둡게 보임).
2. **확대 화면 배치:** 위 줄 `GE코인`, 왼쪽 큰 칸에 매수·매도 버튼 2개(각 70×36, 아래 작은 글자 `나에게`/`광대에게` 유지), 오른쪽에 아이템 아이콘 4칸(2×2, 앱 아이콘처럼), 아래 줄 키 안내(`A/D 고르기 · Space 실행 · 1~4 아이템 · Esc 닫기`, 크기 9).
3. **아이템 상세 = 같은 화면의 다른 페이지:** 아이템을 고르면 확대 화면 안이 상세(회전 그림·이름·분류·설명·`Space 사용`/`Esc 뒤로`)로 바뀜. 지금 `ItemCloseupPanel`은 이 페이지로 옮기고 따로 뜨던 패널은 없앰.
4. **버튼 색:** 매수·매도 버튼은 지금처럼 남색, 고른 쪽은 금색 테두리(색 역할: 노랑 = 선택). 초록·빨강은 캔들 결과에만.
5. **열 수 있음 표시:** 내 차례에 모니터 테두리에 금색 1도트 테두리(깜빡임 없음) + 모니터 받침대 아래에 작은 글자 `Space`(크기 9). 광대 차례엔 둘 다 꺼짐.
6. **평소 내 아이템 표시:** 모니터 앞 테이블 위(y 144~160)에 작은 아이콘 21×16 최대 4개(광대 아이템이 왼쪽 위에 있는 것과 짝). 클릭하면 확대 화면이 그 아이템 상세로 바로 열림.
7. **열린 동안 입력:** A/D = 매수·매도, Space = 고른 것 실행(아이템 상세에서는 사용), 1~4 = 아이템 상세, Esc = 상세에서 뒤로 / 첫 화면에서 닫기. 화면 밖 클릭·우클릭 = 닫기. 일시정지는 닫힌 상태에서만 Esc.
8. **광대 차례:** 모니터는 열리지 않고, 광대가 고르면 모니터 위 줄에 `광대 매수`/`광대 매도`를 공개 동안 보여 줌(광대가 무엇을 골랐는지는 지금도 결과 글자에 나옴 → 공개 전에 보여도 규칙 문제 없음).
9. **아래 띠 자리:** 테이블 그림을 y 180까지 늘림(앞 모서리를 화면 아래 밖으로), 내 동전 탑·매트 자리는 그대로, 결과 글자는 벽 그대로.
10. **Ticket 나눔:** 42 "매수라고 부르고 숫자 대신 색으로 본다"(이름·문장·GLOSSARY, 개수 글자 끔, 복권 문장 — 작은 코드) → 43 "모니터를 열어 매수·매도한다"(확대 화면 기본·클릭·키·아래 띠 없앰·테이블 늘림) → 44 "아이템을 모니터 안에서 쓴다"(아이템 페이지·상세 이전·테이블 위 작은 아이콘). 43은 42 뒤, 44는 43 뒤. 그림은 43·44에서 시안 먼저.
