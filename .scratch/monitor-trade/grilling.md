# Grilling: 모니터로 거래하기 (모니터 클릭 → 매수·매도·아이템, 아래 띠 없애기)

> 2026-11-17. 계기: stock-screen 40(주식 모니터) 진행 중 사용자 "복권 아이템 사용시 뭐가 당첨됐는지 알려주는 연출과 캔들 남은 개수, 종류를 알려주는건 삭제해. 그리고 매도, 보유를 아래에 있는 모니터를 클릭해서 매도할지 매수할지 정하는 연출로 해보자 아이템도 화면 안에서 하면 좋고, 따라서 화면 아래에 차지하는 매도 보유를 없애. 그리고 게임에서 쓰는 '보유'를 매수로 바꿔도 문제가 없다면 바꿔도 매수 매도 일관성 지키고 싶거든. 내가 원하는 연출은 모니터에 자동으로 캔들 공개, 모니터를 클릭해서 자세히 들여다 봄-> 매도 or 매수 결정 혹은 아이템 사용. 그리고 목숨이 동전인 것도 맞지 않은 것 같아. 체력 관련 이건 나중에 결정할게".
> AI가 규칙과 부딪히는 곳 2군데(개수 공개 규칙, 결정 → 공개 순서)를 짚고 추천과 함께 질문. 사용자 답: **Q2 "그냥 캔들 색만 보여줘", 나머지 전부 채택**.

## 규칙과 부딪히는 곳 (AI가 짚음)
- 남은 개수·종류 표시 삭제 ↔ GDD 04장 "개수 공개·순서 숨김"
- "모니터에 자동으로 캔들 공개 → 들여다봄 → 결정" ↔ 지금 규칙은 **결정한 뒤 공개**(먼저 공개하면 결과를 보고 고르는 게임이 됨) → Q1에서 결정 → 공개 순서를 지키는 쪽으로 채택

## 1라운드
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 흐름 | **모니터 클릭 → 화면 크게(확대) → 매수·매도·아이템 중 고름 → 모니터에서 캔들이 자동으로 공개** (결정 → 공개 순서 유지) | 사용자 연출 + 게임 규칙 유지 |
| Q2 | 캔들 개수·종류 표시 | **사용자 답: "그냥 캔들 색만 보여줘"** → 숫자·글자로 개수를 알려 주지 않음. 모니터의 `남은 n`/`하락n 상승m` 글자 없앰, 덱을 채울 때 공개 연출은 **캔들 색(빨강·초록)만** 보여 주고 `하락 n · 상승 m` 글자는 없앰 (AI 추천은 "공개 연출 글자 유지"였으나 사용자가 색만으로 정함) | 기억력 재미(#29·#39와 같은 방향), 숫자 대신 눈으로 |
| Q3 | 복권 결과 | 결과 글자를 `플레이어: 복권 사용`으로만, 무엇이 당첨됐는지 글자·연출로 알리지 않음(잔고·레버리지·아이템 변화는 화면에서 보임) | 사용자 요청 |
| Q4 | 보유 → 매수 | 화면 글자·결과 문장·문서(GLOSSARY·gdd-changes)·**코드 이름(`Hold` → `Buy`)** 모두 **매수**로 | 매수·매도 일관성(사용자 요청) |
| Q5 | 아래 띠 | 매수·매도 버튼과 아이템 슬롯을 모두 없애고 아래 띠도 지움, 그 자리는 테이블, 내 동전 탑은 그대로 | 화면 아래를 차지하는 버튼 없애기(사용자 요청) |
| Q6 | 아이템 | 확대된 모니터 화면 안에 **앱 아이콘처럼**, 평소에는 모니터 아래 가장자리에 작은 아이콘으로 개수만 보임 | "아이템도 화면 안에서"(사용자 요청) |
| Q7 | 키보드 | 단축키 유지: Space = 모니터 열기/실행, A/D = 매수·매도 고르기, 1~4 = 아이템, Esc = 닫기 | 마우스 없이도 플레이 가능 |
| Q8 | 체력(동전)·진행 | 체력 표현은 **나중에 결정**(범위 밖). `.scratch/monitor-trade/` Grilling → Spec → Ticket, 코드는 AI가 작성 | 사용자 "나중에 결정할게" |

## 아직 정하지 않은 것 (Spec에서)
- 확대 화면의 크기·배치(매수·매도 버튼, 아이템 아이콘, 설명 글자)와 기존 아이템 확인 패널(27·32: 회전 그림)을 어떻게 합칠지
- 확대 화면이 열린 동안 광대·테이블을 어떻게 보일지(어둡게 등)
- 아래 띠가 없어진 뒤 테이블 아래쪽 그림, 결과 글자 자리 유지 여부
- 광대 차례에 모니터를 클릭하면(막기) / 광대의 거래는 어떻게 보일지(광대가 모니터를 쓰는 연출?)
- stock-screen 40의 `남은 n` 자리, "다음" 창 유지 여부
