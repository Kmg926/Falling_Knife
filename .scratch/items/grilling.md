# Grilling: 아이템 4종 + 광대 아이템 규칙 (마일스톤 ②)

> 2026-11-09. 지금 게임: 잔고 10, 덱 랜덤(2~6 / 4~8 / 7~9), 광대 AI는 덱 비율 규칙(④)만, 텍스트 UI(개발용), 행동 기록 없음(gdd-changes #29).
> 질문은 AI가 추천 답과 함께 묻고, 사용자가 채택·거절했다. 2라운드, Q1~Q17 **모두 채택**.

## 확인한 사실 (질문 전, GDD 원문 PDF)
| 항목 | 원문 |
|---|---|
| 보유 | 최대 4. 장전마다 2개 지급, 초과분 버림. 라운드 시작 시 초기화. 시작 조건 "아이템 2개씩" |
| 차트 분석 | 사용자 턴, 다음 캔들을 사용자만 확인, 단말기에 표시(플레이어만) |
| 찌라시 | 사용자 턴, 다음 캔들을 공개하고 버림 |
| 거래 정지 | 상대가 이미 정지 상태가 아닐 때, 상대의 다음 턴 1회 건너뜀, 상대 잔고 옆 정지 표시 |
| 복권 | 각 25%: 잔고 1 회복 / 레버리지 1 증가 / 아이템 1개 / 꽝. 적용할 수 없으면 꽝 |
| 입력 | 1~4 / 슬롯 클릭: 아이템을 화면 중앙에 크게, 설명(내 턴, 슬롯에 있을 때). Space(확인 중): 사용. Esc/우클릭(확인 중): 취소, 아이템은 남음. 한 턴에 행동 전까지 여러 개 사용 |
| 광대 AI | ① 차트 분석 → 상승이면 보유, 하락이면 매도 ② 거래 정지(플레이어가 정지 아님) ③ 잔고 1 + 복권 ④ 하락 비율 ≥ 50% 찌라시 또는 매도, 미만 보유 |
| F05 | 확인 화면, 사용 연출, 정지 중복 불가, 아이템별 1회씩 검증 |
| 08장 | ItemData/ItemEffect(ScriptableObject) 계획, ScriptableObject는 "직접 학습" 항목 |
| 원문에 없음 | 지급 아이템 종류를 정하는 방법, 복권 잔고 상한, 상대 아이템 공개 여부 |
- 지금 게임과 어긋남: 잔고 10이라 광대 규칙 ③ "잔고 1"은 거의 안 쓰임.

| Q8 | 거래 정지 | 정지된 사람의 차례가 오면 건너뛰고 바로 상대에게(`광대: 거래 정지로 턴을 건너뜀`), 레버리지 그대로, 1회 뒤 풀림. 이미 정지면 확인 화면 "사용 불가", 아이템 남음 | GDD 그대로 |

| Q10 | 차트 분석 표시 | 플레이어가 쓰면 그 캔들 공개 때까지 `차트 분석: 다음 캔들은 상승` 표시. 광대가 쓰면 `광대: 차트 분석 사용`만(결과 숨김). 덱 순서가 바뀌면(찌라시 등) 표시 지움 | GDD "사용자만 확인" |
| Q11 | 광대 아이템 연출 | 아이템도 생각 1초 뒤 하나씩, 결과 줄에 표시 | 기록이 남지 않으니 읽을 시간 |
