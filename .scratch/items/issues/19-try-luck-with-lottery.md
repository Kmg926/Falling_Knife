# 19: 복권을 쓴다 (25%씩 잔고·레버리지·아이템·꽝)

**What to build:** 복권을 쓰면 25%씩: 잔고 +1(그 라운드 시작 잔고를 넘지 않음) / 레버리지 +1(3이면 안 오름) / 아이템 +1(4종 중 무작위, 가득이면 안 됨) / 꽝. 적용할 수 없으면 꽝. 결과 줄 `플레이어: 복권 → 레버리지 +1` 같은 문구. 테스트용 복권 결과 고정 옵션(Inspector 체크 + 결과).
