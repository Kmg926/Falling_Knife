# 18: 거래 정지로 상대 턴을 한 번 건너뛴다

**What to build:** 거래 정지를 쓰면 상대 잔고 옆에 `(정지)`. 차례가 상대에게 넘어가는 순간 `광대: 거래 정지로 턴을 건너뜀`과 함께 바로 내게 돌아오고 정지가 풀린다. 레버리지는 그대로. 상대가 이미 정지 상태면 확인 줄에 `사용 불가`, Space를 눌러도 아이템이 남는다.

**Blocked by:** 16

**Status:** ready-for-agent

- [ ] 사용 → `(정지)` 표시, 아이템 −1, 차례 그대로 (C7)
- [ ] 매도(상승)로 차례를 넘김 → 건너뜀 문구 → 다시 내 차례, `(정지)` 사라짐 (C7)
- [ ] 보유+하락으로 차례가 넘어가도 같은 건너뜀 (모든 차례 넘김이 같은 곳을 지남)
- [ ] 이미 정지면 사용 불가, 아이템 남음 (C7)
