# 16: 라운드 시작과 재장전 때 아이템 2개를 받고, 1~4로 확인해 찌라시를 쓴다

**What to build:** 두 참가자가 아이템 슬롯(최대 4)을 갖는다. 라운드 시작 때 비우고 2개씩, 재장전 때 2개씩 4종 중 무작위로 받는다(넘치면 버림, 결과 줄 `아이템 +2`). 화면에 `아이템  나: … / 광대: …`. 내 차례에 1~4 → `확인: 이름 — 설명 / Space 사용, Esc 취소`, 확인 중 A/D 무시. 이번 Ticket에서 효과가 있는 아이템은 **찌라시**뿐이다(다음 캔들을 공개하고 버림, 마지막이면 재장전, 차례 그대로). 다른 3종은 확인까지만 되고 Space를 누르면 `아직 쓸 수 없음`. 광대는 아이템을 받기만 하고 쓰지 않는다(20). `ItemData` ScriptableObject 4개, Input Actions `Item1`~`Item4`·`Cancel`, 테스트용 아이템 고정 지급.

**Blocked by:** 없음

**Status:** ready-for-agent

4. 덱 마지막 장에서 찌라시 → 재장전 + 아이템 +2
