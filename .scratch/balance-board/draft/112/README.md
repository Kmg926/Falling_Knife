## BalanceView.cs — 줄 하나(광대 줄·내 줄 두 개를 Scene에 둠)
| 부분 | 무엇을 | 왜 |
|---|---|---|
| `tensDigit`·`onesDigit` + `digits[10]`·`dangerDigits[10]` | 숫자를 그림으로 바꿔 끼움(7세그먼트). 십의 자리는 10 이상일 때만 | TMP 글자보다 기계 화면 같음. 몸통 그림에 꺼진 "88"이 비쳐 LED처럼 |
| `cells[10]` + `cellOn/Off/Hit/Heal` | 칸 수 = 라운드 시작 잔고(`StartingBalance`), 남은 만큼 켜짐 | 정확한 숫자 + 한눈의 양(Grilling Q1·Q4) |
| `Refresh()` | 같은 사람의 잔고가 바뀌면 바뀐 칸 범위 [lo, hi)·방향·끝나는 시각을 적고 "▼n"/"▲n" 글자 | 라운드가 바뀌면 새 Participant라 깜빡이지 않음(전 코드와 같은 방법) |
| `Update()` → `Draw()` | 매 프레임 그림 몇 장만 다시 고름 | 깜빡임이 시간에 따라 바뀜 |
| 위험 | 내 잔고 3 이하면 숫자가 1.2초 주기로 0.9초 빨강 | 전 긴장 색 규칙(플레이어 쪽만) 그대로 |
| 칸 깜빡임 | 0.6초 동안 0.1초마다 켜짐(빨강·밝음)·꺼짐, 그 뒤 원래 모습 | 잃은 칸이 정확히 몇 개인지 보임 |
| "▼n"과 "정지" | 한 자리를 나눠 씀, 변화 글자가 떠 있으면 그쪽 먼저 | 작은 기계라 자리가 좁음 |
지운 것: 동전 탑·동전 떨어짐(`DropCoin`, Tween 사용)·"7/10" 글자.
