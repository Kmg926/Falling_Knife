# balance-board — Spec

> 2026-11-27. Grilling Q1~Q10 채택.

## 1. 목표
잔고(체력)를 테이블 왼쪽의 **잔고 전광판** 하나로 보여 준다: 위 광대·아래 나, 줄마다 7세그먼트 숫자 + 칸 막대.

## 2. 플레이어 경험
- 평소: 각 줄에 이름, 숫자(예 06), 칸(그 라운드 시작 잔고만큼, 남은 만큼 켜짐).
- 맞음: 잃은 칸이 빨강으로 깜빡이다 꺼지고 숫자가 줄며 "▼n"이 잠깐. 회복: 칸이 초록으로 켜지며 "▲n".
- 잔고 3 이하: 그 줄 숫자가 빨강으로 천천히 깜빡임.

## 3. 규칙·값
게임 규칙 변경 없음. 칸 수 = 라운드 시작 잔고(최대 10).

## 4. 화면
HUD(320×180) 왼쪽 테이블 위, 세운 기계(그림은 AI 코드). 숫자·칸은 그림 조각(Image)으로 바꿔 끼움, 이름·"▼n"은 TMP. 매트 2장·동전·옛 글자는 끔.

## 5. 코드 구조
- `BalanceView` 다시 씀: 줄 2개(광대·나) × {숫자 2자리 Image, 칸 Image 10, 변화 글자}. GameManager 잔고·시작 잔고를 읽기만.
- 튜토리얼 "여기를 봐"(내 잔고·광대 잔고)는 새 줄을 가리킴.
- 그림 도구 `tools/make_art_board.py`.

## 6. 범위 밖
잔고 규칙, 결과 화면.

## 7. 확인
A/B 게임 캡처 → 선택, 피해·회복·위험 깜빡임 MCP 시험, 튜토리얼 Look, 규칙 1쪽 그림 다시.
