## 변경·유지·확인

**변경:** 타이틀의 조작 안내 상자·시작/종료 버튼·"목표" 줄을 없애고, 왼쪽 아래에 세로 메뉴 **시작 / 규칙 / 설정 / 크레딧 / 종료**를 둔다. 규칙(3쪽)·설정·크레딧은 타이틀 위에 뜨는 창.

**바꾸지 않을 것 / 유지 (이유):**
- U1 게임 판정·GameScene 화면 그대로(설정 값 반영만)
- U2 로고·부제·로고 차트 선·광대·타이틀 배경(52) 그대로
- U3 32색·640 격자·Galmuri 글꼴, UI는 조명 안 받음
- U4 시작 → GameScene(지금과 같음)

**사건별 알아차릴 정보:**
- 메뉴: "지금 무엇을 고르고 있나" → 금색 + ▶
- 규칙: "몇 쪽 중 몇 쪽" → 아래 1/3, ←/→ 안내
- 설정: "값이 바뀌었나" → 막대·켬/끔 글자가 바로 바뀌고 소리 크기는 바로 들림

**확인 – 작동:**
- C1 메뉴 5개, ↑/↓·W/S 이동(끝에서 반대쪽으로 돌기), Space·Enter·클릭 선택, 마우스 올리면 선택 이동
- C2 시작 → GameScene / 종료 → 끝(에디터 Play 멈춤) / 첫 화면 Esc는 아무 일 없음 / 창에서 Esc → 메뉴로
- C3 규칙 3쪽 ←/→ 넘김, 글이 창 안에 다 들어감(넘침 0)
- C4 설정: 값 바꿈 → `PlayerPrefs` 저장 → 타이틀 다시 켜도 그대로 → GameScene에서 소리 크기·흔들림 반영
- C5 크레딧 글 넘침 0, 본명·학번 없음(공개 저장소)
- C6 GameScene 퇴행 T65~T68·T143, Console 오류 0

**확인 – 경험:** 메뉴가 게임 분위기에 맞는가, 규칙만 읽고 처음 하는 사람이 할 수 있는가(③ 플레이테스트 때). "직접 확인 필요".

**확인 전:** 구현 전이라 전부 확인 전.

## Problem Statement

타이틀에 조작법이 늘 떠 있어 복잡하고, 규칙을 볼 곳·소리를 조절할 곳·크레딧(폰트 라이선스 표기 의무)이 없다.

## Solution

타이틀을 세로 메뉴로 바꾸고, 규칙·설정·크레딧을 각각 창으로 연다. 설정은 컴퓨터에 저장해 게임 화면이 시작할 때 읽는다.

## User Stories

1. 처음 하는 플레이어로서, 타이틀에서 규칙을 읽고 시작하고 싶다.
2. 플레이어로서, 키보드나 마우스로 메뉴를 고르고 싶다.
3. 플레이어로서, 소리 크기·화면 흔들림·전체화면을 바꾸고, 다음에 켜도 그대로이길 원한다.
4. 플레이어로서, 누가 어떤 도구·자산으로 만들었는지 보고 싶다.
5. 개발자로서, 폰트 라이선스(OFL 크레딧 표기)와 AI 사용을 게임 안에 밝히고 싶다.
6. 개발자로서, 실수로 Esc를 눌러 게임이 꺼지지 않길 원한다.

## Implementation Decisions

- **코드(AI 작성, 4장 예외):** `TitleMenu.cs` 다시 씀(메뉴 이동·선택·창 열고 닫기), 새 `GameSettings.cs`(정적: 불러오기·저장·기본값), `AudioManager`·`UIManager`가 시작할 때 `GameSettings`를 읽음.
- **Scene(MCP):** TitleScene에서 `ControlsBox`·`StartButton`·`QuitButton`·`Goal` 끄거나 지우고, 메뉴 글 5개·창 3개(규칙·설정·크레딧) 추가.

### AI 제안 → 사용자 채택 (2026-11-18, 8개 모두)
1. **메뉴 모양:** 왼쪽 아래(지금 조작 안내 상자 자리, x −138~, y −32~−88)에 글자만 5줄(크기 11, 줄 간격 12). 고른 줄 = 금색(gold2) + 앞에 "▶", 나머지 = 흐린 크림(cream0). 버튼 그림 없음(배경이 어두워 글자만으로 충분).
2. **창 그림:** 새 그림 없이 `closeup-panel.png`(168×110)를 **9칸 늘이기(9-slice)**로 크게 써서 창 3개 공통 — 테두리는 그대로, 가운데만 늘어남. 창 뒤 화면은 `pause-dim.png`로 어둡게. 창 크기 약 260×150(지금 좌표).
3. **규칙 3쪽 글(지금 값 기준):**
   - ① **목표·턴:** "두 사람이 번갈아 숨겨진 캔들을 한 장 공개해요. 3라운드, 잔고 10에서 시작. 상대를 먼저 파산(잔고 0)시키면 라운드 승리, 3라운드를 이기면 클리어. 내 잔고가 0이 되면 패배." + 표 4줄(매수+상승 → 레버리지 +1, 한 번 더 / 매수+하락 → 내 잔고 −(1+레버리지) / 매도+하락 → 상대 잔고 −(1+레버리지) / 매도+상승 → 변화 없음, 차례 넘김).
   - ② **레버리지·아이템:** "레버리지는 두 사람이 같이 쓰는 0~3. 피해가 나면 0으로." + 아이템 4종(그림 아이콘 + `ItemData` 글) + "라운드 시작·덱 다시 채울 때 2개씩, 최대 4개."
   - ③ **조작:** "Space·클릭 모니터 열기 / ←→·A D 매수·매도 / 1~4 아이템 / Esc 뒤로·일시정지".
   - 글은 `ItemData`·코드 값과 다르면 안 되므로 규칙 글은 Scene 글자로 쓰되, 아이템 글은 `ItemData`에서 읽어 표시.
4. **설정 4줄:** "전체 소리 ■■■■■■■■■■ 100%", "음악 ■■■■■■□□□□ 60%", "화면 흔들림 켬", "전체화면 켬". ↑/↓로 줄, ←/→로 값(소리 10% 단위, 켬/끔 전환), 마우스는 줄 클릭 = 오른쪽으로 한 단계. 소리를 바꾸면 클릭음으로 바로 들려 줌. 저장 키 `fk.master`·`fk.music`·`fk.shake`·`fk.fullscreen`. 기본값 = 지금 값(전체 100%, 음악 60%, 흔들림 켬, 전체화면 = 지금 창 상태).
5. **크레딧 글(위아래로 넘김):** 게임 "Falling Knife" / 만든 사람 Kmg926 / 엔진 Unity 6.6 (URP 2D) / 글꼴 Galmuri11 by Lee Minseo(quiple), SIL Open Font License 1.1 / 그림·효과음: Claude(Anthropic)가 작성한 코드로 생성, 고르기·지시는 만든 사람 / 코드 도움: Claude / 배경음악: (정해지면) / "비영리 학교 과제". 실제 문구는 `asset-rights.md` 3장 초안과 맞추고, 그 초안도 같이 고침.
6. **타이틀 키 입력:** 지금처럼 키보드·마우스를 직접 읽음(게임 판정과 무관). 시작은 메뉴에서 "시작"을 고른 뒤 Space·Enter·클릭 — Space 한 번으로 바로 시작하던 것은 없어짐(첫 줄이 "시작"이라 Space 한 번이면 같음).
7. **GameScene 반영:** `AudioManager.Awake`에서 `masterVolume = 저장값`, `musicVolume = 0.6 × 저장값/60%`(음악 100% = 지금의 1.67배가 되지 않게: 음악 막대 100% = 지금 0.6), `UIManager.Awake`에서 `screenShake = 저장값`. 전체화면은 `Screen.fullScreen`(에디터에선 효과 없음 — 빌드에서 확인).
8. **Ticket:** 53 "타이틀에서 메뉴를 고르고 규칙을 읽는다"(메뉴·규칙·조작 이동, 시작·종료) → 54 "설정을 바꾸면 게임에 남는다"(설정 창·저장·GameScene 반영) → 55 "크레딧에서 만든 사람과 도구를 본다". 54·55는 53 뒤.
