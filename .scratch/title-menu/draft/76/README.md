# draft/76: 타이틀 메뉴 글자를 부제 "떨어지는"과 같은 왼쪽 선에

사용자: "타이틀 시작 아래에 있는 텍스트들 '떨어지는'에 맞춰서 정렬(왼쪽으로 밀라는 뜻)".

## 원인
- 메뉴 칸은 부제와 같은 x 22에서 시작하지만, 고르지 않은 줄은 "▶ " 자리를 비우려고 앞에 빈칸 3개(`"   " + 글자`)를 넣어 글자가 오른쪽으로 밀려 있었다.

## TitleMenu.cs `RefreshMenu`
| 바뀐 줄 | 왜 |
|---|---|
| `items[i].text = (on ? "▶ " : "") + labels[i]` | 고르지 않은 줄은 빈칸 없이 글자만 → 부제와 같은 선 |
| `items[i].margin = (on ? -arrowWidth : 0, …)` | 고른 줄은 "▶ " 폭만큼 왼쪽 여백을 음수로 → 글자는 같은 선, ▶는 선 바깥 왼쪽 |
| `arrowWidth` = `"▶ 가"` 폭 − `"가"` 폭(처음 한 번) | 끝 빈칸은 폭을 잴 때 빠져서 `"▶ "`만 재면 모자람(첫 시도에서 고른 줄 글자가 조금 오른쪽에 남았음) |

## 확인
- 첫 시도 캡처 `menu-aligned.png`: 고르지 않은 줄은 "떨어지는"과 같은 선, 고른 줄은 조금 오른쪽 → 폭 재는 방법을 고침. 고친 뒤(Unity 다시 켠 뒤) 캡처를 같은 파일로 다시 찍음: "시작"·"설정"을 골라도 다섯 줄 글자가 모두 "떨어지는"과 같은 선, ▶는 선 바깥 왼쪽(폭 15.58). 컴파일 오류 0.
