# 일시정지 버튼: 마우스 올림 강조 + 두 버튼 같은 크기

> 사용자 "작동은 되는데 마우스 호버링 애니메이션이 없어서 뭘 클릭하는지 명료하지 않음", "계속과 타이틀 버튼 크기 동일하게"(2026-11-18). AI가 Scripts에 직접(4장 예외), Scene은 MCP. 전 코드 `PausePanel.before.cs`(59 버전).

## 바꾼 것
| 대상 | 전 | 후 |
|---|---|---|
| 마우스 올림 | 변화 없음(Button Transition None, 계속은 늘 금색·타이틀은 늘 크림) | 올린 버튼 = **금색 글 + "▶ "** + 원래 밝기, 다른 버튼 = 흐린 글(cream0) + 그림 0.6배 어둡게. 막 멈추면 "계속"이 먼저 강조. 버튼 밖으로 나가면 마지막 강조 유지 |
| 타이틀 버튼(GameScene) | 64×21, x 128, 남색 테두리 그림 | **72×21, x 124**(계속과 같음), 계속과 같은 그림 `result-button-retry`(64 그림을 늘리면 도트가 일그러짐) |

## 줄별 핵심 (`PausePanel.cs`)
| 부분 | 왜 |
|---|---|
| `Awake`에서 버튼 글(`labels`)·원래 글(`labelTexts`) 저장 | "▶ "를 붙였다 뗄 때 원래 글로 되돌리기 |
| `Refresh`: `IsPaused && !wasPaused` → `SetHighlight(0)` | 일시정지를 열 때마다 "계속"부터 |
| `Update`: 마우스가 어느 버튼 위인지(`over`) → 바뀌면 `SetHighlight` | 타이틀 메뉴와 같은 방식(금색 + ▶) |
| `SetHighlight`: 글 색·"▶ "·`targetGraphic.color` | 그림 색은 곱하는 값이라 0.6 = 어둡게, 흰색 = 원래 |
| 클릭은 59 그대로(막 누른 순간 + 버튼 영역) | |
