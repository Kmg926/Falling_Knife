# title-menu 다듬기 2: 규칙을 상세하게 (3쪽 → 4쪽)

> 사용자 "레버리지 설명 상세하게 예: 피해 후 0 → 피해 후 0으로 초기화. 규칙이나 이런 글들은 상세하게 설명이 필요함", "화살표 같은 기호는 빼줘. 단, 1쪽의 상승 하락과 4쪽의 조작은 제외"(2026-11-18). AI가 Scripts에 직접(4장 예외), Scene 값은 MCP. 전 코드 `TitleMenu.before.cs`.
> 확인한 사실(코드): 레버리지는 매수→상승에서 +1(최대 3, 3에선 그대로), 하락 피해 = 1 + 레버리지 후 `Leverage.Reset()`, 매도→상승은 그대로, 라운드 시작 때 새로 0. 조작: Space·클릭 = 모니터 열기/실행, ←→·A D = 고르기, 1~4 = 아이템 확인 후 Space로 사용, Esc = 닫기·취소·일시정지.

## 쪽 구성
| 쪽 | 내용 |
|---|---|
| 1 목표와 턴 | 문장 3줄 + 표. 매도 ▲상승 결과 "아무 일도 일어나지 않는다", 아래 줄 '"한 번 더"일 때만 같은 사람이 다시 고른다.' |
| **2 레버리지(새 쪽)** | 8줄: 무엇인지 · 함께 씀·0에서 시작 · 매수 상승마다 +1(최대 3) · 피해 = 1 + 레버리지 · 피해 뒤·새 라운드 **0으로 초기화** · 매도 상승은 그대로 · 예) 레버리지 2에서 매도 하락 → 상대 잔고 −3, 0으로 초기화 |
| 3 아이템 | 머리말 2줄(받는 때·개수 / 고르고 쓰는 법) + 아이템 4줄(이름 금색). 아이템 줄 y −42 → −56 |
| 4 조작 | 키 금색 + 동사 설명("모니터를 열고, 고른 행동을 실행한다" 등) |
