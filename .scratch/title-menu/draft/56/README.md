## 줄별 핵심
| 부분 | 왜 |
|---|---|
| `<color=#D9B45A>…</color>` | TMP 글 태그로 글자 색. 금색 = 이름표·키·아이템 이름(팔레트 gold2), 초록 #6CC27F(green2) = 상승, 빨강 #E46A58(red4) = 하락·피해 |
| `<pos=22%>`·`<pos=44%>` | 앞 글 길이와 상관없이 그 자리에서 시작 → 표처럼 줄이 맞음(설정 창과 같은 방법) |
| `rulesPage1Footer` 새 칸 | 1쪽 본문이 8줄을 넘지 않게 보충 설명은 아래 줄로 |
| 아이템 글 `$"<color=…>{displayName}</color>  {description}"` | 이름과 설명이 한눈에 나뉨, 글은 그대로 ItemData에서 |

## 위 3줄을 문장으로 (사용자 "목표 패배 내 차례를 문장으로 설명하고 … 단어에 지금과 같은 색")
| 전 | 후 |
|---|---|
| **목표**  상대 잔고를 먼저 0으로 (잔고 10, 3라운드) | **목표**는 매 라운드 상대 잔고를 먼저 0으로 만드는 거예요. |
| **패배**  내 잔고가 0이 되면 | 어느 라운드든 내 잔고가 먼저 0이 되면 **패배**예요. |
| **내 차례**  숨겨진 캔들 한 장에 매수 또는 매도 | **내 차례**엔 숨겨진 캔들 한 장에 매수 또는 매도를 해요. |

- 단어만 금색(`<color=#D9B45A>`), 문장 나머지는 흰색.
- 한 줄에 들어가는지 후보 문장의 폭을 TMP로 재서 고름(폭 240 안: 237·206·226). 더 길게 쓰면 두 줄로 넘어가 1쪽이 넘침.
- 빠진 정보: "잔고 10"·"3라운드" — 게임 화면(잔고 판 10/10, ROUND 1/3)에 보이므로 뺌.
- 확인: 1쪽 8줄, 넘침 0.

## '-다' 격식체로 (사용자 "-요체 말고 -다로 끝나는 격식체로")
| 전 | 후 |
|---|---|
| …만드는 거예요. | …만드는 **것이다.** |
| …되면 **패배**예요. | …되면 **패배**다. |
| **내 차례**엔 … 매도를 해요. | **내 차례**에는 … 매도를 **한다.** |
| "한 번 더"가 아니면 차례가 넘어가요. | …차례가 **넘어간다.** |
| 아이템은 라운드 시작·덱을 다시 채울 때 2개씩 (최대 4개) | 아이템은 라운드 시작·덱 재장전 때 2개씩 **받는다** (최대 4개). — "덱을 다시 채울 때"는 폭 240/240이라 줄임 |
| (준비 중 창) 준비 중이에요. | 준비 중이다. |

확인: 1쪽 8줄·2쪽 1줄, 본문·아래 줄 넘침 0, 규칙 글에 '요.' 없음. 아이템 설명(ItemData)은 원래 '-다'.
