## 바꾼 것
| 쪽 | 전 | 후 |
|---|---|---|
| 1 목표·턴 | 긴 문장 4줄 + "매수 + 상승 → …" 4줄, 한 색 | 이름표 **목표·패배·내 차례**(금색) + **행동·캔들·결과 표**(줄 맞춤). ▲ 상승 초록·▼ 하락 빨강·피해 빨강·"한 번 더" 금색. "차례 넘김"은 아래 한 줄(`rulesPage1Footer`) |
| 2 레버리지·아이템 | "레버리지: …" / "이름 — 설명" | "**레버리지**  0~3 공용 · 다음 피해 +1씩 · 피해 후 0"(한 줄), 아이템 **이름 금색** + 설명 |
| 3 조작 | 띄어쓰기로 맞춘 글 | **키 금색**, 설명은 `<pos=36%>`에서 시작 |

## 줄별 핵심
| 부분 | 왜 |
|---|---|
| `<color=#D9B45A>…</color>` | TMP 글 태그로 글자 색. 금색 = 이름표·키·아이템 이름(팔레트 gold2), 초록 #6CC27F(green2) = 상승, 빨강 #E46A58(red4) = 하락·피해 |
| `<pos=22%>`·`<pos=44%>` | 앞 글 길이와 상관없이 그 자리에서 시작 → 표처럼 줄이 맞음(설정 창과 같은 방법) |
| `rulesPage1Footer` 새 칸 | 1쪽 본문이 8줄을 넘지 않게 보충 설명은 아래 줄로 |
| 아이템 글 `$"<color=…>{displayName}</color>  {description}"` | 이름과 설명이 한눈에 나뉨, 글은 그대로 ItemData에서 |
