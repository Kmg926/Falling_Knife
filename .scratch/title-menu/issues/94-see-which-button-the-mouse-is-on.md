# 94: 마우스를 올린 버튼이 어떤 건지 보인다

**What to build:** 사용자 "태블릿에서 매수·매도할 때 마우스 호버링 반응이 없어. 패배 화면의 타이틀·다시하기도"(2026-11-23).
- 매수·매도 버튼: 마우스를 움직여 올리면 그 행동이 "선택"됨(밝은 그림 + 클릭음) — 타이틀 메뉴처럼 올린 곳 = 고른 것. 가만히 있는 마우스는 A/D 선택을 덮어쓰지 않음.
- 결과 화면(파산·생존): 올린 버튼은 금색 글 + "▶", 다른 버튼은 흐리게(일시정지 메뉴 60과 같음). 처음 켜질 때는 "다시하기" 강조.
