# Grilling: 타이틀 메뉴 (시작·규칙·설정·크레딧)

> 2026-11-18. 계기: title-bg 52 뒤 사용자 "타이틀에 조작법을 적어놓지 말고 시작 / 규칙 / 설정 / 크레딧 이런 식으로 만들어줘".
> 확인한 사실: 지금 타이틀 = 로고·부제·목표 + 조작 안내 상자 + 시작·종료 버튼, `TitleMenu.cs`(Space 시작·Esc 종료, 키보드 직접 읽음). `AudioManager`에 전체·음악 소리 칸(저장 안 됨), `UIManager.screenShake` 켬/끔 칸, `asset-rights.md` 3장에 게임 안 크레딧 문구 초안.
> 사용자가 **Q1~Q9 모두 채택**.

## 1라운드 (모두 채택)
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 메뉴 항목 | **시작 / 규칙 / 설정 / 크레딧 / 종료** | PC 게임이라 종료도 메뉴에 |
| Q2 | 조작 | ↑/↓·W/S 이동, Space·Enter·클릭 선택, 마우스 올리면 선택 표시, **Esc = 뒤로**(창 닫기), 첫 화면 Esc는 아무것도 안 함 | 실수로 꺼지지 않게 |
| Q3 | 모양·자리 | 조작 안내 상자 자리(왼쪽 아래)에 세로 목록, 고른 항목 금색 + ▶. 로고·부제 그대로, "목표" 줄은 규칙 화면으로 | 타이틀을 깔끔하게 |
| Q4 | 규칙 화면 | 타이틀 위 어두운 창, **3쪽**(←/→): ① 목표·매수/매도 결과표 ② 레버리지·아이템 4종 ③ 조작법 | 타이틀에서 뺀 조작법이 갈 곳 |
| Q5 | 설정 | **전체 소리·음악 소리(0~100%, 10단계), 화면 흔들림 켬/끔, 전체화면 켬/끔**, `PlayerPrefs`에 저장해 게임 화면에 반영 | 이미 있는 칸을 사용자 설정으로 |
| Q6 | 크레딧 | 만든 사람, 엔진(Unity), 폰트(Galmuri, SIL OFL), AI 도움(Claude: 그림·효과음 코드 생성), 배경음악(정해지면 추가), 위아래로 넘김 | 라이선스(OFL 크레딧 표기)·평가(AI 투명성) |
| Q7 | 만든 사람 이름 | **GitHub 이름 `Kmg926`만** | 공개 저장소의 Scene 파일에 본명을 넣지 않음 |
| Q8 | 일시정지 화면 설정 | 이번엔 타이틀만, 일시정지에서 설정 열기는 다음에 | 범위 작게 |
| Q9 | 진행 | `.scratch/title-menu/` Grilling → Spec → Ticket **53 메뉴·규칙 / 54 설정 / 55 크레딧**, 코드·Scene은 AI가(MCP) | 지금까지와 같은 방식 |
