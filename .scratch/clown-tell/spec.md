**변경:** 광대 머리 왼쪽에 말풍선. 광대가 매수·매도를 정하거나 아이템을 쓰면 그 말을, 결과가 나오면 결과 대사를 띄운다. 결정 뒤 0.6초·아이템 뒤 0.8초 기다린다. 9시 결과 글자는 없앤다.

**바꾸지 않을 것 / 유지:**
- U1 판정·광대 AI 규칙 그대로(말하고 기다리는 시간만 추가)
- U2 기존 반응(피해 깜빡임·흔들림·잔고·불꽃·광대 폰 깜빡임·모니터 위 줄 "광대 매수") 그대로
- U3 32색·Galmuri, 새 소리 없음

**사건별 알아차릴 정보:**
- 광대 결정: "매수인가 매도인가" → 말풍선 금색 "매수"/"매도"
- 광대 아이템: "무슨 아이템인가" → 금색 아이템 이름
- 결과: "누가 맞았나·차례 유지인가" → 결과 대사 + 기존 반응

**확인 – 작동:**
- C1 광대 매수·매도 → 말풍선 → 0.6초 뒤 공개
- C2 광대 아이템 4종 → 각 이름 말풍선 → 0.8초 뒤 다음 판단
- C3 결과 대사 8종(매수·매도 × 상승·하락 + 아이템 결과) 맞게, 1.5초 뒤 사라짐
- C4 내 차례 피해 때만 "하하."/"…칫."
- C5 내가 행동하면 말풍선 바로 사라짐, 일시정지·결과 화면에서 이상 없음
- C6 9시 결과 글자 없음
- C7 퇴행 T65~T68·T143, Console 오류 0

**확인 – 경험:** 처음 하는 사람이 광대가 무엇을 했는지 바로 아는가(③ 플레이테스트).

## Problem Statement
광대 차례에 무엇을 했는지 작은 글자와 왼쪽 결과 글자로만 알 수 있어, 그 글자를 없애면 광대 행동을 알 수 없다.

## Solution
광대가 말풍선으로 자기 행동과 결과를 말한다. 읽을 시간을 조금 준다.

## User Stories
1. 플레이어로서, 광대가 매수했는지 매도했는지 한눈에 알고 싶다.
2. 플레이어로서, 광대가 어떤 아이템을 썼는지 알고 싶다.
3. 플레이어로서, 광대가 맞았는지 내가 맞았는지 알고 싶다.
4. 플레이어로서, 광대가 상대처럼 반응하는 걸 느끼고 싶다.

## Implementation Decisions
- **코드(AI 작성, 4장 예외):** 새 `ClownSpeechView.cs`(말풍선 보이기·사라지기, 대사 표는 Inspector), `GameManager.cs`(광대가 말할 순간을 알림 + 기다림), `TerminalView.cs`(결과 글자 안 씀), `UIManager.cs`(새 View 연결).
- **그림:** `tools/make_art.py`에 말풍선 꼬리(어두운 창과 같은 색·테두리) 추가 → `Sprites/HUD/speech-tail.png`. 틀은 `closeup-panel` 9칸 늘이기 재사용.
- **Scene(MCP):** `/HUD/ShakeRoot/ClownSpeech`(틀·꼬리·글자), `ResultText` 끔.

### AI 제안 → 사용자 채택 (2026-11-22, 6개 모두)
1. **알리는 방법:** `GameManager`가 대사 종류(`ClownLine`: 매수 선언·매도 선언·아이템 4·결과들·Q8 반응)와 번호(`ClownLineCount`, 광대 폰 깜빡임과 같은 방식)를 올림 → `ClownSpeechView`가 번호가 바뀌면 그 대사를 표에서 찾아 띄움. 판정 코드에는 글이 들어가지 않음.
2. **복권 결과:** `UseLottery`가 실제로 된 것(잔고·레버리지·아이템·꽝; "이미 가득" 꽝도 꽝)으로 대사를 고름.
3. **광대가 거래 정지로 쉬는 차례:** 대사 하나 추가 "…한 번 쉬지." (지금은 아무 표시 없이 넘어감)
4. **모니터 위 줄 "광대 매수/매도":** 그대로 둠(말풍선과 같은 정보, 모니터를 보는 사람용).
5. **9시 결과 글자:** 오브젝트 끔 + `TerminalView`가 안 씀. `LastResult`(결과 화면·개발용 글자에서 씀)는 그대로.
6. **말풍선 자리:** HUD 단위 (40,−44)~(150,−72) 근처, 시안 캡처로 맞춤. 흔들림 묶음(`ShakeRoot`) 안 → 내가 맞을 때 같이 흔들림.
