# Grilling: 광대 행동이 분명히 보이게 (clown-tell)

> 2026-11-22. 계기: 사용자 "광대가 어떤 행동을 했는지 잘 안 보여. 실제 게임에서는 화면 9시 방향의 텍스트가 없을 거니까. 보이는 게 명확해야 해".
> 확인한 사실(MCP 캡처, 개발용 글자 끔): 생각 1초 = 오른쪽 위 "광대 턴" + 생각 애니메이션 / 결정 = 내 모니터 위 줄 작은 글자 "GE코인" → "광대 매수"(`TerminalView.titleText`) / 아이템 = 광대 폰 금색 테두리 3번 깜빡임(무슨 아이템인지 모름) / 결과 = 왼쪽 벽 글자 "광대: 매수 → 상승! 레버리지 1, 차례 유지"(`TerminalView.resultText`, 정식 UI — 내 결과도 이 글자). 생각 1초 → 바로 공개 0.5초.
> 사용자 **Q1~Q11 모두 채택**.

## 1라운드
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 무엇을 | ① 매수·매도 결정 ② 아이템 사용(무엇) ③ 결과 모두 | |
| Q2 | 방법 | **광대 말풍선**(머리 옆 짧은 대사, 핵심 단어 금색) | 광대가 상대처럼, 새 그림은 말풍선 틀만 |
| Q3 | 9시 결과 글자 | **없앰**. 결과는 기존 반응(피해 깜빡임·흔들림·잔고·불꽃·캔들 색) + 광대 차례 결과 대사 | |
| Q4 | 읽을 시간 | 결정 말풍선 뒤 **0.6초** 기다렸다 공개, 아이템은 **0.8초** 뒤 다음 판단(Inspector 칸) | 지금은 읽기 전에 결과가 나옴 |
| Q5 | 진행 | `.scratch/clown-tell/` Grilling → Spec → Ticket, 코드·Scene AI, 말풍선 그림 `tools/`, gdd-changes | 지금까지와 같음 |

## 2라운드
| Q | 질문 | 결정 |
|---|---|---|
| Q6 | 대사(늘 같은 대사, 금색 = 강조) | 매수 "**매수**. 들고 간다." / 매도 "**매도**. 너한테 넘기지." / 아이템 "**차트 분석**을 쓰지."·"**찌라시**를 쓰지."·"**거래 정지**를 쓰지."·"**복권**을 쓰지." / 매수+상승 "한 번 더." / 매수+하락 "…칫." / 매도+하락 "잘 받았지?" / 매도+상승 "흥. 아무 일도 없군." / 차트 분석 "…그렇군." / 찌라시 "다들 봤지?" / 거래 정지 "넌 한 번 쉬어." / 복권 잔고+1 "운이 좋군."·레버리지+1 "판을 키우지."·아이템+1 "하나 더."·꽝 "…꽝이군." |
| Q7 | 자리·모양 | 광대 머리 왼쪽(9시 글자 자리) 약 110×28, 꼬리는 광대 쪽, 대사 상자와 같은 어두운 창 + 꼬리 그림(`tools/`), 글자 11·강조 금색 |
| Q8 | 내 차례 반응 | 피해 날 때만: 내가 매수+하락 "하하." / 내가 매도+하락(광대가 맞음) "…칫." |
| Q9 | 떠 있는 시간 | 결정 → 결과 대사로 바뀜, 결과 대사 1.5초 뒤 사라짐, 다음 말풍선이 오면 바로 바뀜, 내가 행동하면 바로 사라짐 |
| Q10 | 나오는 방식·소리 | 한 번에 다 보임, 클릭음 30% 한 번 |
| Q11 | Ticket | 80 결정·아이템 말풍선(+기다림) / 81 결과 대사(+Q8)·9시 글자 없애기(80 뒤) |
