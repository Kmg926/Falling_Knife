# Spec: 로컬 ComfyUI로 타이틀 일러스트 시험 (comfy-local)

Status: ready-for-agent

> 근거: 2026-11-18 Grilling Q1~Q9(모두 사용자 채택, `grilling.md`). 기준: ADR 0003(그림은 코드로), gdd-changes #36~38·#42·#67, formal-ui 29(TitleScene), art-hd(640 격자·32색·PPU 2).
> Spec 작성 중 AI가 제안한 세부 9개("AI 제안" 절)는 2026-11-18 사용자가 **모두 채택**.
> 확인한 사실: 그래픽카드 RTX 4070 SUPER 12GB. TitleScene 그림 = 바탕색 + 빨간 차트 선(`Title/title-graph.png`) + 제목 글자 + 조작 상자(`title-controls-box`) + 시작 버튼(`title-start-button`) + 광대(`Clown/clown-idle`). ComfyUI·모델은 아직 설치 안 됨.
> 아직 확인 못 한 것: 생성 속도, 도트 LoRA 품질, 모델·LoRA 라이선스 세부(받기 전에 페이지에서 확인).

## 변경·유지·확인

**변경:** 로컬 ComfyUI로 타이틀 화면 배경 일러스트를 만들어, 32색·640 격자로 후처리한 뒤 지금 타이틀과 나란히 비교한다. 사용자가 고르면 TitleScene 배경으로 넣는다.

**바꾸지 않을 것 / 유지 (이유):**
- U1 게임 화면(GameScene)·판정 그대로 — 이번 시험은 타이틀만(Q2)
- U2 광대·UI·애니메이션 그림은 코드(Q1)
- U3 32색 팔레트·640 격자·PPU 2(Q5)
- U4 제목·조작 안내·시작 버튼 글자는 그대로 위에(읽기 쉬움)
- U5 배경음악은 AI로 만들지 않음
- U6 비영리 프로젝트 기준으로 권리 판단, 모든 생성 과정 기록(Q6)

**사건별 알아차릴 정보:**
- 타이틀을 켰을 때: "어두운 도박판·떨어지는 차트"의 분위기가 한눈에

**확인 – 작동:**
- C1 ComfyUI가 내 컴퓨터에서 돌고, API로 모델 목록을 읽을 수 있음(AI가 확인)
- C2 같은 워크플로·시드로 다시 만들면 같은 그림(재현)
- C3 후처리 결과 640×360·32색(팔레트 검사 OK)·PPU 2
- C4 타이틀 글자·버튼과 겹쳐도 읽힘(캡처), 시작 버튼으로 GameScene 진입
- C5 GameScene 변화 없음, Console 오류 0
- C6 `asset-rights.md`에 도구·모델·LoRA·라이선스·프롬프트·시드, ADR 0004

**확인 – 경험 (직접 보기):** 지금 타이틀보다 분위기가 나은가, 코드로 그린 광대·글자와 어울리는가. "직접 확인 필요".

**확인 전:** 구현 전이라 전부 확인 전.

## Problem Statement

타이틀은 바탕색 위에 선·글자·광대만 있어서 게임의 첫인상(어두운 도박판)이 약하다. 코드로 큰 배경 일러스트를 그리기는 어렵고, 전에 Comfy를 안 쓴 이유(유료 구독)는 로컬에서는 없다.

## Solution

사용자가 ComfyUI를 직접 설치하고, AI가 `tools/` 스크립트로 로컬 API에 워크플로를 보내 배경 일러스트 후보를 만든다. 후보는 팔레트·격자에 맞게 후처리하고, 지금 타이틀과 나란히 캡처해 사용자가 고른다. 쓰지 않기로 해도 결과를 ADR 0004에 남긴다.

## User Stories

1. 플레이어로서, 타이틀에서 게임 분위기를 한눈에 느끼고 싶다.
2. 플레이어로서, 제목·조작 안내·시작 버튼이 잘 읽히길 원한다.
3. 개발자로서, 생성 그림도 지금 팔레트·격자 규칙에 맞길 원한다.
4. 개발자(평가·면담)로서, 어떤 도구·모델·프롬프트·시드로 만들었는지 남기고 싶다.
5. 개발자로서, 별로면 지금 타이틀을 그대로 쓰고 싶다.

## Implementation Decisions

- **설치(사용자):** ComfyUI + 모델 파일. AI는 받기 전에 배포 페이지의 라이선스를 확인해 보고, 설치 뒤 연결만 확인.
- **스크립트(`tools/`, AI 작성):** 생성(API에 워크플로 보내고 그림·설정 저장), 후처리(줄이기·팔레트).
- **Scene(MCP):** 사용자가 고른 경우에만 TitleScene에 배경 오브젝트 추가.

### AI 제안 → 사용자 채택 (2026-11-18, 9개 모두)
1. **설치 형태:** **ComfyUI Desktop**(Windows 설치 파일, 공식 사이트)을 추천 — 설치·업데이트가 쉬움. 포터블(압축 파일)도 가능. 연결 포트는 설치 뒤 AI가 확인(데스크톱과 포터블의 기본 포트가 다를 수 있음).
2. **모델 후보:** 기본 모델 **SDXL base 1.0**(Stability AI) + 도트 그림 LoRA 1개(후보는 받기 전에 AI가 2~3개 찾아 라이선스·예시와 함께 보고 → 사용자가 고름). 라이선스가 비영리 사용·결과물 공개를 허락하지 않으면 제외.
3. **만드는 그림:** 사람·글자 없는 **배경만** — 어두운 방, 매달린 전등 하나의 노란빛, 테이블, 벽에 떨어지는 빨간 차트 선. 왼쪽은 어둡게 비워 제목 글자 자리, 광대는 지금 코드 그림을 오른쪽에 그대로(Q1). 네거티브: 글자·워터마크·사람.
4. **크기·후처리:** SDXL이 잘 만드는 16:9 크기(1344×768)로 생성 → 두 가지 후처리를 나란히: **A** 640×360으로 바로 줄여 32색 맞춤(지금 그림과 같은 도트 크기) / **B** 320×180으로 줄여 32색 맞춘 뒤 2배(굵은 도트). 무늬 섞기(dither)는 A·B 각각 켠 것/끈 것.
5. **후보 수:** 시드 4개 생성 → 후처리 → 지금 타이틀과 함께 한 장에 비교. 마음에 드는 게 없으면 프롬프트를 말로 고쳐 다시(최대 3번).
6. **재현·기록 파일:** 워크플로 `tools/comfy/title-bg.json`, 생성마다 `.scratch/art/drafts/comfy/<시드>.png` + 같은 이름 `.json`(프롬프트·시드·모델·LoRA·크기·걸음 수). `asset-rights.md`에 고른 그림 한 줄.
7. **넣는 방법:** 고른 그림을 `Sprites/Title/title-bg.png`(640×360, PPU 2)로, TitleScene 맨 뒤(정렬 가장 낮게). 지금 빨간 차트 선(`title-graph`)은 그림에 차트가 있으면 끔 — 비교 캡처에서 둘 다 보여 주고 사용자가 정함.
8. **ADR 0004·CLAUDE.md:** 비교 결과가 나온 뒤(채택이든 거절이든) 한 번에 씀 — 결과를 담아야 하므로.
9. **Ticket 나눔:** **50** "ComfyUI가 내 컴퓨터에서 돈다"(ready-for-human: 사용자 설치, AI 라이선스 확인·연결 확인 C1) → **51** "타이틀에 어두운 도박판 일러스트가 깔린다"(생성·후처리·비교·적용·기록 C2~C6). 51은 50 뒤.

## Testing Decisions

- **좋은 테스트:** 바깥 동작만 — API 응답(C1), 같은 시드 재생성 비교(C2), 팔레트·크기 검사(C3), 타이틀 캡처·시작 버튼(C4), GameScene 퇴행(C5), 기록 파일 존재(C6).
- **seam:** ① ComfyUI API ② 생성·후처리 스크립트 출력 ③ TitleScene 캡처 ④ `tools/` 팔레트 검사.
