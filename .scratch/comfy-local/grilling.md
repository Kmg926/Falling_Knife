# Grilling: 로컬 ComfyUI로 큰 일러스트 만들기

> 2026-11-18. 계기: lighting 49 뒤 사용자 "comfy를 로컬로 돌리면 지금 세션 메모리 유지하면서 아트워크 작업을 수월하게 할 수 있어?" → AI 답(메모리는 Comfy와 무관, 이 세션에서 생성 → 후처리 → Unity 반영을 한 번에 할 수 있음, ADR 0003의 거절 이유는 유료 구독이었음) → 사용자 "Grilling 하자".
> 확인한 사실: 그래픽카드 RTX 4070 SUPER 12GB(`nvidia-smi`). 사용자가 **Q1~Q9 모두 채택**.

## 1라운드 (모두 채택)
| Q | 질문 | 결정 | 이유 |
|---|---|---|---|
| Q1 | 어디에 쓸까 | **한 장짜리 큰 그림만**(타이틀 일러스트·결과 화면 배경·방 벽 배경). 광대·UI·애니메이션 프레임은 코드 유지 | 생성 그림은 프레임끼리 맞추기 어렵고, 이미 코드로 만든 그림과 섞이면 어색함 |
| Q2 | 첫 시험 | **타이틀 화면 일러스트 1장** | 게임 화면에 영향 없고 지금 그림과 비교 쉬움 |
| Q3 | 설치 | **사용자가 공식 배포처에서 직접 설치**, AI는 설치 확인·연결(`localhost:8188`)만 | 실행 파일이라 직접 받는 게 안전 |
| Q4 | 모델 | **SDXL base 1.0 + 도트 그림 LoRA 1개**, 라이선스는 고를 때 AI가 확인·보고(비영리 기준) | 12GB로 충분, 널리 쓰이는 조합 |
| Q5 | 후처리 | 640 격자로 줄이기 → **32색 팔레트 맞추기**(`tools/`, AI 작성), 틀린 픽셀도 AI가 코드로(#42) | 생성 그림은 진짜 도트가 아님, 지금 팔레트·격자 규칙 유지 |
| Q6 | 재현·기록 | 워크플로 JSON·시드·프롬프트·모델 이름을 저장소에, `asset-rights.md`에 "로컬 ComfyUI + 모델·라이선스" | 면담·평가(AI 투명성)에서 과정을 보여 줌 |
| Q7 | 쓸지 판단 | 지금 코드 그림과 **나란히 비교해 사용자가 고름**, 더 낫지 않으면 지금 방식 유지 | 품질로 결정 |
| Q8 | 문서 | 새 **ADR 0004**(큰 일러스트는 로컬 Comfy도 씀, 0003 일부 대체), gdd-changes 한 줄, CLAUDE.md 4장 `tools/` 문단 갱신 | 결정 이력 남기기 |
| Q9 | 진행 | `.scratch/comfy-local/` Grilling → Spec → Ticket 50, API 부르는 스크립트도 AI가 `tools/`에 | 지금까지와 같은 방식 |

## 유지
- 배경음악은 AI로 만들지 않음(사용자가 구함)
- 효과음·애니메이션·UI 그림은 지금처럼 코드

## 아직 정하지 않은 것 (Spec에서)
- 설치 형태(ComfyUI 데스크톱 앱 / 포터블)와 모델·LoRA 구체 이름·라이선스
- 타이틀 일러스트의 구도·크기(지금 TitleScene 그림과 같은 자리?)·프롬프트 방향
- ADR 0004·CLAUDE.md 갱신 시점(시험 결과 채택 뒤 / 지금)
