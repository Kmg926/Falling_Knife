# room-dress — Spec

> 2026-11-27. Grilling Q1~Q10 전부 채택.

## 1. 목표
빈 배경과 무늬 없는 테이블을 "지하 불법 증권 거래실"로 꾸민다. 게임 정보(카드·폰·전광판·모니터)는 더 잘 보이게, 꾸밈은 어둡게.

## 2. 플레이어 경험
광대 뒤 벽에 낡은 시세판(빨강·파랑 차트 선이 그 안에서 흐름), 천장 배관·전선·무대 조명 2개, 왼쪽 서버 선반(LED 깜빡임), 오른쪽 캐비닛·벽 단말. 테이블엔 닳은 페인트 선과 소품. 전등이 가끔 약하게 깜빡임.

## 3. 규칙·값
게임 규칙 변경 없음.

## 4. 화면
- 배경 `room.png`(640×360) 다시 그림, 차트 선 영역을 시세판 화면 안으로(ChartLines 폭·자리 Scene 값만).
- 테이블 `table.png`(640×160) = 지금 테이블(매트 없음) + 페인트 선 + 소품.
- LED는 겹쳐 그리는 그림 2장을 번갈아(깜빡임).
- 금색(gold1·gold2·gold3) 안 씀.

## 5. 코드 구조
- 그림 도구 `tools/make_art_room.py`(새, AI).
- `RoomFlicker`(새): LED 그림 번갈아 켜기 + 전등 빛 가끔 약하게. 읽기만(판정 없음).

## 6. 범위 밖
타이틀 화면 배경, 광대·전등 그림.

## 7. 확인
A/B 게임 캡처 → 선택 → 적용 캡처, 32색 검사, Console 오류 0.
