# 30: 테이블만 봐도 잔고·차례·라운드를 한눈에 안다 (정보 위계)

**What to build:** 떠 있는 상자(광대 잔고 틀·ROUND 틀)를 없애고 정보를 테이블 위 물건으로 옮긴다. 광대 동전은 테이블 왼쪽에 2줄 5개씩 쌓인 더미, 내 동전은 아래 띠 왼쪽에 틀 없이(제안 1). 잔고 숫자는 더미 옆 작게. ROUND는 오른쪽 위 작은 글자. 내 차례에 광대 그림을 한 단계 어둡게(조명, 제안 4). 턴이 바뀌면 가운데 띠 `내 턴`/`광대 턴` 0.8초(제안 5). 결과 한 줄은 광대 동전 아래로. 글자 겹침 0, 최소 크기 9. 공통 움직임 도구 `Tween`(제안 8)을 이 Ticket에서 만든다(턴 띠에 처음 사용).
