## Problem Statement

정식 UI(24~29)로 스케치 배치는 갖췄지만, 상자가 많고 글자가 겹쳐 정보 위계가 흐리다. 사건(덱 채움·턴 전환·피해)이 대부분 글자나 그림 교체로만 알려져 무게가 약하다. 특히 이 게임의 핵심 긴장인 "이번 덱 구성"이 단말기의 작은 글자 한 줄이라 기억하기 어렵다. 아이템 확인은 평면 그림이라 물건을 들여다보는 느낌이 없다.

## Solution

화면을 "테이블 위 물건" 중심으로 다시 정리한다(동전 더미, 광대 조명). 덱을 채울 때 캔들을 실제로 늘어놓아 보여 주고 섞는 연출을 넣는다. 아이템은 코드로 미리 그린 회전 그림 8장으로 유사 3D를 만든다. 공통 움직임 도구(쉬운 시작·멈춤, 차례로 나타나기)를 하나 만들어 버튼·띠·흔들림·동전에 같이 쓴다. 판정은 그대로 두고, GameManager는 "연출 중"인 동안 입력만 막는다.

## User Stories

1. 플레이어로서, 라운드가 시작될 때 이번 덱의 하락·상승 캔들 개수를 눈으로 보고 기억하고 싶다.
2. 플레이어로서, 덱 공개 연출을 이미 알면 Space로 건너뛰고 싶다.
3. 플레이어로서, 내 잔고와 광대 잔고를 테이블 위 동전 더미로 느끼고 싶다.
4. 플레이어로서, 누구 차례인지 화면 전체 분위기(조명·띠)로 바로 알고 싶다.
5. 플레이어로서, 피해를 입으면 화면이 흔들리고 동전이 떨어져 손해를 실감하고 싶다.
6. 플레이어로서, 버튼을 누르면 눌렸다는 반응을 보고 싶다.
7. 플레이어로서, 아이템을 확인할 때 물건이 공중에서 천천히 도는 걸 보고 싶다.
8. 멀미에 약한 플레이어로서, 화면 흔들림을 끌 수 있으면 좋겠다(지금은 Inspector).
9. 개발자로서, 연출이 판정 시간과 섞이지 않아 퇴행 테스트가 그대로 통과하길 원한다.
10. 개발자(면담 대비)로서, 움직임 코드가 한 곳(공통 도구)에 모여 설명하기 쉽길 원한다.

## Implementation Decisions

- **그림 (`tools/make_art.py`, AI 작성):** 동전 더미(제안 1), 광대 조명용 한 단계 어두운 광대(이미 `clown-dark`는 두 단계 → 한 단계 판 추가), 덱 공개용 뒤집힌 캔들 뒷면, **아이템 회전 그림 4종 × 8장**(아이콘을 두께 3도트로 세우고 Y축 0~315° 45° 간격, 정사영, 옆면은 한 단계 어두운 색, 팔레트로 맞춤), 그림자 타원, 턴 띠.
- **공통 움직임 도구 (새 `Tween` 정적 클래스, 제안 8):** `IEnumerator Move/Scale/Fade(대상, 시간, easing)`와 easing 함수 몇 개(EaseOutCubic·EaseOutBack). DOTween 같은 외부 패키지는 쓰지 않음(면담에서 설명 가능하게). 도트가 흐려지지 않게 위치는 **정수 도트로 반올림**.
- **연출 중 입력 막기 (GameManager):** `public bool IsPresenting`(연출 중). `CanPlayerAct`와 입력 함수 첫 줄에 추가. 연출은 화면 쪽(`DeckRevealView`)이 맡고, 시작·끝을 GameManager에 알린다(`BeginPresentation()`/`EndPresentation()`). 판정 코루틴은 연출을 기다리지 않는다 — 라운드 시작·재장전 **직후** 연출이 돌고, 그동안 플레이어 입력과 광대 차례 시작만 미룬다.
- **덱 공개 (`DeckRevealView`, 새 파일):** `deck.JustFilled`가 켜지는 순간 시작 → 캔들 n+m개를 테이블 위 한 줄로 0.08초 간격 등장(하락 먼저, 상승 다음 — 개수만 보이게) → 0.4초 멈춤 → 모두 뒷면으로 뒤집힘 → 단말기 쪽으로 모여 사라짐. Space(Execute)로 즉시 끝.
- **동전 더미 (`BalanceView` 수정, 제안 1):** 틀·떠 있는 숫자 대신 테이블 위 더미 그림 + 작은 숫자. 줄어들면 줄어든 동전이 떨어지는 움직임.
- **턴 (`RoundTurnView` 수정, 제안 4):** ROUND 상자 없앰 → 오른쪽 위 작은 글자. 턴이 바뀌면 가운데 띠 0.8초. 광대 그림은 내 차례에 한 단계 어둡게(`ClownView`).
- **아이템 3D (`ItemCloseupPanel` 수정):** 큰 아이콘 대신 회전 그림 8장을 0.15초씩 넘김 + 위아래 1도트 사인 움직임 + 그림자.
- **피해 흔들림 (`UIManager` 수정):** 카메라가 아니라 **그림·HUD를 담은 부모를 2도트 흔듦**(Pixel Perfect 카메라는 건드리지 않음), `screenShake` 칸으로 끄기.
- **버튼 눌림 (`ActionButtonsView`·슬롯):** 눌린 0.1초 동안 그림을 1도트 아래로.
- **코드:** AI가 Scripts에 작성(Q8, 4장 예외 기록). Scene 연결도 AI가 MCP로.
- **Ticket 순서(Q1):** ① 정보 위계·동전 더미·조명·턴 띠(30) → ② 덱 공개 연출(31) → ③ 아이템 유사 3D(32) → ④ 작은 반응·흔들림·버튼(33).

### AI 제안 → 사용자 채택 (2026-11-16, 8개 모두)
1. **동전 더미 자리:** 광대 동전은 **테이블 왼쪽**(단말기 왼쪽, 지금 결과 한 줄 자리 위쪽)에 2줄 5개씩 쌓임, 내 동전은 아래 띠 왼쪽(지금 자리)에서 틀 없이 더미 모양. 결과 한 줄은 그 아래로.
2. **연출 길이:** 라운드 시작 약 1.5초, 재장전 약 1.0초(재장전은 자주 일어나서 짧게).
3. **덱 공개에서 하락→상승 순서로 놓기:** 개수 세기 쉽게(섞인 순서가 아님을 화면에 `섞는 중…`으로 분명히).
4. **조명 = 광대 그림 한 단계 어둡게:** 반투명 덮개 대신 그림을 바꿈(팔레트 유지). Light 2D는 범위 밖(나중 과제).
5. **턴 띠:** 화면 가운데 가로 띠(bg0 바둑판 위 글자) 0.8초, 연출로 입력을 막지 않음.
6. **아이템 회전:** 8장 × 0.15초 = 1.2초에 한 바퀴, 위아래 1도트 1초 주기.
7. **흔들림:** 2도트, 0.15초, 기본 켬, Inspector `Screen Shake`로 끔.
8. **움직임 도구는 직접 만든 `Tween` 정적 클래스:** 외부 패키지 없이 코루틴 + easing 함수 3개.

## Testing Decisions

- **좋은 테스트:** 바깥 동작만 — 연출 중 `IsPresenting`과 입력 무시, 놓인 캔들 수 = 덱 구성, 건너뛰기 뒤 즉시 끝, 회전 그림 순서, 흔들림 끄면 위치 그대로, 글자 상자 겹침 검사(RectTransform 서로 비교).
