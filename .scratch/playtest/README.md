# 플레이테스트 (마일스톤 ③ Alpha + 3인)

> 2026-11-27 준비. 빌드: `Builds/FallingKnife/FallingKnife.exe`(Git 제외 — 이 컴퓨터에서 만든 빌드를 그대로 씀, 배경음악 포함).
> 테스터 이름은 공개 저장소라 **쓰지 않는다**(A·B·C로). 실제 이름이 필요하면 로컬 작업기록에만.

## 진행 순서 (한 사람 약 15분)
1. 아무 설명 없이 실행 → 타이틀에서 스스로 고르게 둔다(처음 `시작`의 튜토리얼 권유를 받는지 보기). 처음 권유는 한 번만 나오므로, 다음 사람 전에 설정 기록을 지운다(아래).
2. 튜토리얼(했으면) → 실전 한 판. **도와주지 않는다** — 막힌 곳만 적는다.
3. 끝나고 질문 5개(아래 표 오른쪽).

### 사람마다 처음 상태로 되돌리기
- 저장값(소리·흔들림·튜토리얼 권유)은 Windows 레지스트리 `HKCU\Software\DefaultCompany\Falling_Knife`에 있다. 다음 사람 전에 지우면 처음처럼 권유가 나온다.
- PowerShell: `Remove-Item "HKCU:\Software\DefaultCompany\Falling_Knife" -Recurse`
