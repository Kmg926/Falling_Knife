# 05: 한쪽 잔고가 0이 되면 승패가 나오고 R로 다시 시작한다

**What to build:** 광대 잔고가 0이 되면 "승리 — R로 재시작", 플레이어 잔고가 0이 되면 "패배 — R로 재시작"이 보이고 더 이상 행동을 실행할 수 없다. 이 화면에서 R을 누르면 잔고·레버리지·덱·차례가 처음 상태로 돌아간다. R은 테스트용 키이며 최종 빌드 전에 제거한다.

- [x] 플레이 중·공개 중 R은 무시된다

Spec: `../spec.md` (Q2·Q12·Q22) · Grilling: `../grilling.md`

## 시연 순서
1. 고정 순서 `U U D U D` → Play → Space × 3 → `패배... - R로 재시작`
2. A·D·Space를 눌러도 반응 없음
3. R → 처음 상태(잔고 2/2, 레버리지 0, 남은 2/3, 플레이어 차례)
4. 고정 순서 `D U U D U` → D·Space × 3 → Space → `승리! - R로 재시작`
5. 플레이 중에 R을 눌러도 반응 없음
