# 11: 라운드를 시작하거나 재장전할 때마다 덱의 하락·상승 개수가 랜덤으로 정해진다

**What to build:** 라운드 표 한 줄이 `Starting Balance / Min Cards / Max Cards / Fixed Order`가 된다. 덱을 채울 때마다(라운드 시작·재장전) 총 장수를 그 줄의 최소~최대에서, 하락 수를 1 ~ (총−1)에서 뽑아 섞는다. 범위 값이 잘못되면(최소 < 2, 최대 < 최소) 맞춰 쓰고 경고한다. `Use Fixed Order`를 켜면 빈칸이 아닌 고정 순서 문자열이 그대로 덱이 된다(개수 비교 없음). 빈칸이면 경고 없이 랜덤, D·U·공백 외 글자는 경고 + 랜덤. 잔고는 아직 2/3/4 그대로(12에서 바꿈).
