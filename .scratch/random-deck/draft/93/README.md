# draft 93: 라운드마다 다른 잔고로 시작한다

> 2026-11-23. 코드는 AI가 Scripts에 직접(사용자 지시, CLAUDE.md 4장 예외와 같은 방식). `*.before.cs` = 바꾸기 전.

## 줄별 설명 (면담 대비)
### RoundConfig.cs
- `startingBalance`(한 값) → `minBalance`·`maxBalance`(범위). 기본값 5·7. 고정하고 싶으면 최소 = 최대(3라운드 10·10, 퇴행 테스트 2·2).
- `[Serializable]` 클래스라 Inspector 라운드 표에 칸이 바로 생김. 이름이 바뀐 칸은 Scene에 저장된 옛 값(10)을 못 읽어서, Scene 값은 MCP로 다시 넣고 저장함.

### GameManager.cs
- 라운드 표 기본값: `{5,7} / {5,7} / {10,10}`.
- `StartRound()`:
  - `Random.Range(최소, 최대 + 1)`: 정수용 `Random.Range`는 **끝 값을 빼고** 뽑음 → 7도 나오게 + 1. `Mathf.Max(최소, 최대)`는 최대를 최소보다 작게 잘못 넣어도 오류 없이 최소를 쓰게.
  - 한 번 뽑은 `balance`로 나·광대를 둘 다 만듦 → 같은 잔고(공정).
  - `StartRound`는 게임 시작·다음 라운드·다시하기 때마다 불리므로 그때마다 새로 뽑힘. 재장전(덱만 다시 채움)은 잔고를 건드리지 않음.
- 그대로인 것: 회복 상한·동전 개수·"7/7" 표시는 모두 `Participant.StartingBalance`(그 라운드에 뽑힌 값)를 읽어서 코드 변경 없음.
