## 1. `RevealRoutine()` — `deck.Draw()` 다음에 추가
```csharp
        Candle candle = deck.Draw();

        Participant actor = Current;                       // ← 추가

        if (action == PlayerAction.Hold) ResolveHold(candle);
        else ResolveSell(candle);

        LastResult = $"{actor.Name}: {LastResult}";        // ← 추가

        if (!IsRoundOver && deck.IsEmpty)
        {
            Reload();
        }
```
| 줄 | 왜 |
|---|---|
| `Participant actor = Current;` | **판정 전에** 지금 차례인 사람을 기억한다. `ResolveHold`(하락)·`ResolveSell`은 안에서 `PassTurn()`을 불러 `Current`를 **상대로 바꾼다**. 판정 뒤에 `Current.Name`을 쓰면 매도한 사람이 아니라 상대 이름이 찍힌다 |
| 비유 | 심판이 "방금 던진 사람"을 공이 떨어지기 전에 메모해 두는 것. 공이 떨어지면(판정) 차례가 넘어가서, 그때 "지금 차례가 누구지?"라고 보면 다음 사람이 나온다 |
| `LastResult = $"{actor.Name}: {LastResult}";` | 판정이 만든 문구 앞에 이름을 붙인다. 네 가지 문구(보유 상승·보유 하락·매도 하락·매도 상승)를 하나씩 고치지 않고 **한 곳**에서 처리 |
| `Reload()`보다 **앞** | 재장전 줄(`\n덱 재장전 …`)은 그 뒤에 덧붙으므로 결과 줄 아래에 그대로 남는다(C3) |

- `Participant`는 이미 있는 클래스(이름·잔고). 새로 만드는 것 없음.
- 지역 변수(`actor`)라서 이 함수 안에서만 쓰고 사라진다. 상태를 늘리지 않는다.

## 2. `ResolveHold()` 상승 문구 — 이름 빼기
지울 줄:
```csharp
            LastResult = $"보유 → 상승! {Current.Name} 레버리지 {Leverage.Value}, 차례 유지";
```
넣을 줄:
```csharp
            LastResult = $"보유 → 상승! 레버리지 {Leverage.Value}, 차례 유지";
```
| 왜 |
|---|
| 앞에 이름이 붙으므로 그대로 두면 `광대: 보유 → 상승! 광대 레버리지 1`처럼 이름이 두 번 나온다. 레버리지는 **공용**이라 원래 이름이 필요 없었다 |
| 다른 세 문구의 이름(`광대 -2`, `플레이어 -1`)은 **맞은 사람**이라 그대로 둔다: `광대: 매도 → 하락! 플레이어 -1` = 광대가 매도해서 플레이어가 맞음 |

## 3. 결과 문구 (반영 후)
| 행동 | 화면 |
|---|---|
| 보유 + 상승 | `플레이어: 보유 → 상승! 레버리지 1, 차례 유지` |
| 보유 + 하락 | `광대: 보유 → 하락! 광대 -2` |
| 매도 + 하락 | `광대: 매도 → 하락! 플레이어 -1` |
| 매도 + 상승 | `플레이어: 매도 → 상승! 변화 없음 (레버리지 0 그대로)` |
| 재장전 | 위 줄 아래 `덱 재장전 (하락N / 상승M)` |
