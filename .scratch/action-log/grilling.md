# Grilling: 광대 행동 속도 + 행동 로그

> 2026-11-09. 계기: random-deck Ticket 12 직접 플레이 피드백 "광대가 행동할 때 텍스트가 너무 빨리 지나가서 뭘 했는지 못 보겠다. 텍스트가 지나가는 속도를 줄이고 왼쪽 하단에 로그가 남았으면 좋겠다."
> 질문은 AI가 추천 답과 함께 묻고, 사용자가 채택·거절했다. 1라운드, Q1~Q8 **모두 채택**.

## 확인한 사실 (질문 전, GDD 원문 PDF)
- F06 광대 AI: "04장 순서대로 판단, **1초 간격**". 지금은 생각 0.5초 + 공개 0.5초.
  - gdd-changes #22에 "광대 턴 진행 시간 미정"이라고 적었던 것은 **원문과 다른 기록(AI 실수)** → 이번에 바로잡음.
- 05장 단말기 "덱의 남은 수와 **공개 기록** 표시", 찌라시 "기록에 추가", F07 결과 "결과 문구, 기록", 08장 데이터 "결과 기록. GameManager가 보관" → 로그는 GDD에 있는 "공개 기록"의 구체화.
- 지금 결과 문구는 행동한 사람이 빠진 경우가 있다(`매도 → 하락! 플레이어 -1` = 광대가 매도한 것인지 차례 줄로 짐작해야 함).
- 생각 중에는 직전 결과 줄이 계속 보인다(09에서 "덮지 않고 덧붙임") → 생각 시간 = 광대 결과를 읽는 시간.
