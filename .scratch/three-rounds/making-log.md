## 한 문장 기록
1라운드에서 끝나던 판을 3라운드(잔고 2/3/4, 덱 2:3 / 3:4 / 4:4)로 늘렸고, 1라운드 동작은 그대로 두었으며, C1~C9를 Play 모드에서 모두 확인했지만 텍스트 UI로는 라운드가 올라가는 느낌이 약해 정식 UI 과제로 남겼다.

## 변경 목적
마일스톤 ①은 1라운드만 끝까지 갈 수 있어서 GDD의 승리 조건("3라운드에서 광대 잔고 0")을 달성할 수 없었다. 라운드가 올라가며 잔고·덱이 커지는 긴장감도 시험할 수 없었다.

- 3라운드 재장전(하락4/상승4), 3라운드 패배 — 같은 코드 경로지만 그 라운드에서 직접 보지는 않음

## 배운 것 (오류 해결)
- Unity 창에 포커스가 없으면 저장한 스크립트를 다시 컴파일하지 않은 채 Play될 수 있다(08에서 옛 문구가 보임). → MCP 테스트 전에 **컴파일 시각이 저장 시각보다 나중인지** 확인한다.
- 같은 이유로 키 시뮬레이션이 전달되지 않을 때가 있다(07). → 함수 직접 호출로 먼저 확인하고, 실제 키 확인을 따로 남긴다.
