# 08: 어느 라운드에서든 지면 R로 1라운드부터 다시 한다

**What to build:** 어느 라운드에서든 플레이어가 파산하면 `패배... - R로 처음부터`가 보이고 Space·A/D는 무시된다. 끝난 화면(라운드 클리어·최종 승리·패배) 어디서든 R을 누르면 1라운드부터 다시 시작한다. 플레이 중·공개 중 R은 무시한다. R은 테스트용이며 최종 빌드 전에 제거한다.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 2라운드(또는 3라운드)에서 플레이어 파산 → 패배 문구, Space·A/D 무시 (C6)
- [ ] 패배 화면에서 R → `라운드 1 / 3`, 잔고 2/2, 남은 2/3 (C6)
- [ ] 라운드 클리어 화면에서 R → `라운드 1 / 3` (C7)
- [ ] 최종 승리 화면에서 R → `라운드 1 / 3`
- [ ] 플레이 중·공개 중 R → 변화 없음 (C8, U4)

Spec: `../spec.md` (Q7·Q9) · Grilling: `../grilling.md`

## 시연 순서
1. 1라운드를 깨고 Space → 2라운드에서 일부러 보유를 반복해 플레이어 파산 → 패배 문구
2. Space·A/D → 변화 없음 → R → 1라운드 처음 상태
3. 다시 1라운드를 깬 클리어 화면에서 R → 1라운드
4. 플레이 중과 "공개 중..." 동안 R → 변화 없음
