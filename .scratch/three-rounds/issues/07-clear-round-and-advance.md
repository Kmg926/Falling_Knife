# 07: 광대를 파산시키면 Space로 다음 라운드에 가고, 3라운드를 깨면 최종 승리를 본다

**What to build:** 1·2라운드에서 광대가 파산하면 `라운드 N 클리어! - Space로 다음 라운드`가 보이고, Space를 누르면 라운드 표의 다음 줄로 새 라운드가 시작된다(잔고 새로, 레버리지 0, 새 덱, 플레이어 차례, `[보유]`, 결과 줄 빈칸). 3라운드에서 광대가 파산하면 `최종 승리! - R로 처음부터`가 보이고 Space는 무시된다. 재장전은 그 라운드 구성으로 한다.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 1라운드 광대 파산 → 클리어 문구 → Space → `라운드 2 / 3`, 잔고 3/3, 남은 3/4, 레버리지 0, 플레이어 차례, `[보유]` (C3)
- [ ] 2라운드에서 7장을 다 써도 승부가 안 나면 `덱 재장전 (하락3 / 상승4)` (C4, U3)
- [ ] 마지막 캔들로 광대 파산 → 재장전 없이 클리어 (C9, U2)
- [ ] 3라운드 광대 파산 → `최종 승리! - R로 처음부터`, Space 무시 (C5)
- [ ] 클리어 화면에서 A/D는 무시, 공개 중 입력 무시는 그대로 (U4)
- [ ] 1라운드 동작은 06과 같다 (U1)
